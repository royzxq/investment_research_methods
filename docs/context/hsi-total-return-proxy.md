## 2026-09-30 的构造

历史研究使用盈富基金 `02800` 作恒指收益代理：

1. 新浪 `ak.stock_hk_daily(symbol="02800", adjust="")` 提供未复权收盘价 `raw`；东方财富 `ak.stock_hk_hist(symbol="02800", adjust="hfq")` 提供后复权收盘价 `hfq`。记忆称当日观察到 `hfq - raw` 呈阶梯状，按加法调整处理；这个判断需要重新核验，不能泛化至所有后复权序列。
2. 两源按交易日期内连接并排序，计算候选派息 `div_t = Δ(hfq_t - raw_t)`。历史脚本把绝对变化不超过 `0.005` 港元的项置零，首日候选派息置零。
3. 从首日原价起连乘：`TR_t = TR_(t-1) × (raw_t + div_t) / raw_(t-1)`，输出 `HSI_TR_2800.csv`。脚本同时打印年度隐含派息率、原价与 HSI 日收益相关性，以及长期收益比较。

这是**基金分红再投资收益代理**，包含基金自身费用、跟踪差异及两源数据误差；不等同于恒指官方全收益指数。原研究另按汇率折人民币，需与收益代理和信号各自币种一同复核。

历史记忆记载当日新浪原价与东财后复权可读，东财原价反复连接失败、新浪 `hfq-factor` 解析失败。这些只说明 2026-09-30 的环境，不说明现在的接口可用性。

## 后续复现缺口

- 从私有备份恢复到独立临时目录，先核对两源单位、日期、缺失值和复权口径，再与基金正式派息记录逐笔对照；不能仅凭阶梯形状把每次差分都认作分红。
- **原脚本只打印较大的负候选派息，仍让它们进入 TR 连乘**；超过噪声阈值的正误差同样可能被当作分红。原记忆提到两源不一致的小跳变，脚本没有完整消除它们，复现须逐笔裁决并保留原始数据。
- 核对派息时点、再投资假设、税费、基金费用是否重复扣除，以及人民币换算。优先与可得的官方全收益序列或基金复权净值交叉检查。
- 形成可复现报告后，才决定是否接入取数脚本或正式回测。旧隐含派息率、年化收益与接口可靠性数字不作为已复核事实；本次迁移不运行联网研究。
