# V50 基准、现金流估值与市场隐含预期审计

状态：用户授权本地实施、隔离验证及评审修复后合并本地dev；实际合并后核对正文哈希并建立adopted接续，不推送远端、不更新正式报价。

## 问题与裁决

V50 的正常情景不能由多个没有联合依据的悲观参数拼成。PE 的计算正确不证明倍数合理；固定 K×市值只能作终局粗筛。DCF 也不因形式更复杂而更准确，必须核经营、再投资、资本桥与终值。研究不得以贴近市价或提高触价率为目标。

新准备批次使用 `two-price-controls/v7` / `stock-research-audit/v4`，轻量价格保持 `stock-research/v4`。旧 controls v1–v6 的提示字节、输入、审计版本与冻结方法原样恢复。audit-v3 的 PE 权益调整继续有效；旧 non-PE `other` 仍按原合同验证，不能用新版本追认其 DCF 已被复算。

新增 `dcf_fcff` 支持持续经营非金融公司、逐年分部 FCFF、稳定期再投资与独立权益桥。FCFF 与 WACC 匹配，终值利润乘 `(1-g/ROIC)`。有限寿命、金融、FCFE/DDM 等继续使用适用模型并披露计算覆盖；不把这版有限计算器冒充所有 DCF。计算模块供报告审计与隔离对照共同使用，不生成正式报价。

audit-v4 要求 `valuation_review`：中性情景依据、方法选择、倍数交叉核验、市价/日期/来源及差异解释、反向估值状态及依据。可核算的 FCFF 不通过 `other` 回避。反向 DCF 使用同一正向模型，对指定分部终值利润率在有依据区间内求根；其他变量固定，明确只是一组条件解，不能直接解释为完整业务天花板。支持在报告中对不同资本成本/经营组合分别求解。无根或关键输入不可得保留状态及区间，不外推成唯一事实。

本次FCFF计算边界补充：残差业务可显式设终值利润率=0且g=0，表示终值价值为0，仍完整计入显式期成本及投入；不能为通过审计编造正利润。非零增长的亏损/零利润终局仍不适用该永续式；反向求解仍要求正终局利润率的可识别条件解。

## 方法与状态、兼容与周更

canonical 和 compact 同步，仅修改估值/终局及对应交付。固定 K 保留为速算，不能凭速算的不可达判定触发终局冻结，须适用详细模型与业务证据复核；既有持续限制解除仍要求逐项对应证据及复评。DCF 主估值不能豁免 Gate/持仓规则。

周更区分新事实刷新、口径纠错与方法变更。参数更新需经济证据及作用位置，不能按每周涨跌拟合参数；新增模型、默认参数或阈值必须方法审议。未采纳提案不写进已采纳状态，不自动完成个股复评。旧报告按自身版本检查、新审计完成凭证正常接续；市场状态块不刷新。

## 验证设计

先失败测试再实现。覆盖 FCFF/终值/权益桥、反解往返、负过渡现金流、时点/币种、非有限数、错序、无根、风险重复、旧冻结字节和周更完成凭证。相同经营条件下 ROIC=WACC 的稳定增长价值中性；不能用“增长更高必更值钱”作为通用不变量。

阿里及小米统一估值日 2026-10-31，各自原始包及补证字节冻结。先固定经营与倍数只纠资本桥/残余折扣，再固定修复规则比较模型与经营假设，按有说明的顺序分解（交互项有路径依赖），不把研究者自由取值当规则因果效应。保留未决资本归属条件和市场隐含组合。正式 CSV、本地模型报价、正式报告/latest 做前后哈希对照。
