# DSH 有界补证与效果记录

日期：2026-11-08（Asia/Shanghai）。用户授权在取数体检后集中补强网页截断、PDF、分页不足的补证闭环和效果记录。此变更不调整投资方法、估值合同、模型或调度。

## 决定与生效范围

新准备批次选择 `dsh-deepseek-flash-high-recovery-v1`，在原工具和 `data-health-v1` 上增加 `evidence_recovery=evidence-recovery-v1`。旧 profile 不修改，已冻结批次、重试及恢复不追补。回退选择上一版 `dsh-deepseek-flash-high-health-v1`，只影响以后准备的批次。

适配器冻结 `dsh-evidence-recovery.mjs` 与 `dsh-document-recovery.py` 两个源文件及其 SHA-256；补证插件引用本次冻结的体检模块、估值日和已验证的 PyMuPDF 解释器。最终回执验证源码绑定。没有自动安装依赖、切换模型、改排期或启动正式研究。

## 原生工具组合

补证插件在 DSH `tools/post-execute` 中观察体检允许保留的原始返回，调用注册的 `research_recover_evidence`；分页内部调用原生 AKTools 工具，仍经过已有工具策略和体检。不绕过其他策略拒绝，不把补证结果写回原始 canonical value，原工具失败也保留原失败身份。根/子代理在同一次尝试内共享来源状态；PTC 子调用将补证状态作为工具来源上下文送回。

| 问题 | 自动动作 | 限制与停止条件 |
|---|---|---|
| 网页显式截断或无可见正文 | 对同一 URL 完整下载，保存原始字节及去除脚本/导航后的定位文本 | 每 URL 只做一次补证下载；失败保留缺口。URL 片段不作为不同来源。HTML 解析成功不是主体、相关性或语义完整性证明 |
| PDF 链接或 PDF 不支持错误 | 下载原件，核文件头，用 PyMuPDF 按页提取；也可直接调用补证工具传 URL | 下载完整、PDF可解析、文本可读分开；无文字页保留警告，可请求渲染原页，生成图片不等于已经查看或 OCR |
| AKTools 分页不足 | 先保存已获页，从首个未覆盖偏移续取；每轮最多补3页、每页最多1000行 | 首轮自动，最多3轮，后两轮由研究者按缺口调用；总行数漂移、重复/重叠冲突或身份错误停止。网络失败保留已核片段及未解决状态；尾页 truncated=true 不触发额外重试 |

文档只访问公共 HTTP(S) 标准端口，不继承认证头、Cookie、代理或模型密钥；逐次重定向核目标，固定已核 DNS 地址并保留 HTTPS 主机名校验。HTTPS 不降级到 HTTP。单文档32 MiB、PDF最多1000页、提取文本32 MiB、最多5次重定向；下载总预算60秒、单连接15秒，整个工作进程90秒。超过边界显式失败，不截断后宣称完整。压缩响应暂不解码，记录不支持并保留缺口。

子进程直接使用冻结解释器与脚本，无 shell。取消时终止并等待子进程退出；分页转发调用方取消信号。每尝试最多跟踪64个来源；每来源最多100次有记录的读取及100次采用判断。上述为工程资源上限，不是投资规则。

## 证据和效果语义

每次尝试的 `evidence-recovery/<来源摘要>/` 保存不可覆盖的事件快照、分页返回、文档原件、提取文本、文档清单及哈希。原始体检记录仍在 `data-health/`。会话内重复请求共享结果；进程重新载入遇到未结束记录只标记中断，不能据文件存在自动认定补证完成。

三个工具各自承担不同责任：

- `research_recover_evidence`：取回材料或续补分页，返回状态与证据目录；机械收齐不等于事实核验。
- `research_read_evidence`：关键词定位、按 PDF 页序/文本字符/表格行位置读取。实际返回片段有独立读取凭证及来源、片段哈希。关键词命中和仅生成图片均不生成可冒充正文读取的凭证。
- 文档读取及搜索同时校验清单、原件和所需文本；原件已变化时不以旧提取文本生成读取凭证。工作进程的 JSON 输出按完整字节流解码，保留跨管道块的中文元数据。
- `research_record_evidence_use`：绑定已有读取凭证，记录采用/部分采用/未采用/未解决/拒绝、相关输入、范围、理由及采用时的报告章节。这是研究者声明，不是程序确认事实正确或最终报告确有引用。

`dsh-metrics.json` 新增可选 `evidence_recovery`，按来源、触发问题、结果类型和状态汇总轮次、补充分页调用、文档下载尝试、去重次数、读取和声明采用情况，核对引用的证据文件哈希。补证耗时之和可能重叠，不等于整个研究墙钟时间；工具执行日志与补证调用计数不应直接相加。未知费用不补0，最终引用核验和独立事实核验保持 null。

不改研究成功/失败验收：补证辅助路径失败仍允许按已有方法保留缺口、使用可靠局部证据或另取来源。统计失败不得放松验收，也不抹掉既有运行统计。bash/curl、其他 MCP 和任意本地 PDF 路径仍不自动纳入本闭环；需要进入闭环的公开 PDF 使用上述工具。
