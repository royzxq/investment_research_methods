# 历史估值日复评的显式报告基线

用户已授权沿用原估值日和原包，用新方法修订每只股票最新已发布价格地图。默认 `company_runs` 刻意排除 `-rN`，以防把未采纳的隔离试算当作正式历史；但已经通过 AI 发布事务的修订也会被排除，不能据默认发现结果倒退比较基线。

新请求可在既有 `data_pack_meta.historical_valuation_revision.original_reports` 中显式绑定报告，条目为 generator/path/sha256。prepare 对每个条目校验当前证券、原估值日、真实生成端、标准公司目录、原报告字节及唯一性；按同生成端复制至既有 frozen research-baselines，不从文件名自动升级其它修订。没有同生成端绑定的仍沿既有发现规则，Claude/DSH 不互相冒充同端历史。

这只确定研究比较输入，不证明指定文件已经正式发布，也不自动刷新 latest 或报价。发布端仍必须验证原封口、完成回执及模型版本身份。实际任务清单由已发布来源链生成，不接受大模型自行挑选有利的历史版本。

原数据包和 valuation_date 不改，方法执行/采纳日期另记在同一请求元数据及报告 §0；不回填 adopted，也不把新方法内晚于原截止日的市场观测当作旧事实。既有冻结批次仅读已有快照，现场报告改变不重新选择其基线。常规每日研究、每周框架采纳与默认历史发现不变。

验证包含显式 r2/r10、错股/错日/错生成端/越界/错哈希/重复来源拒绝、旧冻结重放及 runner 相邻合同回归。
