# 估值输入证据、现金税与必要资本衔接

状态：用户授权实施、隔离回归、review 后合并本地 dev；不更新正式报价。

## 裁决

新冻结采用 controls-v8 / audit-v5，价格 JSON 仍为 stock-research/v4。controls-v1–v7 的冻结提示、输入、方法哈希与验收语义不变；旧审计不得因读取程序升级而补字段或改值。

DCF 的新合同另列year_end_offset（−1<值<1，常规0），每期及终值距估值日为year+offset与N+offset，保留原现金流时点而非迁移时重置。逐年直接列 `cash_tax`，NOPAT=EBIT−现金税，不能因合并 EBIT 亏损自动得到退税，也不能推断所有法律实体都不缴税。现金税由同一税务实体的应税利润、可使用亏损/抵扣与支付时点说明，负现金税暂不在计算器支持范围内；确有退款须专项模型及依据，不强行填 0。终值列 `invested_capital`（显式期末、支撑稳定期业务的生产性资本），稳定增长再投资=资本×g；隐含 ROIC=终值首年 NOPAT/期末资本，与原 NOPAT×g/ROIC 同口径。纯税务敏感性冻结生产性资本，不能维持 ROIC 而让所需投入机械缩小。反解仍固定其他变量，只求一个终值利润率，所得只是条件解。经营现金、股东资本加回与生产性资本不混同。

新增 `valuation_review.input_basis` 五项：profit、investment、tax、capital、residual_discount。逐项保存证据/披露截止、解释、状态、影响范围及缺口；resolved / bounded / unresolved / not_applicable 分开。bounded 是有证据约束的条件假设，不代表已证实；unresolved 影响 V50 时正式 V50 和 P1 留空，影响 P1 时 P1 留空。条件诊断放底稿，不能混成 adopted 报价。缺失折扣可为 null，乘数也为 null，不当作零折扣。不可确认的资本归属、必要投入和残余风险不能因拟上调报价而删去。

v5 风险增加 economic_key：同一事实、期间、范围和损失机制的唯一键；同键不可被不同 ID 重复定价。机器只检查声明键，经济同义仍需原文反向审查。利润恢复、长期增长、费用率/PE、税盾和资本回报仍是研究假设，无新增统一利润率、PE、WACC、折扣默认值。资金余额不直接等于普通股可分配价值；期权/NCI/LP/限制资金/预提税与已入模资产或收益成对核，已计成本与未结请求权分别辨认。

## 同步与兼容

canonical 与 compact 同步 §4.1B–D；元研究→变化检测→框架适配→每周维护传递上述证据及缺口，不以周更涨跌校准参数，不把隔离复评登记为完成。audit-v5 的完成凭证继续要求 lifecycle 和 acceptance，不绕过原控制。方法采纳建立新的不可变 handoff，带回旧 pending/withdrawn，旧记录不修改。
