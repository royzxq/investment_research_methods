# ADR-20261031：自动个股投研每日上限增至5只

状态：Accepted（用户2026-10-31明确要求“将每天调研的股票数量上限增至5个”）。

## 决定

- methods 的 `research_scheduler.DAILY_LIMIT` 从4增至5。按 `Asia/Shanghai` 自然日、上市证券归一后的市场与代码计数；同股各生成端及重试共享一个名额，A/H分别计数。
- 仅替代每日额度契约和 DSH 迁移 ADR 中的每日4只上限。四档优先级及同档稳定排序保持，超过剩余额度的候选顺延。持久化台账接纳5只、拒绝超过5只，旧台账无需迁移。
- `MAX_CONCURRENCY=4`、每端一次重试、7×24小时首启动冷却、实际启动后失败占额与启动前失败可释放等规则不变。Coze条件第三席不增加上市证券名额。
- 每日05:00起只检查一次，空检查也记账。当日已有检查记录时不补跑、不清除记录、不重置额度；本次参数调整不授权研究启动、合并、部署或生产数据写入。

## 验收与生效边界

定向回归覆盖0/4/5/6/7只候选、优先级、跨批次及重载台账、5只合法与6只拒绝、剩余一个名额的运行分支、失败不返额、7天冷却与A/H独立计数；离线子进程场景以6只候选启动5对研究，峰值并发仍为4，第6只顺延且重复运行不再启动。

代码先在隔离副本完成649项研究链路离线回归；随后用户确认同步两个仓库并应用实际运行目录，现已应用本机正式 checkout。下一次北京时间05:00晨检使用5只上限；本次不补跑、不重置当天台账，不重新安装 launchd 或改变其现有唤醒配置。ai_investment 的跨仓文档已按用户确认同步。
