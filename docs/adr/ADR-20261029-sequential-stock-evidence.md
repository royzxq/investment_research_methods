# 同股 Codex 先行、DSH 基于共享事实增量研究

日期：2026-10-29（Asia/Shanghai）。状态：用户采纳，实施于本地工作区。

用户选择先由 Codex 完整研究，再由 DSH 复用本轮公共事实，进行核验、补漏和独立分析。目标是减少重复取证，同时保留不同搜索工具与模型解释角度的价值；不能将共享事实后的两份报告当成两套独立事实发现。

## 执行合同

新准备且生成端为 Codex + DSH 的请求，在方法快照保留 `evidence_workflow=codex-then-dsh-evidence/v1`，该版本同时进入冻结提示词。原无标记的冻结批次原样恢复，不改写历史；删除新批次标记会导致提示词绑定检查失败。Codex-only、旧 Codex + Claude 仍按原合同运行。

调度按股票衔接。Codex 完成原有九节报告、价格和控制输出及验收后，还须成功冻结事实包，才可完成发布。DSH 启动前校验同股同轮 Codex 的原生成功退出、已停止进程组、completed 记录、已验收回执及正式产物，再验证事实包和来源文件。不同股票仍可并发，共用默认及上限均为四个根 CLI 进程槽。

Codex 失败、缺包或包校验失败会阻止该股 DSH 启动，保留依赖失败原因；不会把失败研究当作增量输入，也不悄悄回退成全量调研。其他股票继续。自动重试仍最多两次，Codex 第二次成功时仅采用第二次的包；DSH 两次使用同一冻结依赖。取消时不领取等待端的启动 claim。

DSH 显式恢复继续沿用父轮冻结请求、原始量价包和框架，引用父轮已验收 Codex 包；重试、恢复不得更换事实来源或把新估值日材料塞回旧轮。预算、冷却、原有双端业务身份、共识计算及下游封口/写回格式保持不变。手工 runner 逐端执行时也受同样的前置校验。

## 事实包与独立判断

Codex 写入执行目录 `agent/shared-evidence/bundle.json`，使用 `stock-shared-evidence/v1`。包含批次、股票、估值日和输入包哈希，以及以下内容：

- `sources`：来源 ID、公开 URL、标题、披露日期、原始文件及 UTF-8 摘录的路径/哈希。
- `facts`：可回查的披露事实或管理层陈述、数值与单位、所属期间、来源 ID、精确引句及原文定位。管理层说法不升级为已发生事实。
- `gaps` 与 `coverage`：资料缺口、实际公告覆盖窗口和读取范围；保留负面事实及来源冲突。

不交接 Codex 的完整报告、投资摘要、P1/T1、预测、倍数、折扣、评级或规则适用裁决。DSH 不读取另一端当前或历史报告/价格文件，仍可使用已冻结的本端历史。关键现金、股本、估值及治理事实回读原始上下文，保留独立公告与新闻补漏、反向搜索；预测和规则适用重新论证，不为不同而制造差异。

DSH 第0节记录共享包路径/哈希，以及沿用、核验、纠错、新发现及剩余缺口。验收要求包哈希出现在第0节可见正文中；不能在隐藏注释中伪装绑定。共享事实包不能代替完整框架覆盖和既有九节报告、两价/控制验收。

运行器拒绝错误身份、未来披露日期、未知字段、缺失原件、哈希不符、伪造引句、越界路径、符号链接及非普通文件。单文件上限64 MiB、包内来源合计256 MiB，超限报错，不截断。验证后复制至 `runner/shared-evidence/`，文件只读；DSH 前后均重验，并以 `runner/evidence-dependency.json` 绑定唯一来源。保留原模型提交与运行器冻结副本，便于审计。

## 边界与验证

结构、哈希和精确引句验证只能证明字节与声明对应，不能证明摘录忠于完整原文、事实真实或文字绝无判断渗入。当前两端仍访问同一工作区；不声称具有操作系统级盲测隔离。独立搜索和语义核验仍由研究执行承担。

专项离线测试通过真实模拟 CLI 子进程覆盖同股顺序、跨股并发、Codex 失败/缺包、Codex 成功重试选择、DSH 重试及恢复、已完成 Codex 的断点接续、证据篡改、日期/引用/路径边界、可见来源绑定，以及旧冻结批次兼容。本地完整离线回归 `python -m unittest discover -s tests -v`：1189 项通过（264.250秒）；股票、期货治理结构检查及 `git diff --check` 通过。本机回环端口测试在允许本地端口的环境中完成。未启动真实付费模型研究，研究质量、实际耗时与节省 token 尚无新流程实测。

生产服务每次唤醒读取本地脚本；在空闲时应用改动，无需启动一轮研究或改写队列。已冻结的执行计划及历史结果保持原字节。本变更按用户要求提交到本地 Git；未推送或发布 PR。
