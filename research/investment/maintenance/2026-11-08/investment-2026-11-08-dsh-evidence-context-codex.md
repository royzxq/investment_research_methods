# DSH 长正文与上下文管理：证据定位、重读与引用

日期：2026-11-08（Asia/Shanghai）｜生成端：Codex｜范围：用户授权的长正文与压缩接续适配。

已实现并为后续新准备批次启用 `dsh-deepseek-flash-high-context-v1`。关键证据保存在对话之外；即使原生裁剪删除了正文中部、压缩摘要遗漏了数字和证据ID，仍能从短定位簿或持久索引找回，核原件哈希重读，再生成可检查的引用。

旧冻结批次不迁移，原补证 profile 保留作为回退。现有定时入口已经读取这份仓库配置，原05:00排期保持；没有重启服务、启动正式研究或调用付费模型。上轮体检及补证三个模块的文件哈希未改变。

## 实际行为

| 环节 | 本次实现 | 边界 |
|---|---|---|
| 原件与定位 | 原生网页、补证 HTML/PDF/文本进入持久来源索引；片段有稳定 evidence_id、页序/范围和哈希 | 自动覆盖限这些路径；任意 bash、本地文件、其他 MCP、AKTools表格不自动登记 |
| 精简上下文 | DSH required runtime context 保留短定位簿，按轮次刷新；关键标记保留主体、期间、币种、单位、披露日、反证及未决状态 | 最多显示6条，有明确省略数；完整索引可查，未知口径不补造 |
| 裁剪后重读 | find 搜索、open 按ID校验原件和片段；关键词命中可续查后续页/范围 | 命中不是已读，片段不是全文；扫描空白页不生成虚构文字 |
| 正式引用 | cite 生成原URL、PDF页码/文本范围及隐藏标记；可带一段逐字短引文 | 引用转述是否成立、日期是否适用及原披露真实性仍由研究者核验 |
| 最终交付 | runner 对最终暂存报告再查原件、引文、链接、位置及已标记的必引项 | 未知引用、改字/错页/改链接、原件变化或关键漏引阻止该次发布；未登记时记 not_exercised |
| 效果记录 | 汇总打开、主动重读、自动引用检查、生成引用及最终审计 | 不输出原文、URL或标注理由；不把机械通过记为独立事实核验 |

不改 DSH 安装包或摘要算法，也不加摘要模型调用。实现利用其原生 ToolRuntime、最终工具结果事件、required context 与提示词装配接口。源码、估值日、目录和执行解释器随尝试冻结；短簿和证据目录按尝试隔离。投资方法、价格JSON、模型及共享事实边界保持原合同。

Codex 共用技能中的取证与压缩接续原则；自动登记、原生定位工具和本次引用验收只在新 DSH profile 上运行。

## 使用与后续观察边界

关键估值输入和反证应先读原文再标记，压缩后按ID重读；不采用的证据写明原因并取消必引，未决证据保留未决。生成的引用Markdown原样进入正文，邻近文字补齐披露日、章节/印刷页码与口径。机械检查只覆盖已登记引用和已标记关键证据，不能发现所有尚未登记的重大遗漏，也不判断经济推论是否受到原文支持。

运行原件与定位簿在每次尝试的 output 目录中，清理后无法本地重读。扫描件、跨页表格、单位/负号和重述仍需原流程核页；没有新增OCR、浏览器或通用本地文件导入。尚无新版完整生产研究的成本、耗时和最终质量对照，不能把离线通过推定为研究质量或收益提升。
