## 1. 方案定位与文章取舍

建议采用“分红质量决定是否进入长期候选，估值和前瞻回报决定买入价格，分红能力及资本安全决定能否继续持有”的流程。股债利差用于比较价格吸引力，历史分位用于识别需要解释的异常；二者均不单独决定买卖。

| 文章方法 | 处理 | 对用户的实际用途 |
|---|---|---|
| 固定来源、定义、时点和符号 | 采用 | 保证跨期比较可复核，换源必须先核重叠区间和定义，不能拼接不兼容历史 |
| 股息率减国债收益率 | 采用，但分开指数历史与个股前瞻口径 | 判断现金收入相对吸引力，结合增长、资本损失与风险分析 |
| 历史分位、均值与标准差 | 降为辅助 | 展示位置和敏感性，不把高分位或两倍标准差当必然均值回归 |
| 分红来源、周期位置、现金覆盖 | 核心采用 | 识别普通分红、特别分红、融资分红和周期高点派息 |
| 与行业自身历史比较 | 有条件采用 | 同时解释盈利能力、资本结构、规则和业务结构变化；历史中枢不是公允价值 |
| 连续增派、分红贵族 | 改造采用 | 默认回看至少5个完整年度，重视连续派息和跨周期兑现；不要求每年机械增长 |
| 4%股息率红线、70%/30%分位、5.5%/6.5%定投档位 | 不直接采用 | 属特定指数/样本/个人策略参数，不能自动移植为A/H个股规则 |
| 两倍标准差自动减仓、因成长风格占优减红利 | 不作为长期收息主规则 | 可触发前瞻回报和组合复核，不因相对跑输单独退出 |
| 分批投入 | 沿用现有纪律 | 保留目标仓位预算首笔60%、预留40%，追加前重新核验；每次跌到P1不重置预算 |

本次不设置统一“高于国债几个百分点就买”或统一必要回报。现金收入目标与总回报要求是两项不同参数，用户未提供最低现金需求，先按现行方法逐股论证必要回报并披露现金收入，不能代设已被用户认可的目标。

## 2. 原文核查及需要修正的推论

### 2.1 数据不能直接合成一个当前利差

用户材料列出的股息率日期包括11月3日、6日、13日、16日，并非同日对照。本次打开[有知有行原页面](https://youzhiyouxing.cn/data/indices/000922.CSI)，正文明确分列“内在收益率4.47%”与“股息率4.86%”，页面显示截止2026-11-13。搜索摘要一度显示11月16日，本次以实际打开正文为准，并不将两种指标混为同口径股息率。

[中债官方曲线页面](https://yield.chinabond.com.cn/cbweb-pbc-web/pbc/more?locale=en_US)已核到2026-11-16十年期国债收益率1.6285%。它是曲线期限点，与某只国债的成交收益率不是同一序列。本次未取得同日、同定义的中证官方股息率及完整历史，因此不拼算一个“已核当前利差”，也不确认用户材料中的73.87%历史分位。

不同加权方式确实可能带来差异。[中证红利编制方案V1.3（2023年12月）](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/20231208175433-000922_Index_Methodology_cn.pdf)明确使用股息率加权，并有权重限制。但这不足以证明用户材料全部数值差异都来自权重：先要排除指标定义、日期、普通/特别股息、TTM/预测与税前税后差异。本次未声称已核该指数全部最新修订。

### 2.2 经验统计不等于个股安全线

已在[国信报告转载](https://www.jinguxun.com/article/news/10970969)读到“4%及两年以上正收益胜率”的对应论述；该页自述原报告发布日期2026-10-24。未取得原始回测数据和完整实验合同，无法核对样本独立性、重叠持有期、指数历史重构、费用税负和样本外表现。即使历史统计准确，它也不是任一个股未来两年获利的概率。

已打开[富国星投顾2026-11-02文章](https://caifuhao.eastmoney.com/news/20261102202445333018600)，其中确有“国债收益率减红利股息率”及均值上方两倍标准差的配置建议；它支持该方法确实存在，不证明参数对本用户的个股长期策略有效。变为正号定义后，同一高估信号对应“股息率减国债收益率”低于其均值两倍标准差。标准差带也不是股票收益服从正态分布、或反转概率已知的证据。

“红利贵族”不是统一的连续5年增派定义。例如[S&P 500 Dividend Aristocrats官方说明](https://www.spglobal.com/spdji/en/indices/dividends-factors/sp-500-dividend-aristocrats/)使用连续25年增派。可借鉴长期兑现精神，A/H候选应结合真实分配机制，不照搬名称或年数。

华泰10月27日研报本次只检索到题录与二手讨论，未核原始报告；“方法正在失效”的强结论不作为已证事实。“最好的买点已经过去”也不能仅由过去几个利差读数推出。

### 2.3 三个经济含义修正

- 高股息率与低PB可能同时由价格下降产生，不是两份独立证据；既可能代表错价，也可能代表资产质量或盈利能力下降。必须核每股分红、ROE、资产损失和现金产生能力，不能仅因价格跌出来的高息就排除。
- 无风险利率上升时，股票即使价格不变，其相对吸引力及合理价值仍可能下降。需要拆解股息、股价、国债利率三项变化，并重评融资成本与分配能力；不能说“只是债券端在动所以无需理会”。
- 股息率差不是完整股权风险溢价。在稳态DDM成立且价格等于模型价值时，`D1/P = k_e-g`，所以`D1/P-r_f = (k_e-r_f)-g`。增长、风险、期限和分配政策都会影响该差值，不能把它视为可锁定的超额收益。

## 3. 研究流程与具体交付

### 第一步：按分红机制分流

| 类型 | 核心研究 | 在长期收息组合中的候选定位 |
|---|---|---|
| 稳定经营分红 | 需求、定价/监管、维持投入、资产寿命与债务 | 可研究为稳定收入来源，不因行业标签自动合格 |
| 金融分红 | 资产质量、信用成本、资本充足/偿付能力、资产增长消耗资本 | 单列金融模块，禁止用工业企业OCF减CapEx直接判断 |
| 分红增长 | 竞争优势、再投资回报、每股盈利与分红增长、稀释 | 可兼顾收入增长；不能为追求高派息牺牲有效再投资 |
| 周期高派息 | 中周期和低谷盈利、商品价格、储量更新、库存与债务 | 保留周期模块，不能用高景气股息冒充稳定收入底仓 |

一家公司指定主要持有理由，保留必要辅助模块；类别转换要基于经营与分配机制，不因价格变化或原资格受限而换标签。同一公司仍只有一套经济预测和最终P1/T1，原风险按来源接续。

### 第二步：形成可审计的分红历史与质量判断

建议默认取至少5个完整年度、尽量覆盖完整经营周期；不足5年者不编造历史，可保留观察并说明证据较短。历史字段：每股普通现金股息、特别分配、归母利润及正常化调整、普通分红派息率、现金覆盖、必要投入、债务和股本变化、承诺与兑现、公告/除息/支付日期。金额、拆并股和归属普通股的范围统一。

质量判断分六项，逐项列“支持证据、反证、剩余缺口、结论”，不以不透明总分掩盖重大问题：

1. 生意能否持续产生现金，是否面临长期替代或不可逆衰退。
2. 利润与现金是否真实，分红资金是否可归属普通股股东。
3. 维持经营、必要增长投资、偿债和资本缓冲之后是否仍有分配能力。
4. 派息政策是否可信，资本配置、关联交易和稀释是否损害股东。
5. 正常及压力环境下的股息水平、资本安全与再融资依赖。
6. 实际交易流动性是否与计划规模匹配，信息披露能否支撑持续复核。

非金融公司可以展示“可归属普通股的正常化分配能力/普通现金分红”的覆盖倍数，并把它与同期间OCF、投入、偿债和现金存量桥接。预测增长所需投入均计入，不能只扣维持CapEx却继续假定免费增长；利息和偿债不得重复扣。低于1说明当期分配超过该口径能力，需要解释来源，不能单年机械判失败。一次营运资本波动或明确的多余现金分配与长期靠债务/增发维持普通派息分别判断。

质量研究输出三类：支持长期收息候选；有条件观察并指出缺口；不支持该持有逻辑。它们是研究结论，不额外替换现行Gate。确认造假、治理红线、偿付问题仍按现行规则；普通证据缺口先定向补证和给有依据边界，不自动把缺数据当坏事实。

### 第三步：预测可持续普通股息

默认展示未来3—5年每股普通股息和必要时更长的经营预测；期限按业务确定，这是提案工作习惯，不是已经生效的统一框架参数。

至少包含：正常化基准、与主营风险相关的压力情景、分红增长的支持条件。基准从正常化归母盈利、分配政策和实际可分配能力推导，不能只把历史派息率乘一次未来利润。金融资本限制、受限现金、少数权益、法定分配能力及股本路径均须闭合。

特别股息单列，有限寿命资产按寿命与残值估值；已除息且买入者无权领取的现金剔除。税费和币种按持有渠道处理，未知税负给条件情景，不填0。回购可以改变价值和每股数，但不能同时虚构为持续持有人收到的现金收入。

形成三个可读数：正常年度可持续普通股息、下一年预计可领取普通股息、压力情景下普通股息。下文收益率计算的D1及“下一期”均指估值日起未来12个月预计有权领取的普通股息合计，不把单次半年派息直接当全年股息；与财年预测不同的支付时间须桥接。压力值是条件结果，不承诺保底。

### 第四步：用利差辅助估值，不反客为主

建立两套分开的序列：

- **市场背景序列**：固定指数发布方的某一明确股息率定义，与同日同来源国债曲线期限点配对。A股人民币比较可采用中证发布的明确股息率口径与中债10年期；若官方只能取得短历史，报告历史缺口，不拼第三方数值制造十年分位。指数股息率不等于ETF实际现金分配率。
- **个股决策序列**：`y_forward = 下一期预计可领取且可持续的税后普通股息/当前未复权价格`；另列压力股息率。`S_forward = y_forward - 同币种、同税后比较口径的无风险收益率`。前瞻个股序列不能直接套历史指数TTM分位。

港股先确定估值及投资者回报币种：港币口径采用可论证的港币无风险基准；人民币投资者跨币种比较须把现金流转换及汇率/对冲假设说明，不能把港币税前股息率直接减人民币国债利率后称为已获补偿。

十年期国债是常用比较参考，不代表与股票现金流期限完全匹配，也不表示中途卖出国债没有价格波动。实际估值折现率仍按币种、期限、经营与权益风险论证，不能直接用国债收益率折现股息。

历史展示建议固定10年主窗口、5年敏感性；记录频率、缺失率、分位算法及样本长度，无足够历史则不报伪精确分位。用于历史检验的每一期只能用当时已披露股息和当时成分/政策，不能以后来分红预测回填。业务、分配政策或指数规则发生结构变化，分段解释，不能任意换窗口寻找有利结论。

利差变动逐项拆解：分红预测变化、股价变化、国债利率变化。高利差但分红能力下降，先下修分红预测；利差收窄但分红能力上升，重新计算回报；国债收益率下行不能无限降低绝对回报底线。70%/30%与均值±2σ仅可保留为待检验提示，本方案不授予自动动作。

### 第五步：保留唯一P1及T1

沿用canonical §4.1A/§4.1B/§4.1C/§4.1D：按适用性选择DDM、FCFE、金融PB-ROE/RIM或有限期模型，形成唯一中性V50及压力情景；不挑最高估值、不把股息现值加到完整PE/PB估值上。

基础买入参考仍为`B=V50×(1-d_base)×∏(1-r_k)`。依R22能够论证同期限、同风险口径个股与替代ETF净回报时求内部回报上限U，最终`P1=min(B,U)`。缺合适ETF预测时按现行缺口规则保留可支持估值，不凭空构造ETF收益或额外风险补偿。

推荐分别报告两种替代比较：行业基准用于解释经营和相对表现；风险相近、可投资的红利组合用于收入和持有替代分析。将后者正式替换R22主基准属于待采纳方法变更，不能静默生效。指数股息率、ETF派息率和ETF预期总回报三者不混用。

若用户未来明确最低净现金收入率`y_min>0`，可增加内部现金收入约束`C=D1_net/y_min`，作为研究方案扩展，与既有支持的上限取交集；只保留最终一个P1，C不是第二买入档，也不以C替代企业估值和压力分析。当前未给y_min，故不启用该约束。若需要落入现有审计，需先论证与d_base/R22的归属及去重，不直接新增连乘折扣。

T1沿用合理价值上沿附近的价格复评起点。对长期收息者，达到T1后核现价对应前瞻回报、未来分红能力、换仓成本、税费与组合风险；不机械清仓。利率、减派和资本恶化若已计入现金流或资本成本，不重复扣价。

### 第六步：买入、追加和持有分别决策

| 研究事实与价格状态 | 研究建议 |
|---|---|
| 质量支持长期收息，价值可估，但现价高于P1 | 保留候选，等待价格或基本面变化；不是公司质量否决 |
| 质量支持，现价不高于P1，全部新增资格与组合条件满足 | 可评估按预算建仓，价格到位本身不构成交易执行 |
| 股价下跌，同时预计普通股息明显恶化 | 先重估分红及P1，不能用旧股息率自动追加 |
| 价格波动或短期跑输，分红能力及资本安全保持 | 按既有条件继续持有研究；短期相对表现不单独触发退出 |
| 一次减派或暂停 | 分析特别股息结束、时点变化、周期预期内波动、合理投资或结构恶化；不一刀切 |
| 持续经营分配能力实质受损、资本/治理逻辑失效 | 按证据限制新增并形成相应减仓/退出要求，不等待T1 |
| 前瞻回报明显不足或组合集中风险过高 | 即使仍按时分红，也评估减仓/置换，计入税费和替代风险 |

继续持有的经济比较使用当前市值和未来现金流，成本股息率只作历史记录。收到分红后重新评估是否投入原公司、其他合格候选或保留现金，不默认无条件再投原股。组合同时监控市值权重和预计股息贡献，防止低市值权重的周期股承担大部分现金收入；还要按银行信用、资源价格、监管定价、利率和币种归并风险。

## 4. 持续维护与每份报告模板

建议年报后全面复核，半年报复核分红覆盖与资本需求，季报核关键经营变化；分红方案、重大投资/收购、融资、监管资本变化、债务压力、审计或治理事件即时复核。每月可以刷新股价、股息率、利差和估值位置，避免每次价格波动都重写经营预测。这是研究频率建议，本次不更改自动调度或七天冷却。

## 5. 算术演示：为什么要看普通股息

以下全部为假设示例，非当前公司报价或推荐门槛。某股价格100元，过去一年派6元，其中2元是特别股息；研究判断下一期可持续普通股息为4元。忽略税费的演示口径下，历史总股息率6%，下一期普通股息率4%。若压力下普通股息3元，则压力股息率3%。假设同币种国债收益率2%，相应前瞻与压力利差为2及1个百分点。不能用6%与2%的差4个百分点证明长期现金收入优势。

再假设用户已明确要求4%的同口径现金收入，C=4/4%=100元；基本面与安全边际支持B=90元、总回报约束U=85元，则最终上限为85元。C只是额外约束，没有让报价从85元升至100元的权力。若y_min未确定则不计算C，仍按既有规则计算P1。上述B/U是假设输入，未暗示任何真实估值。
