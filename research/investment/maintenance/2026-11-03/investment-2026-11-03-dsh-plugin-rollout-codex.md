# DSH 首批工具隔离测试与接入记录

日期：2026-11-03，北京时间。生成端：Codex。接续用户授权的首批方案；不修改股票投研方法和现有验收流程。

## 结论

本轮选择 **官方 Search API + 原 HTTP Fetch + 按需 AKTools**。Search API 的主要收益是省去辅助模型搜索链路的等待，并提供发现用摘要。AKTools 的收益是将结构化历史财务一次取回，仍需原始公告核对。Fetch API 本轮样本不通过，暂不切换。没有为普通页面增加常驻浏览器。

| 组件 | 实际验证 | 结论 |
|---|---|---|
| 日志统计 | 回算 32 次尝试，成功样本与前次审计完全对齐；包含失败、重试、子代理、usage 缺口和 shell 非零退出 | 接入每次 DSH 尝试的旁路汇总 |
| Search API | 6 个查询 × 2 轮 × 新旧两路，共 24 次真实 provider 调用；另做两次真实 DSH 集成调用 | 通过，供新批次默认搜索 |
| Fetch API | 5 个 URL × 2 轮 × 新旧两路，共 20 次调用 | 候选有正文 2/10；基线非空响应 6/10 但均无实质正文，不支持全局替换 |
| AKTools | 工具发现/描述、11 次取数（含缓存及分页）、两个新进程复测、DSH 实际工具调用 | 通过，按需补数，不提高其证据权威 |
| 浏览器 | 本次未安装/验证；原 HTTP 样本存在截断缺口，PDF 走现有原件/PyMuPDF 路径 | 困难 HTML 需完整下载或定向浏览器补证，不能据 HTTP 返回成功判断已取证 |

## 对照设计与结果

调用当前安装的 DSH **0.2.1-rc.2** 导出的真实 provider，而非另写一套类似接口。测试前固定查询、URL、报告期、选择标准及原件摘要；两轮交替新旧顺序，保留全部有效响应和失败。第一版驱动的凭据解析器误用同步返回，未发出认证请求；该轮保留并标为无效，排除在效果统计之外。

查询覆盖比亚迪、洛阳钼业、中国联通、中远海控、赤峰黄金的财报发现。Search 基线/候选均成功 12/12，中位耗时 **7.00 秒 → 0.9485 秒**。11 组 URL 集合完全相同，余下一组仅同一新浪研报编号的 URL 别名不同。基线映射结果本次没有 snippet，候选 120 条结果均有 snippet，中位 116.5 字符。摘要只用于发现，不能据此认定原文已读或事实已核。

DSH 集成小测试均只调用一次搜索，输出相同前三条来源。旧/新工具调用耗时 6.546/1.036 秒，全次 15.57/9.31 秒，均完成 JSON 回执。这不是完整个股研报的随机对照，不能将单次搜索降幅外推为整篇投研提速或费用降幅。

Fetch 的 5 个 URL 为比亚迪 HKEX 和巨潮 PDF、两类 IEA HTML、香港银行公会汇率页。候选仅汇率页两轮取得有日期/单位/表格的正文，其余返回 HTTP 404；原 HTTP 两份 PDF 报“不支持内容类型”。**复审纠正：原 HTTP 的三个 HTML 两轮虽然都是非空 200，但都在 100,000 字符截断，剔除脚本/样式/导航后仅余标题或搜索入口，没有实质正文。此前 6/10 是返回成功率，不能当成正文取得率，更不能据此声称原路径更有效。** 质量核验和原始文件哈希见复审记录。

因此保留现有完整下载、原件哈希及页码核验路径；普通 web_fetch 出现截断也必须继续补证。Fetch API 可作为汇率页的定向补充候选，本次覆盖不足以支持全局切换。浏览器未测试，不能据这些截断响应判断无需浏览器；亦不能据 5 个 URL 断言 Fetch API 在所有网站无效。

## AKTools 数据核对

版本固定为 **AKTools 0.1.4 / AKShare 1.20.22 / MCP 2.3.0**，独立 Python 3.11 venv，60 项依赖及关键服务文件摘要已锁定。测试实际通过 stdio 的 `search_interfaces / describe_interface / get_data`，不是模拟 MCP 回包。

比亚迪 A 股返回 75 行、洛阳钼业 A 股 67 行历史利润表；比亚迪 H 股利润表为 2,061 行。通过 1,000/1,000/61 三页收齐，按报告期/科目检查无重复。`truncated` 在末页仍为 true，只表示该页不是整表；终止条件已写入生产工具提示。

抽查 2026 年前三季度 8 个金额：比亚迪 A 股收入/归母/扣非归母，H 股收入/股东应占溢利，以及洛阳钼业收入/归母/扣非归母。全部与已经核哈希并重新读取的原公告页面匹配。比亚迪使用人民币元；洛钼原公告以人民币千元列示，转换后允许每项 500 元的四舍五入差异。港股接口没有币种字段，币种来自原公告，保持这个来源区分。

- 原件：[比亚迪三季报，第 2 物理页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/1029/2026102900816.pdf)、[洛阳钼业三季报，第 3 物理页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/1023/2026102301163.pdf)。原件路径、SHA-256、字段逐项核对见 evidence。
- 首次 A 股调用 41.8/43.9 秒，新进程比亚迪复测 25.5 秒；港股新进程调用约 3 秒。同进程重复/分页主要命中 60 秒缓存，不作为独立可用性样本。
- DSH 实际调用描述和取数，返回 `total_rows=2061 / returned_rows=5 / truncated=true`，首项营业额 566,303,672,000 元；最终隔离启动参数复测通过。

本轮没有证明 AKTools 全部接口和全部字段正确，也没有证明它比现有每条取数脚本都快。接入范围是按需历史补数；完整方法、共享事实优先级、原公告核验及缺失保持未知的规则照旧。

## 日志与运行边界

历史窗口为 2026-10-29 至 11-03，共 32 次尝试，26 成功、6 失败、5 次重试。成功部分 3,604 次工具调用、148 次 web_search、381 次辅助搜索请求、55 次 shell 非零退出，与前次审计一致。全窗口包含 223 次搜索、548 次辅助搜索请求、69 次 shell 非零退出，不能只计成功研究。

统计只从持久化 session 日志计数，避免与 CLI 投影双计；包含裸 UUID 目录中的子代理。Usage 按同一步替换、实际重试另计，缓存输入独立。缺 usage、未返回工具结果、异常行、无主会话都保留缺口。费用为 null，不将不完整记录换算为“真实账单”。工具时间可能重叠，不与整次墙钟相加。

每次执行结束生成 `runner/dsh-metrics.json`，统计异常不改变研究验收。AKTools 日志与 cwd 隔离到该次尝试目录；API 密钥不写入汇总或配置。测试时发现 AKTools 默认会在 cwd 建日志，初次文件已迁到测试目录，最终生产/测试驱动显式指定隔离 cwd。

生产使用新 profile `dsh-deepseek-flash-high-tools-v1`；原 profile 保留可回退，新配置只影响新准备批次。模型、推理强度、两席位身份、股票框架、共享证据、验收脚本和调度时间均不因本次改变。旧冻结计划和重试不得追补新工具配置。

## 验证与材料

生产配置已启用 `dsh-deepseek-flash-high-tools-v1`，预检通过。以实际历史批次验证：旧 execution plan 字节/哈希未变且仍无新 tools 字段；同一请求的新计划预览包含新组合，Codex profile 不变。现有 launchd 使用该配置路径，核验时未运行，无须修改或重启定时服务。

完整离线回归在宿主环境 **1,306/1,306 通过**（259.568 秒）；最终 DSH 定向套件 **51/51 通过**；股票框架结构检查通过。首轮沙箱回归的 45 个错误来自本地 mock 端口或 `ps` 权限，已由完整宿主复测消除。方法正文与 4 个共享验收/输出脚本逐字节匹配 HEAD。结构检查不证明所有财务事实或投资方法有效；本轮没有强制启动正式股票研究。
