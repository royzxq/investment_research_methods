## 3. 修改说明

### 问题、经济依据与采用范围

直接按 ETF 成分身份加价会混合可投资性、资金价格冲击和企业合理价值；直接按历史跑赢奖励又可能把更高行业风险、估值上涨或已经进入盈利预测的优势重复计算。因此，新方法分别处理经营价值、未吸收的交易风险和投资替代选择，并让每次变价落到明确证据与唯一计价位置。

操作定义以 canonical §6.6 为唯一权威：所有 A/H 个股包括非成分股均回答；基准及窗口预先确定、同口径含分红比较；日期/覆盖/来源和未知项显式保留。身份本身和历史涨跌均不自动调价。交易改善只能减少有证据支持的原属折扣或改善容量；经营/持续融资成本变化足以修订假设才重算 V50/T1。没有统一 ETF/alpha 奖罚或固定额外收益百分点。

前瞻机会成本只在期限、现金流、ETF预测、风险可比性及收益要求足以论证时量化。内部上限 U 与 P1 同币种/股，含买入费用的总支出不冒充报价。最终取原 P1 与 U 中更严格者，仅把尚未满足的要求归入已有 `d_base`，原五项折扣及公式保留。内部变量不是新增买卖档，不创建 `r_etf`、`r_alpha`。费用、分红/留存、已折现价值和残余风险逐项防重复。

输入缺口不填0、不制造固定罚分或全市场冻结；依赖未证优势的买入论证仍按适用范围受限。既有风险必须凭自身证据解除；单纯现价/回报不足属于运行时价格判断，不造永久研究冻结。持仓相对优势下降可独立复评，但不机械下调 T1 或因短期跑输退出。

### 正反与边界场景

以下数字仅为算术演示，不是新增方法参数。场景判断由主代理对照两份正文逐项审阅，算术另由 Decimal 核算；不是收益回测，也不是自动交易引擎测试。

| 场景 | 应有结果 / 防止的误判 |
|---|---|
| ETF 新纳入，仅有身份变化 | P1/T1 不变；拟纳入不能当已生效持仓；不自动授予买入资格 |
| 非成分股，但交易容量充足 | 不因身份扣分，仍执行正常经营/风险研究 |
| V50=100、基础折扣20%、原独立交易风险折扣5%，风险实证解除 | P1从76恢复至80；若T1原为110且价值不变，T1不动；最多解除原风险 |
| 原交易折扣为0，仅交易更活跃 | 不造负折扣奖励；容量/执行可单独改善 |
| 盈利改善已进入旧模型，同时历史跑赢 | 不能再提升倍数并减折扣奖励同一影响 |
| 盈利假设确有新增上修，或只是倍数扩张 | 前者重算价值后确定两价；后者不提高价值来追认涨幅 |
| 两年末价值100、分配折至期末6、h=15%，原P1=85 | U≈80.15，P1收紧至80.15，示例基础折扣约19.85%；T1不因机会成本改变 |
| 原折扣已将P1压到72，内部U=80 | P1仍72，不再乘一次U/B，也不反向放宽 |
| 上期已有R22机会成本残余，本期重做研究 | 从有来源的基础折扣与R22残余拆分接续，不逐轮累计；新证据支持原残余减小时可重算，但不高于本期基础P1，缺依据不得归零 |
| U恰等于B，或U高于B | 等号满足该回报条件；P1保持B，其它Gate仍独立 |
| ETF预期回报为负 | h仍不低于有依据的正绝对回报底线；不能据此放宽原P1 |
| 有买入费、现金分红与再投资假设 | U按含费净现金流反解每股报价；已扣费用不重扣，已分配利润不重复留在期末价值 |
| 只有价格指数、短历史或风险暴露不可比 | 保留局限，不声称含分红比较或持续alpha已验证 |
| ETF预测/选股要求缺少依据 | 机会成本未量化；原估值可继续，依赖该优势的买入论证保留相应限制，不自动全局冻结 |
| 原公司不可估或已有Gate冻结 | 本条不恢复资格；仅原规则允许的冻结观察价可继续，既有风险不因身份/跑赢解除 |
| 无有限正可行价格或原正值桥不适用 | 不产负价、不用负折扣或≥1折扣凑报价；停止相应量化桥并说明 |
| 元研究只有ETF规模上涨、缺申赎拆分和可比样本 | 记假设/unknown，不声称净流入或因果流动性改善，不预填个股调价幅度 |
| 老元研究报告没有新增两个上下文字段 | 标当期未研究，保留其它有效证据，不补造历史或强制重跑旧报告 |
| 单阶段元研究 / 变化检测 | 前者仅研究，后者分类交接；均不直接改价、自动采纳方法或执行公司研究 |

### 元研究与变化检测的适配

需要适配。原入口覆盖“资金行为与市场风格”，但没有要求拆分 ETF 净申赎与规模变动、控制指数选样导致的流动性差异，也没有规范可供个股复用的含分红基准和前瞻假设。

已新增 `ETF_LIQUIDITY_CONTEXT` 与 `BENCHMARK_CONTEXT`，保留原七变量。前者记录资金/流动性事实、覆盖、反证与传导，后者记录基准/替代ETF、窗口、风险/成本口径和可论证的前瞻研究输入。没有要求每周对所有股票建面板或计算 alpha；重大判断才要求相应可比证据，没证据则明确不能验证。

变化检测将真实申赎/实际流动性变化归状态输入，错口径归证据纠错，新增阈值/奖罚/方法归方法变更；新证据最终交个股按 R22 核算。旧冻结方法尚不含 R22 时先记方法兼容/待适配，不能假定自动生效。

### 研究依据与限制

本次沿用本聊天此前实际打开的原始来源，不新增市场数据采集：

- [SEC ETF 运作说明](https://www.sec.gov/investment/exchange-traded-funds-small-entity-compliance-guide)：申赎篮子与二级市场交易的区分支持资金口径核验。
- [S&P 2021年指数纳入效应研究](https://www.spglobal.com/spdji/en/research/article/what-happened-to-the-index-effect-a-look-at-three-decades-of-sp-500-adds-and-drops/)：历史纳入效应并不随被动资产规模机械增强；不能外推为当期A/H收益规律。
- [Ben-David 等，2018](https://onlinelibrary.wiley.com/doi/10.1111/jofi.12727)：作者摘要所述ETF套利冲击与股票波动机制支持双向风险检查，未据此设定A/H风险折扣。
- [CFA Institute Research Foundation，基准与收益归因](https://www.cfainstitute.org/sites/default/files/-/media/documents/book/rf-publication/2018/rf-v2018-n1-1.pdf)：区分历史与预期alpha、风险可比性及含分配回报。

R22 的机会成本公式是本次明确采纳的研究决策方法，不是上述论文已证明能提升收益的策略；需要在后续公司研究中检验假设、成本和预测敏感性。可能增加的局限是基准/前瞻预测误差导致过严买价与错过机会，故禁止填入无依据收益，保留未量化分支及原有估值路径。
