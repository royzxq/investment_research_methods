## 1. 核验结论及边界

1. **真实 PE 的纠错可以完成，现金经济价值的点估计尚不能完成。** Codex 原模型真实倍数为 12/15/18，利润分别为 18.785000／26.295555／39.556800 亿元；它把同一 77.839774 亿元权益加项除以各情景利润后塞进 PE。恢复为真实 PE 加独立权益调整，三情景的总价值和每股价值保持不变。该重编码在当前固定输入上算术等价，但编码会混淆倍数与现金，不能作为现金加项合理性的证据。
2. **DSH 全排除募资的论证不能被现有原文支持。** “13.5 吨技改资金正来自此次募资”没有逐项目金额及支付时点桥；H1 已有旧 IPO 的境内扩能余款及在建技改，9M 购建支出发生于本次发行前。新募资 50% 用途明确是海外项目，不足以证明吉隆、五龙、华泰等境内技改全由本次融资承担；另外 20% 并购与 30%一般用途亦不能一并视为已计产能或已损失。
3. **Codex 将扣补偿后约 77.84 亿元全加，也只能是条件情景。** 13 吨有 2026 年目标与恢复工程作方向依据，不能推出 2027 年达到该销量的剩余投入为零；14.7 吨的项目闭合更弱。已知项目、资本承诺和 Q3 仍在建说明“以后无需新增付款”没有得到证明。资金尚未使用也不等于全可分红，未来花掉也不等于价值归零。
4. **两端均未计本次新增资金的利息收入；本次没有查到本金与其新增利息被同时资本化的数值证据。** 两端期间费用含旧现金利息抵减，但新资金 10 月才到账、利润锚来自 9 月前。旧现金未另加回时不能机械再剔除旧利息。若后续改成总现金桥，须另拆旧利息收益。
5. **不得把条件敏感性冒充修复后的可靠报价。** 当前可以交付资金事实、两端模型还原、反证和有金额锚的条件测算。缺少 11/12 实际未用款、付款承诺滚动表及产量—项目—投资映射，不能可靠裁决应加回的唯一金额，也不能证明两个端点就是完整合理价值上下界。资格缺口不因表示纠错而解除。

以下仅使用 Python 标准库，可粘贴运行；未写运行文件。已实际执行 Decimal 重算，与两端原表及现金折算一致。

```python
from decimal import Decimal as D
N = D('22.11313909')
A = D('91.8') * D('.85643') - D('.7805')
rows = [
 ('codex-low',  '12','850','430','15','3','.075','7','1.5','.35','.80','12'),
 ('codex-base', '13','900','420','16.5','4','.075','6.8','1','.34','.82','15'),
 ('codex-high', '14.7','1000','400','18','5','.08','7','1','.33','.82','18'),

 ('dsh-high',   '15','900','385','18','7','.072','7.3','0','.34','.82','18'),
]
for name, *args in rows:
    q, p, c, r_other, gp_other, t_rev, opex, fin, tax, owner, pe = map(D, args)
    rev = q*p/100 + r_other
    gp = q*(p-c)/100 + gp_other
    profit = (gp-rev*t_rev-opex-fin)*(1-tax)*owner
    original_A = A if name.startswith('codex') else D(0)
    print(name, 'revenue', rev, 'profit', profit, 'real_PE', pe,
          'adjustment', original_A, 'equity', profit*pe+original_A,
          'V', (profit*pe+original_A)/N)
    if name.startswith('codex'):
        encoded = pe + A/profit
        assert abs(profit*encoded - (profit*pe+A)) < D('1e-20')
    if name.endswith('base'):
        for K in map(D, ['0','4.369125595','7.011705595','39.310137','77.839774']):
            print('conditional', name, 'K', K, 'V', (profit*pe+A-K)/N)
```
