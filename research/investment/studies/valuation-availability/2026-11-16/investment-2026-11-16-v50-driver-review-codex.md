# 三股 V50 基准价差复核

估值日及可用事实截止沿用 2026-11-16 原研究。复算六份报告正式 FCFF 基准及权益桥。三家公司主要分歧各不相同。立讯是折现率和终值利润路径，中芯是退出扩产期的时间和净投入，海光是持续高增长的年数及同年收入。已查实的现金或投资压力支持留意风险，至于压力持续多久，两端有不同程度的外推。

上一份对照把立讯和海光的现金回收速度笼统列为价差成因。逐年现金流显示，2027–2033 共同窗口中 Codex 两只扣的新增营运资本绝对额都更少，反而抵消了一部分价差。对周转强度的判断仍有分歧，需要与收入规模和起点口径一起解释。

- **现金回收**。Codex 基准在 2026Q4 模拟回收营运资本约 86.36 亿元，将估值日前后流量分列。2027–2033 只再扣 282.74 亿元，DSH 扣 446.83 亿元；这一项使 Codex 估值相对高约 1.62 元/股。两条路径分别押注不同的回收时点，Q4 的季节性释放仍需年报确认，不能把这只的价差归因于 Codex 回款更慢。
- **终值和折现**。g 都是 2%。2033 收入 6,620 / 7,459 亿元，稳态整体 EBIT 率约 5.42% / 5.79%，通讯分部 10.0% / 12.5%，稳态有效现金税约 19.1% / 15%。终值首年 FCFF 254.52 / 313.09 亿元。两端的产品组合和规模效应各有经营依据，但精确稳态值缺独立核验。Codex/DSH 终值 IC 是 2,078 / 3,058 亿元，DSH 的四个 IC 可由末年 NOPAT÷12% 精确复现，仍有待与其显式投入轨迹交叉核对。此项反而压低 DSH 估值，不能视为 DSH 所有参数均更乐观。
- **最值得质疑的保守叠加**。WACC 9.0% / 7.5%，是最大的单项差异。只把 Codex 9.0% 改成 7.5%，保留全部现金流及权益桥，31.15 变 41.92。Codex 以回款和资本密集度支持 9%，这两项已在显式现金流体现，额外 150bp 中有多少对应独立的系统性风险没有量化。DSH 7.5% 有权益／债务成本写法，Beta、ERP 和低边际融资成本同样是代理。现有证据不够选定一边为正确。优先核对共同资本成本锚，再评估高投入、较低终值增长兑现与 WACC 的联合依据。

### 有依据与尚无充分依据的部分

- **先统一范围**。Codex 对全资与非全资组做经济份额加权后折现，DSH 折现集团再扣 881 亿元账面 NCI。以下投入对照还原 Codex 到集团。2027 起两套净 CapEx 几乎相同（60.13 / 60.00 亿元）。真正分歧从 2029 后扩大：Codex 2033 CapEx 763.81、D&A 629.39，净支出 134.42；DSH 为 325、435，净支出 −110。七年累计集团 CapEx 4,772.60 / 2,635.00，D&A 3,517.64 / 3,030.00，净支出 **+1,254.95 / −395.00**。这不是少数股东口径造成的差。
- **投入证据和过度延伸**。三季报在建工程约 626.52 亿，半年度已签约未拨备承诺约 410.13 亿，2025 年购建付现约 599.51 亿。它们支持中期高投入不能省略。DSH 假设 2029 年起 CapEx 每年低于折旧，2033 净固定资产/收入降至约 1.28 倍，较 2026 年约 2.6 倍改善很大。Q3 利用率已 97.3%，后续需要结构提价或资本效率跃升。Codex 的反向外推也偏重：假设资本强度七年末仍为 2.20 倍，使 2029–2033 年年 CapEx 716–796 亿元，超出近期可核披露的预测长度。用 Codex 自己的折旧与资本联动规则将 2.20 降到 2.00 倍，V50 为 13.53；降到 1.80 倍为 15.46。两项是敏感性，支持复核资产效率，不能据此指定新基准。
- **现金回收**。Codex 用 30% 存量 NWC/收入和期初 250 亿，DSH 用新增收入约 12% 作为新增占用，计量方式不同。中芯集团七年 ΔNWC 226.57 / 69.60 亿元；审计归母路径下替换 ΔNWC 的机械影响约 0.73 元/股。Codex 自身 NWC 比率改为 25% 后，V50 为 12.24。这里的差远小于净扩产投入。归母及集团 CFO 不能简单替代建模的自由现金。设备应付在 Codex 从开账权益桥扣一次，DSH 的支出采用另一现金假设，需统一付款基础再比债务。
- **终值与归属**。两边 WACC 同为 9%、g 同为 2%。集团 2033 收入反倒是 Codex 更高（1,589 / 1,417 亿），所以“Codex 给更低收入”只在加权归母口径看起来成立。Codex 首年核心 EBIT 率 15.36% 对 DSH 18%，Q4 毛利率指引从 Q3 实际 29.9% 降至 26%–28%，而且两边纳入其他经营收益的定义不一致，方向有依据，精确差额仍应以同定义复核。Codex 基准让非全资组收入份额从 58% 到 65%，母公司只取 48.5% 经济代理；若份额维持 58%，V50 约 12.92，若母份额取公告所示区间中的 66.45% 情景，约 12.67。两端不能把账面 NCI 或一季损益占比直接当长期现金索取权。大幅 V50 差异主因是净投入和显式回收，非 WACC；Codex 保守之处是重投入、较高资金占用和更多非全资组合共同落在基准，其联合轨迹尚缺分厂投产、收入和付款证据。

## 对框架的判断

框架 §4.1D 已明确要求中性经营路径，要求联合依据才可把多个不利假设同时纳入基准，R18 的折扣上沿也主要约束 P1。现在的问题在执行和验收：v9 对空价设了强制复核，对有价报告的基准中性只有说明字段、来源状态和算术校验。它未要求先在同一资产和权益口径下核对固定资本到期末 IC 的滚动，也未检查较弱现金回收、较高 WACC 和 P1 折扣是否依赖同一风险。提示里的“保守边界”对探索下行有效，但不能替代基准参数的双向论证。新版部分减少了拒绝，仍可能把有依据的偏下沿路径标成中性；同样也允许 DSH 给出缺少联合资本支出依据的乐观路径。

若只挑三项复核：立讯统一可比 WACC 再查风险是否累计、中芯要求双方用同一集团资产台账做扩张和维护闭合、海光将同年增长收敛和周转口径分别对照。保留已核投入压力和现金占用，只有新的反证支持才收窄参数分歧。两端结论来自不同模型与运行流程，替换复算说明分歧对数值的作用，无法单独识别框架的因果效应。
