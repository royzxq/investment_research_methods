## 3. 修改说明

### 修改项1

- 模块：参数映射·负反馈修复型 + 决策原则·买入结论条件
- 对应上层变量变化：PRIORITY_MECHANISMS（负反馈修复型状态：启动确认→运行确认·资金面维度）+ TOP_MISTAKE_TO_AVOID（换面为"位置低≠证据硬"）+ MAIN_CONTRADICTION（矛盾焦点转向扩散质量与量能）
- 原内容问题：条目停留在"启动确认（2026-08-08）+ 等待第二周验证"，第二周验证已达成但状态未推进；执行期三纪律针对"成长单边修复"形态制定，未覆盖本周出现的高低切换扩散形态——低位补涨标的的承接标准存在空白，存在把"位置低"误当承接依据的风险
- 修改方式：状态推进为"运行确认·资金面维度（2026-08-15）"，写入形态注记（承接载体扩散为"低位价值+中报受益线"轮动、科创高位分支筹码消化）、缩量注记（存量轮动、确认≠增量牛市、仓位不放大）；执行期纪律由三条扩为四条，新增 d) "位置低不构成承接理由"；买入结论条件的负反馈修复/高低切条目同步补入该纪律；回退条件与报表覆盖面终局判定继续在册
- 修改原因：上期显式预设的验证路径如期兑现，不推进状态则框架滞后于自身预设机制；高低切换是本周新出现的市场形态，原纪律未覆盖
- 预期作用：承接执行合法性增强的同时，把承接标准锚死在"位置+证据"双重校验上，防止在扩散轮动期把无业绩低位股误纳入承接范围，防止缩量存量轮动被误读为增量牛市而放大仓位

### 修改项2

- 修改方式：权重表改写（高=负反馈修复；中高=稳态现金流/周期反转/事件驱动；中=正反馈/供给冲击）；稳态现金流条目改为中高权重并注明兑现路径；状态标记更新为"拥挤回吐尾声（钝化）（2026-08-15）"；底仓锚定位、红利拥挤度护栏实战适用、对称纪律原文保留
- 修改原因：这是反摇摆纪律的正确出口——上周拒绝单周信号降权并显式挂账复核条件，本周条件达成即兑现，避免"永远不调"与"每周乱调"两个极端

### 修改项4

- 模块：参数映射·周期反转型 + 正反馈强化型（存储量价锚）

- 预期作用：涨价链标的的机制归类判断有据可依；存储链标的既不因单例过早放松、也不因审慎标记误杀已兑现个体

## 4. 不应过度反应的部分

- 1. 运行确认不等于增量牛市确认——成交缩量（2.66→2.15 万亿）表明本轮是存量高低切换，承接仓位与 cap 参数不因"运行确认"放大；正反馈强化型维持低位/中权重不动（量能收缩是其直接反证）。
- 2. 稳态现金流降权至中高不是看空红利——底仓锚逻辑（低利率+险资配置+政策呵护）零变化，降的只是"防御主导"语境溢价；对称纪律原文保留，不得因降权触发底仓减配。
- 3. 油价升温但 100 美元条件未触发——次级宏观风险定位不变，只提高监控优先级；不因单周约 +10% 把油价升为一级约束（升级条件明确在册，触发即执行）。
- 4. 9 月 FOMC 前不预判结果——54.1% vs 45.9% 近似掷硬币，紧缩一级约束、硬阈值、隐含降息压测全部原样保留，等 Jackson Hole 与会议落地。
- 5. 中报早期"超 75% 正增长"有幸存者偏差——230 余家样本不足以外推全市场，"大面积兑现"终局判定必须等 8 月下旬高峰；正反馈结构阿尔法门槛与存储量价锚审慎标记均不提前放松。
- 6. 科创/半导体高位筹码消化不触发已验证龙头的减仓——"主线消化≠主线终结"纪律适用，回调定性仍以 capex/订单证据为准。

## 一、分析流程

### 0. 决策原则（Global Rules，保留）

- **Price Map 是最终产品**，所有模块必须回到 P1/P2/T1/T2。
- Gate 仅三种：**通过 / 冻结 / 否决**；冻结 = 禁止新开仓，且必须给出解除条件。
- 结论用区间和分档，不做伪精确。
- 折扣集合 `r_k ∈ {chip, v5, gov, terminal}`，乘法叠加。
- 允许输出「观望 / 回避」，不得强行给买入。
- **必须先做 Precheck Gate**，不通过不得进入估值与 Price Map。
- 买入结论至少建立在以下之一：
  - 盈利兑现
  - 盈利兑现 + 供给出清（反内卷 → PPI 转正）
  - 政策重估（反内卷 / 产业政策） + 盈利兑现
  - AI 成长主线：盈利兑现 + 海外 capex ↔ 国内在手真实订单联动验证通过
  - 负反馈修复 / 高低切：低估值 + 修复证据（利润率修复 / 去库 / 订单恢复 / OCF 转正），经「盈利兑现链」验证。【本次更新】高低切换承接中**「位置低」本身不构成买入条件**——低位补涨标的须与中报受益线重合并逐股经盈利兑现链验证，无业绩的纯位置补涨股排除在承接范围外
- **纯资金面 / 流动性 / 存款搬家叙事不构成买入条件，也不作为加分项**（宽松流动性 ≠ 买入）。
- **海外流动性紧缩体制为一级硬约束**：持续紧缩（沃什转鹰 / 美国 CPI 破 4% / 点阵图预期加息 / 降息预期归零）是高估值成长的带阈值硬约束。判断主轴 = **盈利能否对冲估值压缩**。本项不把流动性作为回报来源，而是把紧缩作为压缩风险纳入约束。
- **隐含降息前置否决检查**：每只高估值成长标的压测「当前估值是否隐含降息扩张」。若估值依赖已证伪的降息叙事（隐含降息 + 降息预期已归零 / 转加息），作否决式处理，不给买入型 Price Map。
- **追高否决三重过滤**：同时满足三项 → 追高否决（只给跟踪价位、禁止追高新开）：① 拥挤度：公募持仓分位 ≥ 88% 或 板块换手率分位 ≥ 95%；② 估值分位：PE/PB 分位 ≥ 80%；③ 近端业绩：无当季/次季可见业绩，仅远期空间。边界澄清（2026-08-08）：三项须**同时成立**方触发；超跌真成长经深度回撤后，估值分位与近端业绩两项通常已不再命中——本条不得被误用为对"有正式中报硬证据的负反馈修复承接"的机械封锁；修复启动期单周急涨的标的须重新逐项过滤。
- 不得用「政策支持 / 赛道景气 / 远期空间大」替代财报季验证。
- 高估值 / 成长股优先验证：**利润兑现、订单转化、经营现金流质量**。
- AI / 算力 / 应用映射若缺乏真实客户、订单、回款、现金流，不得给完整买入型 Price Map。
- **紧缩下独立成立性检查**：必须判断在持续流动性紧缩 / 无降息 / 估值压缩情景下逻辑是否成立，核心是盈利能否对冲估值压缩。不成立 → 冻结；部分成立 → 不给激进仓位与完整买入型 Price Map。
- **双轴定位强制项**：每只个股同时定位 (a) 主线归属与双韧性（既能脱钩海外 capex 波动 = 盈利端韧性，又能在估值压缩下靠盈利兑现存活 = 估值端韧性）；(b) 拥挤与筹码结构现状（含国家队动向）。两维度都不利者，原则上不给完整买入型 Price Map。
- **滚动事件窗口强制项**：每只个股对当前在册窗口给出前后预案。在册窗口（美联储 / 流动性为一级）：① 美联储议息 / 流动性窗口（沃什路径、美国 CPI、点阵图与降息预期、费半 SOX 行为；【本次更新】当前重点 = 9 月 FOMC（CME 维持不变 54.1% vs 加息 45.9% 的分歧收敛路径）+ 8 月下旬 Jackson Hole + 美国 8 月 CPI——7 月 CPI 已于 8/12 落地：同比 3.4%/核心 2.5%，符合预期边际降温；油价成为通胀再输入变数（布伦特 8/11 盘中破 90 美元、霍尔木兹谈判僵局、IEA 供应短缺警告），缓和确认待落地 ≠ 紧缩体制解除）；② 海外 AI 大厂 capex / 财报指引窗口；③ 国内反内卷政策落地 / PPI 数据窗口；④ 公司财报窗口（AI 标的重点为中报；【本次更新】当前重点 = 8 月下旬中报高峰终局判定——预告→报表兑现率与覆盖面能否扩大到板块层面：早期证据正向（截至 8/12 已披露 230 余家中超 75% 净利正增长、存储龙头正式半年报兑现首例落地）但先披露者偏优质、存在幸存者偏差，终局判定必须等高峰落地；AI/科技标的以正式中报 ROI 验证——AI 相关收入、订单、OCF 兑现——为第一核验项，业绩预告不替代正式报表）；⑤ 国内重大政策会议窗口（中央政治局会议、中央经济工作会议等，会前 48h 冻结新开仓纪律同等适用）。
- **主线消化 ≠ 主线终结**：仅适用于「已验证近端业绩的主线龙头的减仓判断」——单周/单日回调不自动触发减仓或 T1/T2，须先用「海外 capex 指引方向 + 在手真实订单」对回调定性。本条不得作为对高拥挤/高估值/无近端业绩标的追高加仓的理由。
- **阈值是约束而非每周追涨杀跌的开关**：单日/单周噪音不升级为框架级变量。

### 2. 公司机制归类（保留）

归入以下一类并映射参数：

- **稳态现金流型**：看现金流稳态、估值锚、下行保护
- **负反馈修复型**：看利润率修复、去库、订单恢复、现金流转正
- **周期反转型**：看成本、库存、供给、资产负债表
- **供给冲击重估型**：看供给约束、库存变化、价格弹性、利润传导
- **事件驱动重估型**：看政策、治理、资产处置、份额变化能否验证
- **正反馈强化型**：看景气/动量自我强化，须以盈利兑现和现金流支撑为护栏

**机制权重重排**：【本次更新】高权重 = 负反馈修复型；中高权重 = 稳态现金流型 / 周期反转型 / 事件驱动重估型；中权重 = 正反馈强化型 / 供给冲击重估型。（稳态现金流型权重高→中高于 2026-08-15 执行——这是 2026-08-08 预设复核路径的兑现：风格切换三条件第二周持续性确认达成（两融连续回升、成交稳于 2 万亿上方、防御未重夺领导权），升权时依据的"防御风格主导"语境被连续两周事实否定；其底仓锚地位（低利率环境下红利-国债利差处历史高位、险资等配置型资金持续增配、政策呵护资本市场）不动，降权只削"防御主导"溢价，不构成看空红利或底仓减配依据。）

**权重含义澄清**：高权重 = 研究关注度/覆盖权重大，**不等于买入倾向放宽**。负反馈修复升[高] = 加大承接方覆盖，修复证据仍须验证。正反馈降[中] ≠ 放弃 AI；AI 算力链由全面贝塔收敛为**结构阿尔法筛选**，保守约束（高 `d_base`、鉴别清单、追高否决）作护栏保留。高低切至多为短期切换，非成长→价值大切换。【本次更新】稳态现金流[中高] = 底仓锚覆盖权重，**不等于红利资产豁免拥挤度检查**（护栏见参数映射）。

- `P1 = V50 × (1-d_base) × ∏(1-r_k)`
- `P2 = P1_low × (1-step_down)`，`step = 5%–10%`

#### 6.2 仓位规则

- `cap_final = min(单票硬上限, 温度仓位上限) × cap系数`
- P1 = 60%，P2 = 40%
- 高不对称 / Chip=Penalty / 可达性=困难 → 降低 P1 或取消 P2

#### 6.3 强制映射规则（保留）

- Precheck = 警惕 → `d_base` 取上沿，`cap_final` 下调 20%–30%，必要时取消 P2
- 正反馈强化型 → 提高 `d_base`，下调 `cap_final`
- 政策链弱 + 盈利兑现链弱 → 只给跟踪价位
- 叙事依赖高 → 同时上调 `r_terminal` 与 `r_v5`
- 成本传导弱 + capex 激进 + 现金流差 → 即使便宜也不得机械重仓
- 高估值 + 财报兑现弱 + 拥挤高 → 上调 `r_chip`、`r_terminal`，显著下调 `cap_final`
- AI/科技纯概念映射缺乏真实客户/订单/回款/现金流 → 只给跟踪价位
- 供给冲击重估型若库存去化/价格传导/利润释放证据不足 → 提高 `r_v5`，P2 从严
- 双轴双不利 → 只给跟踪价位
- 双轴一利一损 + 国家队减持（确认）→ 上调 `r_chip` 至少 3 个百分点，`cap_final` 下调 30%
- 鉴别清单判定为正反馈强化型 → 强制按正反馈强化型参数，不得用「便宜」放宽
- **高估值成长估值依赖隐含降息扩张且降息预期归零/转加息 → 只给跟踪/观察价位**
- **追高否决三项成立 → 只给跟踪价位，禁止追高新开**
- AI 主线即使联动通过、2027 估值不合理 → 上调 `r_terminal`，`cap_final` 下调，P2 从严
- AI 主线脱钩假设未验证 → 只给跟踪价位
- 在册事件窗口前 48 小时 → 临时冻结新开仓，P2 触发暂停执行直到窗口过去
- 仅政策重估链成立而无盈利锚点 → 只给观察价位

#### 6.4 T1 / T2（保留）

**T1 触发**：接近 V50 上沿；可达性「可能」转「困难」；预期差正转中性；政策传导/盈利兑现弱化；订单/回款/现金流弱化；拥挤度上升但基本面未同步加强；双轴由「双中/一利一中」恶化为「一利一损」；板块国家队首次明显减持（确认）；**美联储/沃什边际转鹰、降息预期下修**（高估值成长记 T1）；**估值分位升至追高否决阈值附近（PE/PB 分位接近 80%）记 T1**　`[脚本已供分位可直接判]`；海外 AI capex 指引边际转弱（订单未转弱记 T1 观察）；单周/单日回调本身不构成 T1（须 capex/订单证据转弱，仅限已验证龙头）。

**T2 触发**：明显高于 V50；可达性转「不可能」；预期差为负且温度热；持续紧缩下逻辑不成立（盈利无法对冲压缩）；关键 Precheck 项恶化；财报证伪核心盈利假设；OCF 显著弱于利润表；高拥挤板块踩踏式重定价；双轴恶化为「双损」；**降息预期归零/转加息且估值依赖降息扩张（估值压缩证实）**；**追高否决三项同时成立且仍处追高价位**；海外 capex 指引转弱 + 在手订单同步转弱（脱钩证伪）；油价冲高到 V5 压力情景（油价敏感标的）；在册窗口弱情景实现且公司直接暴露。

#### 6.5 复评 / 熔断（保留）

**复评触发**：天花板变量变化、隐含假设跳变、Chip 恶化、政策真实性下降、盈利兑现转弱、订单转化转弱、回款拉长、成本冲击超预期、capex/现金流恶化、拥挤度升温、供给重估逻辑逆转、海外 AI capex 指引转弱、国家队连续减持（确认）、政策曝光被证伪、双轴恶化一档、**降息预期跳变（归零/转加息）、美联储/沃什路径转鹰、美国 CPI 破 4% 且黏性、估值分位突破追高否决阈值、近端业绩缺失确认**。油价突破 V5 为次级复评项。

**熔断触发**：
- 基本面熔断：红线命中 → 否决
- 筹码熔断：Chip = FREEZE → 冻结
- 终局熔断：可达性 = 不可能 → 强制 T2
- 财报熔断：核心盈利兑现与现金流验证被证伪 → 冻结/强制 T2
- 拥挤熔断：高拥挤题材业绩证伪 + 集中减持/资金流恶化 → 冻结
- 事件窗口熔断：(a) 海外 capex 指引大幅下修且公司高度依赖 → 脱钩证伪标的冻结/T2；(b) Q 财报核心盈利证伪 → 冻结/T2；(c) 美联储路径意外鹰派/降息预期归零/沃什转鹰冲击风格端 → 成长端高估值标的重评/冻结
- 双轴熔断：双轴骤降为「双损」→ 强制冻结
- 流动性熔断：降息预期归零/美联储转加息冲击风格端，且估值依赖降息扩张 → 高估值成长重评/冻结
- 追高熔断：追高否决三项成立且发生估值压缩式重定价 → 冻结
