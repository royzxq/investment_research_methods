# v0.1 决策卡归档

框架 v0.1 时期（2026-09-23/24）的 8 张决策卡，带指数点位锚点。框架 v1.0 起不再给点位，v1.1（2026-10-01）起本仓只出调研报告、不再有决策卡格式，这些卡只作历史留存。
其中的论点、证据、反证、监控变量与失效条件仍可作主题调研的输入；引用其中的数字前须按当期快照重核。`current-v1.json` 是 v0.1 最后一次导出的执行侧文件，只作历史。

| v0.1 卡 | v1.0 去向 |
|---|---|
| `cn-hk-pharma-tactical` | 主题 `innovative-drug` |
| `cn-defense-tactical` | 主题 `defense` |
| `cn-nonferrous-tactical` | 主题 `industrial-metals`（核实工业有色口径） |
| `cn-chemicals-tactical` | 主题 `chemicals` |
| `cn-consumer-tactical` | 主题 `consumer-staples` |
| `cn-star50-tactical` | 核心 `core-star50` |
| `cn-brokers-tactical`、`cn-newenergy-tactical` | 观察项（不在 8 席研究池） |
