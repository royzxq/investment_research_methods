## 3. 修改说明

### 修改项1
- 模块：0) CONTRACTS + 0.2 + 1.5 品种卡卡头
- 对应上层变量变化：目标合约到期（0.3#1 硬否决触发）
- 原内容问题：v2.17 只对 JM/J 做了实测换月，其余 16 个品种停在「主力待核」「月份待选定」，且规定确认前不新开方向性单边——框架的整个执行层被合约层悬空拖住；0.2 表 18 行全空。
- 修改方式：逐品种取 fut_mapping 主力（近 3 年历史+最新 8/31 映射）、fut_basic 最后交易日、近 20 交易日均量与持仓三项实测，按「近腿=实测主力；远腿优先保留原腿，原腿失效（已早于新主力/不过#2）才换代」回填；0.2 表两列由脚本输出直接落值。
- 修改原因：这是 v2.17 自己写死的到期动作，且是执行层解冻的唯一前置。
- 预期作用：合约层落地、临时冻结解除；0.2 表首次有实测数值可直接用于 #1/#2 核对。

### 修改项2
- 模块：0) 新增「合约滚动阶梯」表 + 三条结构性例外
- 对应上层变量变化：换月机制本身（无上层市场变量）
- 原内容问题：框架此前**没有任何地方记录**各品种的主力月阶梯与换月时点，每次换月都要临时判断，于是每次都会留下"待核"尾巴；同一份知识此前只存在于 gitignore 的本地产物 `output/roll_ladder.md` 里，随时会丢。
- 修改方式：把 3 年 fut_mapping 实测出的主力月集合、市场换月中位剩余交易日、当前腿、下一次触发 #1 的**具体日期**、下一目标腿冻结成表，并把滚动判据统一成一句话（近腿触#1线 **或** 主力换月，先到为准；目标腿须过#2，过不了退到最近能过的月份并在 0.2 标注降级）。
- 修改原因：奥卡姆——与其每次换月重新推导，不如一次实测冻结成查表项；这也正是 roll_ladder 探针当初写"冻结用法：主力月集合+换月时点写入框架品种特例层"的意图。
- 预期作用：下次换月是查表执行而非重新研究；最近三个触发点（SC 2026-09-02、CU/AL/RB/AU/AG 2026-09-10、MA 2026-09-16）已挂进 6.8 监控清单，不会再漏。

### 修改项3
- 模块：0) 阶梯表例外 (a) + 1.5 IM/IC 卡 + 1.7 ④ + 脚本 §3
- 对应上层变量变化：IM/IC 合约结构与 #1/#2 的相互作用（结构性，非本周市场变化）
- 原内容问题：股指主力恒为近月直到交割（近 3 年 20 次换月的中位剩余交易日 = 0），而次月腿流动性过不了 #2（IM2610 7,498 手 / IC2610 5,328 手）。近月最后 20 个交易日被 #1 封死、次月被 #2 封死——**框架合规的可持有腿其实只剩远季月**，而此前 CONTRACTS/§3 贴水腿一直写的是近月主力。这不是本周才成立的，只是换月时才第一次撞上。
- 修改方式：IM/IC 的 CONTRACTS 行、0.2 行、H-roll 价差对、§3 年化贴水腿一律改为 2612（远腿 2703），并在阶梯表写成显式例外「勿修正回主力」；1.7 ④ 行写入口径变更与不可比声明。
- 修改原因：把一条一直隐含、每次换月都会被"改回主力"的规则显式化。
- 预期作用：④ 的读数从此稳定（不再受近月临交割的年化放大影响）；代价是绝对水平系统性低于旧口径——实测同日新口径 IM 11.0%/IC 9.9%、旧口径 8.4%/8.9%，**新旧同为 ✗ 未过，本次换月未改变 ④ 的判定方向**。

### 修改项4
- 模块：0) 阶梯表例外 (b) + 1.5 JM/J 卡 + 2.1 高档 + 6.5 双焦行
- 对应上层变量变化：焦炭 J 的远月流动性
- 原内容问题：J 的月差腿在换月后没有合规远腿——J 除主力外没有第二个上万手的月份（J2705 仅 325 手、J2610 709 手），J2701-J2705 的远腿远低于 #2。原 J2609-J2701 两腿都在万手以上，是随 09 合约死亡才失去的。
- 修改方式：**J 月差腿本期挂起、仅作数据采集不进执行层**；双焦月差的唯一执行腿改为 JM2701-JM2705（远腿 18,774 手过 #2）；恢复条件=远腿量能回到 1 万手以上。
- 修改原因：#2 是硬否决，配一条自己就违反硬否决的执行腿等于给自己留坑；但整对删掉会断掉数据序列，故保留配置只标挂起。
- 预期作用：黑色月差的表达收敛到唯一合规腿；J 的分位数字仍可看，但明确不可据以下单。

### 修改项5
- 模块：脚本 `_match_rows`（合约解析主键）
- 对应上层变量变化：无（潜伏 BUG，换月时暴露）
- 原内容问题：脚本用「delist_date 年月 == 合约交割年月」定位合约。该假设对 **INE 原油 SC 系统性错位一个月**——SC 的最后交易日落在交割月的**前一个月**（SC2610 → 20260930），于是 `resolve("SC2609")` 实际取到 SC2610、`resolve("SC2610")` 取到 SC2611。用 fut_basic 全表核验：20 个配置品种里只有 SC 命中该错位，且其 27 个在挂合约全部错位。错位被年份平移腿同步抵消（SC2509 也一并平移成 SC2510），所以**历史分位数值是自洽的，但合约标签、§0 距到期、§2 单合约指标全部张冠李戴**，而且 §0 从未对真正的 SC2609（8/31 到期）报过警。
- 修改方式：主键改为「ts_code 去后缀后与 sym 全等」（已核 tushare 各交易所均返回 4 位年月码，郑商所亦是 MA2601.ZCE 而非 MA601.ZCE，不存在原注释担心的十年循环歧义）；交割年月匹配降级为退化分支兜底。
- 修改原因：第一性原理——拿到 root cause 证据（全表核验：仅 SC 错位、27/27 全错）后再改，而不是给 SC 打特例补丁。
- 预期作用：修正后 SC 近端月差显示为 SC2610-SC2611、两腿 89,354/14,465（均过 #2）；同一份数值在修正前是挂在「SC2609-SC2610」标签下的——这正是错位的直接证据。

### 修改项6
- 模块：脚本 `_busdays` / §0 / §0b / §2b / §3 + 框架 0.3#1 口径注 + 1.1
- 对应上层变量变化：无（口径 BUG，换月时暴露）
- 原内容问题：脚本的「交易日」一直是工作日近似（未剔节假日）。2026 国庆当口实测：CU/AL/RB/AU/AG 的 2610 腿近似读数 33 天、真实交易日 27 天，**差 5 天**——足以让 0.3#1（<20 交易日）的 §0 预警整整晚一周触发，而这一周正是这批合约的换月窗口。§3 的年化贴水分母同样用近似，远季 carry 腿窗口内含长假，偏差比近月腿更大，而 ④ 是 20% 的硬门槛。
- 修改方式：`_busdays` 主口径改 `trade_cal` 真实交易日（左闭右开，与 `np.busday_count` 同语义，四个调用点无需改动），取数失败自动退回原近似；§3 的分母用同一份日历向量化计算；框架侧在阶梯表补口径注，声明表内数值与脚本输出同源。
- 修改原因：框架的 #1 是硬否决，判据源不能是"大致对"的近似；且框架新写的触发日期表若与脚本预警不同源，等于制造两个真相。
- 预期作用：#1 预警与阶梯表触发日期严格一致；§3 年化贴水由 10.1%/9.1% 修正为 11.0%/9.9%（口径修正，不改 ✗ 未过结论）。

## 4. 不应过度反应的部分
- 1. **换月不是行情判断**：本次全部改动都在合约层与换月纪律，0.1/0.0/0.4/1.4/1.7（除④口径）/2.x/3.6 一律沿用 8/29 判定，本周没做新调研——不要把 v2.18 读成一次市场观点更新。
- 2. **"主力待核"解除 ≠ 可以开仓**：临时冻结换成了"新腿分位序列重建观察期内结构腿新开从严"。16 组价差对全部换腿，同期分位/涨幅分位是**归零重算**的，新腿的分位只有一天的历史语境。
- 3. **换月后的高分位不是新信号**：MA2610-MA2701 同期分位 100.0、JM2701-JM2705 91.9、J2701-J2705 92.7、黑色 J-RB 100.0 —— 这些是**新序列的第一个读数**，不是"本周分位跳升"。与换月前的数字没有可比性。
- 4. **④ 读数下降不是贴水结构变化**：11.0%/9.9% 与换月前的 8.4%/8.9% 分属两个口径（远季腿 vs 近月腿，且日历口径也修了）。两个口径同为 ✗ 未过，H 门状态没变。
- 5. **J 月差挂起不是对焦炭的看法变化**：纯粹是 J2705 只有 325 手、不过 #2 的流动性事实；双焦的结构表达仍在 JM 腿上，v2.17 的原料侧结论一字未动。
- 6. **IM/IC 用季月不是"改成了做远月"**：是 #1 与 #2 夹击下唯一的合规腿，且这条约束一直存在、只是本次才撞上并写明。下次换月看到"配置的不是主力"，不要"修正"。
- 7. **两处 BUG 修正不追溯改写历史结论**：SC 错位是标签错位、分位数值自洽；日历近似只影响触发时点与年化分母。既有的 ①/③/④ 判定不因此回滚。
- 8. **阶梯表是实测冻结值，不是永久事实**：主力月集合与换月中位剩余交易日按近 3 年统计，品种活跃月结构变化时需重测；表里已把临界流动性（AL2612 9,920、MA2705 9,055、LC2705 8,834、RB2705 6,821）标出来，到日子仍须复核而不是照抄。
