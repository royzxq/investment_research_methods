### 2. 结构化记录未通过发布前校验，否决归因不自洽（P1）

对用户原文件实际运行：

```text
python3 scripts/validate_futures_audit.py --input <用户报告路径>
退出码：2
status：invalid
错误：input: Markdown must contain exactly one fenced json audit block
```

报告只有 YAML，缺 schema 2 的证据表和 evaluated_checks；不能作为已通过校验的执行审计。以下为另行人工检查发现，并非声称校验器已从 YAML 中自动检出：

| 报告记录 | 应采用的口径 |
|---|---|
| signal=not_confirmed | 只允许 triggered / not_triggered / unknown；确认定义或证据未完成时用 unknown，并单列研究筛选已触发 |
| data_feasibility=no_signal | no_signal 是交易状态；数据可得性另填 available / temporary_gap / research_only |
| MA all_blockers=[#5]，仍有 unknown，only_blocker=false | 现有证据不足以确定是否唯一否决，应为 null；false 要求至少两项已知失败 |
| #5=fail/unknown | 拆开“结构确认定义/观测缺项”和“产业支持已核反向”；每条检查只取一个状态，再按依据确定 #5 |
| 新对 first_blocker=#13(脚本待办) | 缺序列属于 unknown；没有已核失败时 first_blocker=null，#13 进入 unknown_checks |
| M/CF signal=not_triggered、status=incomplete | 已定义信号经充分证据确认未触发才用 no_signal；尚无路由/证据不应声称完成未触发判定 |
| 其余若干规则=not_applicable 或 unknown | 必须逐项决定适用性；已明确的 #7–#10 等未知也应与机器块完整对应 |

AU/SC 信号席放入 coverage/信号记录，不以未定义的 signal_only 状态混入执行候选 schema。

### 5. SC 指标失败被误写为两端结算价缺失（P2，工具与报告共同问题）

本地输出的 SC 价差部分显示：截至 9/7，两腿均使用 settle，价差 +40；5 日变化覆盖 8/31→9/7。单合约部分则报“OHLC/结算价无效”，整行 NaN。

代码 `scripts/future_data.py` 的 indicators 在第 717 行起先对全生命周期 px/high/low 做整体检查，失败即抛错；周涨结算证据直到第 804 行才计算。任何历史高低价异常都可能让本来可独立计算的两端结算证据不输出。

因此目前能确定的是“该模块未生成周涨证据”，不能确定“8/31 和 9/7 两端结算价都缺失”。价差输出也不足以还原两腿各自的绝对结算价，不能据此补造周涨。

修正方向：将仅依赖两端结算价的护栏证据与 ATR/OHLC 模块解耦；分别输出字段级缺项。未复核前 SC 护栏保持 unknown。此问题不直接否决豁免该单边门的完整国内 A 结构。

### 6. 日期核对正确，但事件归属、倒数日及旧腿持有窗混用（P2）

美国 PPI=9/10、CPI=9/11、均 08:30 ET，与 [BLS 官方月历](https://www.bls.gov/schedule/2026/09_sched.htm)一致；WASDE=9/11 12:00 ET，与 [USDA 日程](https://www.usda.gov/about-usda/general-information/staff-offices/office-chief-economist/commodity-markets/wasde-report)一致。FOMC 决议=9/16 14:00 ET、记者会 14:30，与[美联储月历](https://www.federalreserve.gov/newsevents/2026-september.htm)一致。

按上述时间换算，决议北京时间为 9/17 02:00。若以报告自己采用的国内决议归属交易日 9/17 为 T，交易日倒数为 T−3=9/14、T−1=9/16、T+1=9/18。原文 T−3=9/11、T−1=9/15 并不采用同一锚点。框架旧状态段本身也写死了这些较早日期，应先澄清其是否属于额外提前限制，不能在此次复核中直接把已有固定冻结窗缩短。

### 7. 库存反证方向有公开支持，来源与统计口径须修正（P2）

可读的[东方财富转引金联创原文（2026-09-04）](https://qhweb.eastmoney.com/news/202609043865239986.html)明确：截至 9/3，华东社会库存 34.47 万吨，口径不含华东下游工厂，周降 3.68 万吨；华东与华南合计 43.67 万吨。报告写“金十/Mysteel、下降 3.67 万吨”未给可追溯链接。应补录所用原文及同口径前值；不能把区域社会库存与其他港口样本总量直接比较。

该证据可支持“近端供给趋紧，对做空价差不利”的研究推断；不能单独证明价差必然继续走阔。“历史极低”还需要同口径历史比较。转引文章其他分地区数字亦须检查内部一致性，不能因读到了正文便把整表视为无误。

FedWatch 部分把不同日期的旧读数称作“来源冲突”，又汇总成当期 55–66% 上沿附近。不同日期首先属于时间序列变化；同一时刻、同一会议、同一目标利率区间才可判来源冲突。未取得当期可核读数，应保留历史轨迹及当前 unknown，不能从旧值拼出当前概率。

### 8. 目标可达性和“避免亏损”仍缺可验证依据（P2）
