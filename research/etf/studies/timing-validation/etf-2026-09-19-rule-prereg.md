# ETF 轨道规则验证 · 预注册（2026-09-19）

> 本文件先于任何回测结果提交。提交之后，规则定义、参数、基线、折、指标、通过门槛一律不改。
> 写本文件时只看过各序列的起止日期、行数与当前读数（快照），没有计算过任何策略收益。
> 验证报告 `research/etf-<date>-rule-validation.md` 必须引用本文件的提交哈希。
> 跑出结果后若发现代码缺陷，修复须在报告里并列给出修复前后的数字，不得静默替换。
>
> 背景（用户 2026-09-19 口径）：ETF 同样要择时、选标的——候选池逐只投研，给挂在指数点位上的买卖锚点；
> 现有基金保留小额定投，除非系统判断要停或卖；待投资金不按日程投完。任务说明 §7 原拟的「估值缩放定投」与
> 「四类资产再平衡」不再对应用户的做法，本预注册取而代之。

## 0. 要回答的问题

决策卡的三锚点（`add_below` < `buy_below` < `reduce_above`，目标仓位占单笔上限的 100% / 50% / 30%，买入区只买不卖、减仓区只卖不买）
需要一个**状态变量**把「便宜 / 贵」翻译成点位。本次只验证下面四条，结论决定框架 A9 写什么、锚点用哪个推导函数：

| 编号 | 规则 | 对照 |
|---|---|---|
| R1 | 估值分位阶梯：状态变量 = 估值倍数的扩张窗分位 | 满仓买入持有；同均仓位的恒定比例 |
| R2 | 回撤分位阶梯：状态变量 = 相对近 3 年高点回撤的扩张窗分位（给无估值源的指数用：港股、黄金） | 同上 |
| R3 | 趋势闸门：阶梯的买入只在指数月收盘高于 10 月均线时执行 | 不加闸门的同一阶梯（R1 或 R2） |
| R4 | 定投趋势暂停：指数月收盘低于 10 月均线时暂停定投，回到线上恢复，暂停期间的钱不补投 | 不暂停的固定定投 |

不调参、不加规则、不做开放式挖掘。嵌套窗口不算敏感性分析。

## 1. 数据

| 用途 | 序列 | 来源 | 口径 |
|---|---|---|---|
| 指数收益 | 登记清单里各指数的全收益指数（`tr_code`）；没有则用价格指数并在报告里标注 | tushare `index_daily` / `index_global` / `sge_daily` | 月末收盘；外币指数按外管局中间价折人民币 |
| 趋势与回撤信号 | 同一指数的价格指数 | 同上 | 月末收盘 |
| 估值 | 自聚合月频 PE/PB（`etf_data.py` §4：成分权重 × 个股 `pe_ttm`/`pb`，亏损股盈利按 0 计）；沪深300、中证500 另有乐咕乐股月频 PE，仅作交叉核对 | tushare `index_weight` × `daily_basic` | 月末 |
| 现金 | 中证货币基金指数 `H11025.CSI` | tushare `index_daily` | 财富指数 |

**估值序列的前置核对**：快照 §4a 在 5 个固定日（2007-10-31、2008-10-31、2014-06-30、2018-12-28、2021-02-26）加当日，用同一份成分与个股数据
**按现成源的口径（总市值加权：Σ总市值 ÷ Σ净利润）复算**沪深300 的 PE，与乐咕月频、tushare `index_dailybasic` 对比。
判定：可核对日不少于 3 个，且每个可核对日对两个现成源的 `|复算 ÷ 现成源 − 1| ≤ 10%` → 成分与个股估值是当时口径、可作回测输入；
否则 R1 记「数据不可验证」，不出 validated / rejected 结论，框架里保留 provisional。
R1 的状态变量本身用**指数权重口径**（自由流通调整权重的调和加权 = 持有该指数的组合市盈率），因为点位与它同比例变动，换算锚点才自洽。

如实交代：本段在提交前改过一次。初稿拿指数权重口径的自聚合 PE 直接比现成源，首跑快照显示偏差最高 23%（2014、2021、当前）。
排查后确认是口径差而非数据错：现成源按总市值加权，低估值的大盘股占比更高；按它们的口径复算后，6 个核对日的偏差全部在 4% 以内。
改动发生在看到任何策略收益之前，只涉及数据核对方法，不涉及规则、参数与门槛。

已知偏差，事先声明：自聚合把亏损股盈利按 0 计，PE 偏低且偏差随亏损面扩大而变大，周期行业在景气底部最明显；
tushare 的历史 `pe_ttm` 视为当日计算值，point-in-time 未独立验证；价格指数不含分红，对该指数的全部臂同样适用，不影响臂间比较。

## 2. 共同协议

- **频率**：月。信号与交易同在月末收盘。估值信号用**上一个月末**的读数（财报与权重发布有滞后）；趋势与回撤信号用当月末读数（点位盘中可见）。
- **折**：F1 2005-01～2010-12、F2 2011-01～2016-12、F3 2017-01～2022-12、F4 2023-01～2026-08。每折从零重新开始；信号可以使用折起点之前的历史。
- **适用折**：状态变量非空的月份不少于该折**日历月数**的 80%（72 / 72 / 72 / 44 个月；序列在折中途才开始的，不因此得到一个更短的折）。
  R4 同理要求行情覆盖该折日历月数的 80% 且折初已有 10 月均线。某指数适用折少于 3 个 → 该指数对该规则记「数据不足」，不参与结论。
- **参与的指数**：登记清单（`framework/etf_index_registry.json`，本文件提交时共 25 项）里有行情源的全部指数，现金代理 `H11025.CSI` 除外（它就是账户的现金腿）；
  由上一条机械决定谁参与，不人工挑选。R1 只对有自聚合估值序列的指数成立。主指数：R1 为沪深300；R2 为恒生指数（港股是用户最大的无估值源敞口）；
  R3 套在 R1 上时为沪深300、套在 R2 上时为恒生指数；R4 为沪深300。
- **账户（R1–R3）**：折初账户有 1 个单位资金，全部是现金；阶梯决定其中多少买成指数，其余留现金，现金按 `H11025.CSI` 计息。
- **账户（R4）**：每月末到账 1 个单位，固定定投臂当月全部买入；暂停臂在暂停月把到账资金留作现金、此后不补投。两臂到账现金流相同。
- **成本**：每笔买入 0.15%，卖出 0；指数基金年费按快照 §5 的 A 类份额：宽基 0.20%（沪深300、中证A500、中证500、恒生指数、红利低波、上证国债、标普500）、
  黄金 0.60%、其余（行业、主题与恒生科技）0.60%，按月从指数收益里扣除。各臂同扣，对臂间比较几乎没有影响。
- **指标**（只认这三个）：最大回撤（账户时间加权净值，月频）；下行捕获（对照臂月收益为负的月份里，策略月收益均值 ÷ 对照臂均值，只报告）；
  年化收益（R1–R3 为时间加权年化，R4 为资金加权年化）。

## 3. 规则定义

### 阶梯（R1、R2 共用，与决策卡 schema 的语义逐条一致）

状态变量的扩张窗分位 `q`（`etf_calc.expanding_percentile`，最少 5 年历史，0–100；分位低 = 便宜）。目标仓位占账户的比例：

- `q ≤ 10` → 目标 100%；`10 < q ≤ 25` → 目标 50%；两档都是**只买不卖**：现仓位低于目标则买到目标，高于目标不动；
- `25 < q < 75` → 不做任何买卖；
- `q ≥ 75` → 目标 30%，**只卖不买**：现仓位高于目标则减到目标，低于目标不动；
- `q` 不可得 → 不做任何买卖。

### R1 的状态变量

自聚合月频估值倍数：周期性行业（有色金属、细分化工、证券公司、光伏产业、新能源汽车）用 **PB**，其余用 **PE_TTM**。
倍数为空的月份（全部成分亏损等）`q` 视为不可得。

### R2 的状态变量

`回撤 = 月末收盘 ÷ 近 36 个月末收盘的最高值（含当月）− 1`。为与「分位低 = 便宜」对齐，取 `1 + 回撤`（0–1，越小跌得越深）的扩张窗分位。
不足 36 个月时用已有月份的最高值，但分位仍受 5 年最少历史的约束。

### R3 趋势闸门

`etf_calc.sma_state(近 10 个月末收盘, 10)` 为 `above` 时闸门开。闸门关时阶梯的**买入**不执行（目标照算，等闸门开了按当时的 `q` 重新判断，不补做已错过的档位）；减仓不受闸门影响。
分别套在 R1 与 R2 上，各出一个结论。

### R4 定投趋势暂停

闸门定义同 R3。闸门关 → 当月到账资金留现金且不补投；闸门开 → 当月到账资金照常买入。

## 4. 通过门槛

对每条规则、每个参与的指数：

1. **风险**：最大回撤在不少于 3 个适用折里严格优于「满仓买入持有」（R4 对「固定定投」，R3 对「不加闸门的同一阶梯」）；
2. **收益代价**：各适用折年化差 `d_i = 策略 − 对照`，均值 `d̄`、样本标准差 `σ`（ddof=1）：`d̄ ≥ 0` 通过；`d̄ < 0` 时仅当 `|d̄| ÷ σ < 1` 通过；`σ = 0` 且 `d̄ < 0` 不通过；
3. **择时技能**（仅 R1、R2）：阶梯仓位低于满仓，回撤更小几乎是必然，所以另设对照「恒定比例」——折内每月再平衡到该折阶梯的平均仓位。
   要求各适用折对恒定比例的年化差均值 `≥ 0`。不满足说明好处只来自「少持有」，不是「挑时候」。

单个指数：1、2、3 同时满足 → 该指数通过。

**规则结论**：在主指数上通过，且在其余参与指数中通过的超过半数 → `validated`；主指数通过而其余不过半 → `validated(仅主指数类)`，框架里限定适用范围；
主指数不通过 → `rejected`，从 A9 删除。R1 或 R2 只过 1、2 不过 3 → 记 `rejected(无择时技能)`，框架改写为「用固定的较低仓位达到同样的风险，不设买卖点位」。
参与指数之间高度相关（候选池调研：31 个权益指数约等于 3.3 个独立押注），「过半」不是独立样本的投票，只防止结论单靠一个指数。
