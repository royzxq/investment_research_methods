1. **Terminal & Expectation**：市场隐含终局 vs 我的判断 + 天花板变量监控

3. 明确结论：**买入 / 观望 / 回避**
4. 组合动作倾向：**增配 / 降配 / 观察**

## Section 0. 数据输入契约（Data Contract）

### 0.1 基本约定

本次调研随附 `stock_data_pack.py` 生成的【数据包】。数据包提供的量价 / 估值 / 财务 / 分位 / Terminal 初值，**视为既定输入，分析时直接引用，不重复查询、不重新计算**。AI 的工作从「采集 + 计算 + 判断」收敛为「校验 + 判断」。

### 0.2 数据包 → 框架模块映射

| 数据包字段 | 供给的框架模块 |
|---|---|
| 当前量价快照（价 / 涨跌 / 52周回撤 / 量额 / 总流通市值） | Price Map（T1-T2 定位、回调处置） |
| 估值分位（PE/PB/PS/换手 的近1/3/5年分位） | 追高否决三重过滤（2 项）、估值分位、不对称性等级 |
| 盈利兑现数据（营收&YoY / 归母&YoY / 毛利率净利率 / 扣非归母 / ROE & 扣非ROE） | Precheck#1 盈利兑现质量 |
| 现金流数据（OCF / OCF·净利比 / 应收 · 存货 · 合同负债 / 资本开支） | Precheck#3 现金流质量、资本开支纪律 |
| 北向持股比例及近期变化 | Chip / Non-Price Risk |
| 业绩预告 · 快报 / 财报披露日历 | 滚动事件窗口（公司财报窗口） |
| Terminal 初值（隐含终局利润 = 市值×K、隐含倍数 = K×PE_TTM、当前 TTM 利润） | Terminal & Expectation 5.2 |
| 温度代理（50ETF 波指、沪深300 近端）、宏观（中国PPI / 中国CPI / 美国CPI） | Gate 3.1 市场温度、Precheck#4 海外流动性（部分） |

### 0.3 数据自检 mini-gate（必过）

引用数据包前先做 3 项轻校验，**不通过的字段按「该项数据缺失」处理，禁止用旧记忆或估算填充**：

1. **时效一致性**：数据最新交易日与估值时点是否一致 / 可接受；财报报告期是否为最新已披露期。
2. **缺失检测**：关键字段是否显示「—」或「数据为空 / 请人工补充」（常见于 tushare 积分不足导致的北向、披露日历、长周期分位）→ 缺失项转 `[需人工补充]`，不可臆造。
3. **异常值标记**：是否存在可疑数据，例如 OCF/净利剧烈背离、分位 = 100%/0%（疑似常量或样本不足）、扣非与表观异常偏离 → 标注「存疑」，不直接作为 Gate / 熔断的硬依据，需二次核对。

### 0.4 职责边界

数据包只供「可核验的量价 / 估值 / 财务输入」，**不替代** Precheck 判断、机制归类与 Gate 决策。以下定性项仍由 AI 搜索 + 人工补充，脚本不提供：

- 订单真实性（付费客户 / 合同金额 / 交付周期 / 回款 / 客户集中度 / 公告→转化→回款一致性）
- 海外 AI 大厂 capex 指引方向、订单递延 / 砍单 / 交付放缓信号、与在手订单联动
- 政策落地实锤（文件 / 试点 / 财政资金 / 央企动作 / 反内卷落地）
- Terminal 假设：行业 TAM、份额上限、稳态净利率（三者决定隐含市占率与可达性）
- 国家队（汇金 / 证金）持仓与减持节奏（以官方披露为准，媒体报道不作既成事实）
- 海外流动性紧缩体制的判断输入：美联储点阵图 / 降息预期 / 沃什路径与表态 / 隐含降息 bp
- 代理指标精确值：费城半导体 SOX、港股 VHSI

## 一、分析流程

### 0. 决策原则（Global Rules）

- **Price Map 是最终产品**，所有模块必须回到 P1/P2/T1/T2。
- Gate 仅三种：**通过 / 冻结 / 否决**；冻结 = 禁止新开仓，且必须给出解除条件。
- 结论用区间和分档，不做伪精确。
- 折扣集合 `r_k ∈ {chip, v5, gov, terminal}`，乘法叠加。
- 允许输出「观望 / 回避」，不得强行给买入。
- **必须先做 Precheck Gate**，不通过不得进入估值与 Price Map。
- 买入结论至少建立在以下之一：
  - 盈利兑现
  - 盈利兑现 + 供给出清（反内卷 → PPI 转正）
  - 政策重估（反内卷 / 产业政策） + 盈利兑现
  - AI 成长主线：盈利兑现 + 海外 capex ↔ 国内在手真实订单联动验证通过
  - 负反馈修复 / 高低切：低估值 + 修复证据（利润率修复 / 去库 / 订单恢复 / OCF 转正），经「盈利兑现链」验证。高低切换承接中**「位置低」本身不构成买入条件**（2026-08-15）——低位补涨标的须与中报受益线重合并逐股经盈利兑现链验证，无业绩的纯位置补涨股排除在承接范围外。**当前状态（2026-10-11）**：科创50跌破在册深化线，负反馈修复回退深化；承接候选池整体冻结、存量 P2 触发暂停为规则层动作，真实账户执行为 `null`。存量硬证据持仓防守持有，卖出仍需业绩/订单证伪。完整重建条件、回退深化线、执行纪律与当期证据见「2. 公司机制归类 → 参数映射规则 → 负反馈修复型」。
- **纯资金面 / 流动性 / 存款搬家叙事不构成买入条件，也不作为加分项**（宽松流动性 ≠ 买入）。
- **海外流动性紧缩体制为一级硬约束**：持续紧缩（沃什转鹰 / 美国 CPI 破 4% / 点阵图预期加息 / 降息预期归零）是高估值成长的带阈值硬约束；判断主轴 = **盈利能否对冲估值压缩**，不把流动性当回报来源。9/16 FOMC 已加息 25bp 至 3.75%-4.00%；9 月 SEP 的 2026 年底中值 4.10%保留为**无降息 + 年内再加一次的估值压力情景**，并非委员会已确定的未来行动或市场概率；10/7 纪要仅称年内再加可能合适。美国财政部同口径 CMT 10/5—10/9 十年期为 5.31/5.27/5.28/5.22/5.24%，10/9 三十年期 5.60%；美元指数当期同口径连续值 `null`。**硬阈值三分支**：沃什转鹰判据保留，当期是否命中待官方原文核验；9/16 已加息及 9 月 SEP 路径已核，最近已核美国 8 月 CPI 3.4% 未破 4%；9 月 CPI 待 10/14 官方数据，不以旧值判当期新触发。全面执行档位仍为高估值成长 `d_base` 取上沿、`cap_final` 下调一档，并按上述无降息压力情景逐股压测；有正式订单及报表证明盈利可对冲者适用下文三项合取例外，不机械冻结。十年期同口径连续 5 个交易日收于 5% 上方为二次复评项；真实逐股复评执行 `null`。**下一窗口**：10/14 美国 9 月 CPI（同比 ≥3.6% 或核心环比 ≥0.3%→10/27—28 再加作为条件性基准、全面执行不变；同比 ≤3.2% 且核心环比 ≤0.1%→常态化复核前置，仍须后续 FOMC 条件）；10/27—28 FOMC（再加 25bp→维持并复核是否加码；**不加且正式点阵回撤**→放宽至常态化复核（light）；不加但鹰派→维持）。10 月例会不发布 SEP，故“不加”单项不能放宽，声明/发布会只作路径复评，点阵回撤须待 12/8—9 正式 SEP 验证；反弹不撤销全面执行。
- **分母端冲击期加仓纪律**（2026-08-22）：外生分母冲击（长端利率/油价）期间，**"跌多了"不构成加仓标准**——高位科技的下跌是长端利率对远期贴现估值的系统性重定价而非简单超跌，30 年美债利率趋势未逆转前不对长久期高估值资产做左侧抄底；对称面：**外生分母冲击≠盈利证伪**——有正式中报硬证据、估值不依赖远期贴现的持仓（金融/资源/低估值白马）不因价格恐慌退出，卖出仍须业绩/订单证据。
- **非对称双情景纪律**：已发生的 9/16 加息与 9 月 SEP 年底中值 4.10%作为**无降息、可能再加一次的压力情景**，不是对未来政策的确定断言；当前同口径 CMT 十年期 5% 上方、三十年期 10/9 为 5.60%，美元当期值 `null`。对称情景为后续不加且正式 SEP 点阵回撤；10 月无 SEP，该情景最早待 12/8—9 验证。所有加减仓动作仍须显式回答两情景，权重非对称：**基准情形下站得住是必要条件**，尾部情形只作对称提醒——不清仓有正式报表硬证据、估值不依赖远期贴现的持仓，不单边做空；"两情景都站得住"的对称要求继续作废。**硬阈值全面执行期规则（2026-09-19）**：无近端业绩科技的反弹不构成左侧买入理由（反弹驱动为政策方向性文件 + 存储合约价，放大器为融资客加仓寒武纪/沐曦等无近端业绩 AI 芯片——属镜像正反馈对称面而非订单证据）；**冻结口径 = 隐含降息前置否决检查三项合取判据的第 ③ 项（盈利无法对冲估值压缩）之判定规则**，不另立判据：有合约级订单可见度（存储合约/光模块缺货，须「最新合约价 + 当期报表」现验）或有政策映射且报表可验（规划型须第二环证据）的标的判为「盈利可对冲」、③ 不成立，不适用机械冻结；**不冻结 ≠ 放宽**——此类标的仍按全面执行期参数从严（`d_base` 取上沿、`cap_final` 下调一档）、逐股过追高否决三重过滤并按无降息情景重估；「隐含降息压测全面从严」指的是压测的情景取值与参数档位从严，不改写上述合取判据；对称面：不因加息落地/10 年期 5% 对分子端未证伪的持仓恐慌清仓。
- **隐含降息前置否决检查**：每只高估值成长标的压测「当前估值是否隐含降息扩张」。**冻结/否决判据（澄清为三项合取，本条为唯一出处）**：① 估值依赖已证伪的降息叙事（隐含降息 bp > 0）；② 降息预期已归零 / 转加息；③ 盈利无法对冲估值压缩（判断主轴）。**三项同时成立 → 作否决式处理，不给买入型 Price Map、按无降息情景重估**；③ 的判定口径见「硬阈值全面执行期规则」——有合约级订单可见度（存储合约/光模块缺货，须「最新合约价 + 当期报表」现验）或有政策映射且报表可验（规划型须第二环证据）者判为「盈利可对冲」、③ 不成立 → 不作机械冻结，但**不冻结 ≠ 放宽**：仍按当期档位从严（全面执行期 `d_base` 取上沿、`cap_final` 下调一档）、按无降息情景重估并逐股过追高否决三重过滤。Gate 决策树硬失败项、6.3 强制映射与精简版 [R3]/[R18] 均引用本判据，不另立口径；§0 一级约束注记的**硬阈值**（CPI>4% + 降息预期归零/转加息 + 估值依赖降息扩张）是独立且更严的合取条件，最近已核 8 月 CPI 分支未命中、9 月待官方数据，不据旧值判当期新冻结来源，两套条件独立适用。
- **追高否决三重过滤**：同时满足三项 → 追高否决（只给跟踪价位、禁止追高新开）：① 拥挤度：公募持仓分位 ≥ 88% 或 板块换手率分位 ≥ 95%；② 估值分位：PE/PB 分位 ≥ 80%；③ 近端业绩：无当季/次季可见业绩，仅远期空间。边界澄清（2026-08-08）：三项须**同时成立**方触发；超跌真成长经深度回撤后，估值分位与近端业绩两项通常已不再命中——本条不得被误用为对"有正式中报硬证据的负反馈修复承接"的机械封锁；修复启动期单周急涨的标的须重新逐项过滤。
- 不得用「政策支持 / 赛道景气 / 远期空间大」替代财报季验证。
- 高估值 / 成长股优先验证：**利润兑现、订单转化、经营现金流质量**。
- AI / 算力 / 应用映射若缺乏真实客户、订单、回款、现金流，不得给完整买入型 Price Map。
- **紧缩下独立成立性检查**：必须判断在持续流动性紧缩 / 无降息 / 估值压缩情景下逻辑是否成立，核心是盈利能否对冲估值压缩。不成立 → 冻结；部分成立 → 不给激进仓位与完整买入型 Price Map。
- **双轴定位强制项**：每只个股同时定位 (a) 主线归属与双韧性（既能脱钩海外 capex 波动 = 盈利端韧性，又能在估值压缩下靠盈利兑现存活 = 估值端韧性）；(b) 拥挤与筹码结构现状（含国家队动向）。两维度都不利者，原则上不给完整买入型 Price Map。

- **主线消化 ≠ 主线终结**：仅适用于「已验证近端业绩的主线龙头的减仓判断」——单周/单日回调不自动触发减仓或 T1/T2，须先用「海外 capex 指引方向 + 在手真实订单」对回调定性。本条不得作为对高拥挤/高估值/无近端业绩标的追高加仓的理由。

#### 1.1.1 必答问题

- 公司当前主要暴露于哪类主矛盾：AI 算力链外需盈利兑现高景气 / 财报季利润·订单·现金流兑现 / 政策重估·反内卷供给出清（PPI 转正）/ 供给冲击与价格重估 / **海外流动性紧缩逆风**（表现为「赚指数不赚钱」）/ 低估值均值回归修复·高低切 / 成本端周期反转 / 内需弱拖累。
- 公司收益逻辑属于：盈利兑现 / 盈利兑现+供给出清 / 政策重估+盈利兑现 / 供给重估 / AI 主线（盈利兑现+海外 capex↔订单联动）/ 负反馈修复（经盈利兑现链）/ 周期反转（经供给重估链或盈利兑现链）/ 均不足。
- **双轴定位必答**：
  - 主线归属与双韧性：主线受益且双韧性强（订单可脱钩 capex + 盈利可对冲压缩）/ 主线受益但脆弱 / 政策供给出清受益 / 负反馈修复·周期反转承接方 / 中性 / 内需端受损。（2026-09-19）内需弱为正式约束期内，"内需端受损"须显式标注暴露程度（收入端依赖内需的比例 / 是否有政策或外需对冲），不得留空。
  - 拥挤与筹码结构现状：清淡 / 中性 / 拥挤 / 拥挤极值（+国家队减持信号）。
  - 双轴判定：双利 / 一利一中 / 一利一损 / 双中 / 一损一中 / 双损。

#### 1.2 硬失败定义（命中任一项即至少冻结）

- 盈利兑现弱，但估值依赖远景叙事
- 订单无法落实到客户/交付/回款
- 现金流差且融资依赖高
- 政策受益无法映射到订单/份额/利润
- capex 明显超前于需求且回收逻辑不清
- 成本传导弱、利润对上游极敏感且无对冲
- 高拥挤题材在财报季缺乏业绩和现金流验证
- AI 商业化缺乏真实付费客户与回款证据
- 双轴定位为「双损」且无明确解套催化
- **高估值成长估值依赖隐含降息扩张，且降息预期已归零/转加息，且盈利无法对冲估值压缩**（隐含降息压测不通过；澄清为三项合取，判据与例外口径见 §0「隐含降息前置否决检查」，本条不另立口径）→ 冻结；三项不全成立（如盈利可对冲）→ 本条不成立、不作机械冻结，但仍按当期档位从严（全面执行期 `d_base` 取上沿、`cap_final` 下调一档）并过追高否决三重过滤
- **追高否决三项同时成立且处于追高价位** → 不给买入型 Price Map
- AI 主线标的脱钩假设被证伪（海外 capex 指引转弱 + 在手订单同步转弱）→ 冻结
- 油价上行 30% 情景下 OCF 转负且无对冲（限油价敏感标的）
- 在册事件窗口缺乏任一应对预案

#### 1.3 判定规则

- 命中 1 项硬失败 → **冻结**；治理/红线 → **否决**。
- 命中 2 项及以上中度风险 → 上调 `r_v5`、`r_chip`，下调 `cap_final`，必要时取消 P2。
- 「拥挤高 + 验证弱」同时成立 → 优先冻结。
- **高估值成长隐含降息扩张 + 降息预期归零 + 盈利无法对冲估值压缩（三项合取，判据与例外口径见 §0「隐含降息前置否决检查」）** → 冻结（否决式前置）。
- **追高否决三项成立** → 只给跟踪价位，禁止追高新开。
- 「双轴一利一损 + 验证弱」→ 上调 `r_chip` 与 `r_v5`，下调 `cap_final` 30% 以上。
- 「双轴双损」→ 冻结，不给完整买入型 Price Map。
- 全部通过 → 进入估值。

输出：Precheck 状态、主要约束、双轴定位、隐含降息压测结果、追高否决结果、是否允许进入估值、对 P1/P2/cap 的影响。

### 2. 公司机制归类

归入以下一类并映射参数：

- **稳态现金流型**：看现金流稳态、估值锚、下行保护
- **负反馈修复型**：看利润率修复、去库、订单恢复、现金流转正
- **周期反转型**：看成本、库存、供给、资产负债表
- **供给冲击重估型**：看供给约束、库存变化、价格弹性、利润传导
- **事件驱动重估型**：看政策、治理、资产处置、份额变化能否验证
- **正反馈强化型**：看景气/动量自我强化，须以盈利兑现和现金流支撑为护栏

**机制权重表**：**高权重 = 稳态现金流型 / 供给冲击重估型 / 事件驱动重估型**；中高权重 = 周期反转型；中权重 = 负反馈修复型（当前回退深化）/ 正反馈强化型。机制权重档位不变；截至 2026-10-11 科创50已命中负反馈深化线，猪链子映射失效，政策新文件仍只到 (a)，A/H 三季报兑现未核。各型适用性、状态与证据限制见下列参数映射及本期市场研究。

**权重含义澄清**：权重 = 研究关注度/覆盖权重，**不等于买入倾向放宽**。负反馈修复降[中] = 新承接暂停（见参数映射回退注记），不等于存量硬证据持仓的退出指令。正反馈[中] ≠ 放弃 AI；AI 算力链由全面贝塔收敛为**结构阿尔法筛选**，保守约束（高 `d_base`、鉴别清单、追高否决）作护栏保留。高低切至多为短期切换，非成长→价值大切换。稳态现金流[高] = 底仓锚覆盖权重，**不等于红利资产豁免拥挤度检查**（护栏见参数映射），亦不等于因避险涌入追高红利。供给冲击重估升[高]（2026-09-12）= 上游资源/油气/煤炭/航运覆盖权重与稳态现金流并列，**不等于对涨价叙事放宽验证**——供给证据+利润传导核验、85 美元回落对称情景、贵金属分支强美元基准情景全部强制；负反馈修复[中]：一般“等待触发”状态的新承接仅给跟踪价位；**本期回退深化优先**，新承接候选池整体冻结、存量 P2 触发暂停（规则层），存量硬证据持仓可防守持有，卖出仍需业绩/订单证据；研究权重不等于买入许可。事件驱动重估升[高]（2026-09-19）= "十五五"专项规划直接受益方向（半导体设备/材料/存储、创新药/器械、地产新模式相关、银发经济）的覆盖权重升高，**不等于规划即买入**——规划型政策重估只到政策重估链 (a)，映射到 (b) 前只给观察价位，Precheck#6 实锤要求不放松；"政策周期 ≠ 需求周期"，政策 beta 不豁免内需暴露核验。

**参数映射规则**：
- 稳态现金流型：**高权重**；标准 `d_base`，保留完整 P1/P2；流动性紧缩体制下进一步定位为**红利/底仓锚**（估值端低敏感、提供下行保护）。**红利拥挤度护栏**：红利/高股息板块公募持仓分位 ≥ 88% 或 换手率分位 ≥ 95%、或红利-10 年期国债利差显著收窄时，按拥挤交易处理（追高否决三重过滤同等适用），不得因"防御属性"豁免拥挤度检查——防御侧同样会变成拥挤交易。底仓锚保留，不因短期避险涌入追高加仓。**红利拥挤度核验（2026-09-12 起，必查）**：每只红利/底仓标的必须给出红利-10 年期国债利差、公募持仓分位、换手率分位三项现值，缺一不得给完整买入型 Price Map；油气上游具"供给冲击 + 稳态现金流"双属性，估值锚须按布油回落至 85 美元情景重算，不得用 100+ 油价固化现金流稳态。**当前状态（2026-10-11）**：稳态现金流型权重仍高，底仓与红利拥挤度护栏不变；国债收益率、DR007、人民币、红利估值及港股股息率当期同口径现值本次未核（`null`），不沿用 9 月水位判当前风格。收入端是否依赖内需、正式现金流与股息、拥挤度、港股高息利差逐股现验；油气双属性仍按布油 85 美元必答基准候选重算，不以现货与期货错配或 100+ 油价固化稳态。
- 负反馈修复型：**中权重**；典型对象券商/非银/被错杀创新药，扩展纳入**双创深跌后有真实盈利与现金流的超跌真成长**——承接触发条件显式化：修复启动必须以**正式报表 ROI 验证**（收入/订单/OCF 兑现）为证据，"跌幅足够大"本身不构成修复启动信号；承接候选池合格线收紧（2026-08-29）：中报收官证实"增收不增利"占比 43.6%，候选标的须过**"利润率 + 现金流质量"双验证**（营收增长不构成证据，见 Precheck#1 合格线收紧）（估值体系 capex 定价→ROI 定价切换不是普通回调，不会靠情绪修复自动复原）；修复证据弱则下调 `cap_final`、取消 P2。**执行纪律**：新承接（含低位价值轮动候选白酒/化工/有色/医药）暂停；存量有硬证据持仓按"外生冲击≠盈利证伪"防守持有，卖出仍须业绩/订单证据。预告≠正式报表；确认≠全赛道反转；覆盖面持续跟踪（中报终局分层：全市场净利正增长仅56.4%，合格线收紧适用）；位置低≠承接理由。2026-09-12 曾进入“等待触发”；资金面启动失效不等于修复原始报表 ROI 证据被证伪。**重建条件（2026-09-12 起）**：成交连续 3 个交易日严格 >2 万亿 + 同口径两融连续 3 日净流入 + 科创50 收复 1577.36（9/4 收盘）→ 恢复"启动确认"复核（light）；**回退深化线在册**：成交跌破 1.6 万亿 或 科创50 跌破 1516.2（9/11 盘中低点）或 两融再现单日 -150 亿以上偿还 → 回退深化：低位承接候选池整体冻结、存量持仓 P2 触发暂停执行（light）。**当前状态：回退深化（截至 2026-10-11）**：科创50 10/8、10/9 收于 1456.32/1457.27，均低于 1516.2，独立充分触发既有“任一命中”深化线；9/30 融资余额日差仅是代理，完整两融净变动与 10/9 融资余额 `null`，不称三项深化线均已核实。规则层承接候选池整体冻结、存量 P2 触发暂停；真实账户、持仓与成交执行 `null`。存量硬证据持仓防守持有，卖出仍须订单/盈利证伪。**深化退出阶梯（2026-10-11 新增，对称出口；当前未满足）**：沪深成交连续 3 个交易日 >1.6 万亿 **且**同口径两融净变动连续 3 个交易日无单日 -150 亿以上净偿还 **且**科创50守住 1516.2，三项均满足后才降回“等待触发”复核（light）；融资余额日差不可替代两融净变动。既有重建条件仍为成交连续 3 日 **>2 万亿** + 同口径两融连续 3 日净流入 + 科创50收复 1577.36，三项同时成立才恢复“启动确认”复核；当前成交仅两个交易日且均 <2 万亿，科创50亦未守深化线。ETF 涨日净流出连续 3 日→承接改判“兑现型”并注记；本期同口径连续序列 `null`，不得用 ETF 净流入豁免深化。科创50跌破 1577.36 或创业板跌破 3286.55→“重建进行中”回退“等待触发”（light）的原状态转移继续有效；已命中 1516.2 深化线时由回退深化优先覆盖，不据较浅回退解除冻结。

#### 3.4 联动规则

- 成本传导弱 + capex 激进 + 现金流差：任两项共振 → 上调 `r_v5`、下调 `cap_final`，必要时冻结。

### 6. Price Map（标注预供值）

#### 6.1 公式

- `P1 = V50 × (1-d_base) × ∏(1-r_k)`
- `P2 = P1_low × (1-step_down)`，`step = 5%–10%`

#### 6.2 仓位规则

- `cap_final = min(单票硬上限, 温度仓位上限) × cap系数`
- P1 = 60%，P2 = 40%
- 高不对称 / Chip=Penalty / 可达性=困难 → 降低 P1 或取消 P2

#### 6.3 强制映射规则

- Precheck = 警惕 → `d_base` 取上沿，`cap_final` 下调 20%–30%，必要时取消 P2
- **高估值成长硬阈值全面执行（2026-09-19 起）**：9/16 加息与 9 月 SEP 路径已落地，高估值成长 `d_base` 取上沿、`cap_final` 下调一档仍为系统性档位；隐含降息以“无降息 + 年内可能再加一次（9 月 SEP 年底中值 4.10%）”作压力情景，不把未来加息当已决定。真实逐股复评执行 `null`。出口仍为**不加且正式点阵回撤**才放宽至常态化复核（light）；10/27—28 FOMC 无 SEP，不加单项不满足，声明/发布会只供路径复评，点阵待 12/8—9 正式 SEP；再加 25bp 则维持并复核是否加码，鹰派指引维持从严。盈利可对冲者按 §0 三项合取例外不机械冻结。
- 贵金属标的（供给冲击重估型贵金属分支，2026-09-12）→ 强美元 + 加息基准化为基准情景：`r_v5` 上调一档、P2 从严；黄金收复 4500 后撤销复核；黄金连续两周收于 4300 上方且美元 100 上方→基准情景降级为对称情景复核（2026-09-19）
- 油价敏感成本端 / 购进价格暴露的中下游制造（2026-09-12）→ V5 100→130 美元情景不过则提高 `r_v5`、取消 P2；供给受益标的 85 美元回落情景不过则 P2 从严（2026-09-19 起 85 美元情景为上游资源标的必答基准候选）
- 负反馈修复**回退深化（截至 2026-10-11）**→ 新承接候选（含低位价值轮动）整体冻结，存量 P2 触发暂停；真实账户执行 `null`。本期新增三项合取深化退出阶梯当前未满足，降回“等待触发”仍不能跳过既有三项重建条件直接恢复买入型 Price Map；存量硬证据持仓防守持有，卖出需业绩/订单证据。
- 内需暴露标的（2026-09-19）→ 收入端依赖内需且无对冲证据者按从严收入假设重算 V50、`cap_final` 下调；"十五五"规划受益不豁免
- 规划型政策重估标的（2026-09-19）→ 政策重估链只到 (a) 者只给观察价位；出现第二环证据（招标/大基金/财政资金/集采规则）后方进入买入型 Price Map 候选，仍须过盈利锚点
- 正反馈强化型 → 提高 `d_base`，下调 `cap_final`
- 政策链弱 + 盈利兑现链弱 → 只给跟踪价位
- 叙事依赖高 → 同时上调 `r_terminal` 与 `r_v5`
- 成本传导弱 + capex 激进 + 现金流差 → 即使便宜也不得机械重仓
- 高估值 + 财报兑现弱 + 拥挤高 → 上调 `r_chip`、`r_terminal`，显著下调 `cap_final`
- AI/科技纯概念映射缺乏真实客户/订单/回款/现金流 → 只给跟踪价位
- 供给冲击重估型若库存去化/价格传导/利润释放证据不足 → 提高 `r_v5`，P2 从严
- 双轴双不利 → 只给跟踪价位
- 双轴一利一损 + 国家队减持（确认）→ 上调 `r_chip` 至少 3 个百分点，`cap_final` 下调 30%
- 鉴别清单判定为正反馈强化型 → 强制按正反馈强化型参数，不得用「便宜」放宽
- **高估值成长估值依赖隐含降息扩张、降息预期归零/转加息、且盈利无法对冲估值压缩（三项合取，判据与例外口径见 §0「隐含降息前置否决检查」）→ 只给跟踪/观察价位**；三项不全成立（如盈利可对冲）→ 不适用本条，但仍按当期档位从严（全面执行期 `d_base` 取上沿、`cap_final` 下调一档）并过追高否决三重过滤
- **追高否决三项成立 → 只给跟踪价位，禁止追高新开**
- AI 主线即使联动通过、2027 估值不合理 → 上调 `r_terminal`，`cap_final` 下调，P2 从严
- AI 主线脱钩假设未验证 → 只给跟踪价位
- 在册事件窗口前 48 小时 → 临时冻结新开仓，P2 触发暂停执行直到窗口过去
- 仅政策重估链成立而无盈利锚点 → 只给观察价位

#### 6.4 T1 / T2

**T1 触发**：接近 V50 上沿；可达性「可能」转「困难」；预期差正转中性；政策传导/盈利兑现弱化；订单/回款/现金流弱化；拥挤度上升但基本面未同步加强；双轴由「双中/一利一中」恶化为「一利一损」；板块国家队首次明显减持（确认）；**美联储/沃什边际转鹰、降息预期下修**（高估值成长记 T1）；**估值分位升至追高否决阈值附近（PE/PB 分位接近 80%）记 T1**　`[脚本已供分位可直接判]`；海外 AI capex 指引边际转弱（订单未转弱记 T1 观察）；单周/单日回调本身不构成 T1（须 capex/订单证据转弱，仅限已验证龙头）。

**T2 触发**：明显高于 V50；可达性转「不可能」；预期差为负且温度热；持续紧缩下逻辑不成立（盈利无法对冲压缩）；关键 Precheck 项恶化；财报证伪核心盈利假设；OCF 显著弱于利润表；高拥挤板块踩踏式重定价；双轴恶化为「双损」；**降息预期归零/转加息且估值依赖降息扩张（估值压缩证实）**；**追高否决三项同时成立且仍处追高价位**；海外 capex 指引转弱 + 在手订单同步转弱（脱钩证伪）；油价冲高到 V5 压力情景（油价敏感标的）；在册窗口弱情景实现且公司直接暴露。

- 拥挤熔断：高拥挤题材业绩证伪 + 集中减持/资金流恶化 → 冻结
- 事件窗口熔断：(a) 海外 capex 指引大幅下修且公司高度依赖 → 脱钩证伪标的冻结/T2；(b) Q 财报核心盈利证伪 → 冻结/T2；(c) 美联储路径意外鹰派/降息预期归零/沃什转鹰冲击风格端 → 成长端高估值标的重评/冻结（冻结与否同按 §0「隐含降息前置否决检查」三项合取判据）
- 双轴熔断：双轴骤降为「双损」→ 强制冻结
- 流动性熔断：降息预期归零/美联储转加息冲击风格端，且估值依赖降息扩张 → 高估值成长重评/冻结（冻结与否按 §0「隐含降息前置否决检查」三项合取判据；判据不成立者按「重评 + 当期档位从严」处理，不作机械冻结）
- 追高熔断：追高否决三项成立且发生估值压缩式重定价 → 冻结
