# ETF 主题调研框架 v2.1

> 第三条轨道（ETF），与期货、个股并列。canonical 文档；改动只走分支 + PR。配套：数据快照 `scripts/etf_data.py`、指数清单 `framework/etf_index_registry.json`、skill `etf-review`。
> 规则来源：用户《A股与港股ETF投资与投研方案 v1.0》（下称"方案"）。本框架只承接其中的主题研究部分。

## 0. 只回答两个问题

每 2 个月对 **{{AS_OF_DATE}}** 做一次主题调研，回答：

1. **未来两个月定投哪 2–3 个主题 ETF**（各 5% 或 10%）；
2. **每个持有主题的目标权重和处理**（目标可以是 0%）。

- 背景：组合 = 宽基底仓 50%（A500 28 / 科创50 7 / 恒指 15）+ 红利低波 20%（港股通 10 + 中证 10，用户 2026-10-01）+ 主题模块 30%（主题股票 + 主题待配现金）。宽基与红利由用户按方案长期持有，本框架不研究。
- 判断窗口：主题看未来 6–18 个月，横向比较默认 12 个月。2 个月是评审周期，不是判断周期。
- 边界：本框架只做研究，输出目标权重、处理方向和理由。
  - 金额、点位、下单时点、分批、再平衡区间、回撤处置都属于执行，由用户按方案 §六、§七、§八.3、§九 处理，不写进框架和报告。
  - 点位、均线、估值分位这类择时规则在本仓预注册验证中被否（`research/etf-2026-09-18-rule-validation.md`），没有新的验证不得加回。

## 1. 主题规则（方案 §二.3、§五、§九）

- **档位**：单主题目标 5% 或 10%。15% 是例外，须写明估值、把握和下行风险。新进一般从 5% 起。
- **预算**：常态持有 2–3 个主题，主题股票目标合计 ≤ 30%。
  - 合格的不够就少配，余额记为**主题待配现金**：留在主题模块里，不挪给宽基和红利，也不为凑满而买。
  - 资料不足的方向是 0%。
  - 待配现金连续两期不为 0，在下一次半年复核里讨论是否缩小主题模块。
- **同一主题共用一个预算**：A 股、港股创新药算一个方向，现持的四只医药基金都计入创新药。
- **每个持有主题都要有目标权重**。只写"继续持有""长期看好"不算结论。
- **换定投对象不等于换旧仓**：
  - 只有涨幅、热度差异 → 不动；
  - 新主题略好 → 只倾斜新增。旧主题写"持有不投"，目标记为当前权重，计入 30%；
  - 明显更好 → 部分切换；
  - 逻辑失效 → 退出。
- **换手上限**：常规评审最多新进或退出一个主题。首期、逻辑失效的退出、超限纠偏不受此限。
- **按实际账户管理**（方案 §九 路径 A，用户 2026-10-02 确认）：
  - 主题目标按当前实际账户算，不按将来的 50 万算。
  - 主题实际高于目标时，报告给出每个主题的目标和偏离（百分点），并按研究结论排出先减哪个。排序只看逻辑强弱、与论点的错位，不看哪只盈利、哪只回本。
  - 已持有的不因此自动保留。
  - 单主题超过 15% 时提示超限，给出减至目标的建议。

## 3. 每期怎么做

1. **核对上期**
   - 上期 = 最近一份 `research/etf-YYYY-MM-DD-review.md`（v0.1 的 `*-monthly-review.md` 不算）。首期改读 `research/etf-cards/v1-archive/`。
   - 逐条核对上期台账里的失效条件：触发、未触发或无法判断。
2. **记分**（方案 §十一）：用快照 §6 收盘价，算上期至今三条线的指数涨跌（价格指数，不含分红）。
   - 主题模块：上期名单按目标权重，加上待配现金（按货币基金指数 `H11025.CSI`）；
   - 基准：A500 70% + 恒指 30%（方案把 30% 主题换成 21% A500 + 9% 恒指）；
   - 首期篮子不轮换：首期名单和待配现金一直不动。

   单期结果只记录，不下结论。每年 11 月评审汇总一年，主动研究有没有价值按方案 §十一 判断。
3. **8 个主题各填一行**，每期都填：
   - 基本面：改善 / 持平 / 恶化，附依据；
   - 估值：读数 + 口径，或"未知"；
   - 位置（辅助观察）：距 36 个月高点、距 200 日线。只作背景，不据此做任何决定；
   - 与底仓重叠：一句话说清在底仓之外多押了什么；
   - 结论。
4. **深度要点**写四类：名单上的主题、有变化的持有主题、拟新进的、拟减持或退出的。首期写全部持有主题。每个写五点：
   - **买到什么**：论点受益企业约占指数多少权重，观点与持仓错位在哪；
   - **判断**：
     - 一条盈利或现金流逻辑，以及 2–3 个关键变量；
     - 为什么是现在：比上次多了什么证据，预计何时兑现；
     - 至少 2 条证据、1 条反证，都标出处；
   - **价格**：
     - 估值位置，以及"当前价格要求多高增长"；
     - 名单主题和拟新进主题，再加 12 个月悲观 / 基准 / 乐观三种情景。每种写明盈利（或净资产）假设和估值假设，标为"假设"；
   - **组合影响**：与底仓、其他主题、用户提供的个股和私募的重叠（未提供写"未知"）；
   - **失效条件**：1–2 条可观测的条件。
5. **定名单**：三个条件都过才合格——
   - 基本面依据可核实，且落在指数主要持仓上；
   - 价格可以接受。估值"未知"算不过；同一主题另一条路线有估值的可以暂代（例如创新药港股路线暂用 A 股 931152），但须注明，且不上调目标；
   - 合并底仓后仍值得配。

   在此基础上：
   - 已持有且合格的主题优先延续；
   - 新进须"明显更好"：自己三条件全过，被替换的主题至少一条不过或失效条件已触发。只是略好的记"候补"，并写一句"出现什么证据就进入"；
   - 合格的多于名额时，写一句取舍理由；不够时写待配现金。
6. **定目标与处理**：每个持有主题一行，写目标权重和处理（按 §1）。没给持仓时只出名单。
7. **组合两项数**（有持仓时）：只报告，不设阈值。
   - 港股跨模块合计：恒指、港股通红利低波、恒生科技、港股创新药；
   - 方案 §八.2 压力情景下，当前结构与本期目标结构的损失。情景为 A500 −35%、科创50 −50%、恒指 −35%、红利低波 −25%、主题股票 −50%、现金 0。

## 4. 数据

- **快照**：评审前由用户在本地跑 `scripts/etf_data.py`。
  - 末行要有「快照完成」，且距评审日不超过 10 天。
  - 头行须为「ETF 框架 v2.0」（快照格式自 v2.0 未变），且快照里有 `H30184.CSI`、`931994.CSI`。否则是旧快照，须重跑。
- **快照引用范围**：
  - A 股主题的指数结构与估值只用 §3、§4（指数权重口径）；工具用 §5。
  - §6、§6b 只用收盘价（记分）和距高点、距 200 日线（辅助观察）。
  - 不引用 §1、§2、§4b，以及 §6b 的点位列。
- **联网资料**：
  - 先查原始资料：指数公司（中证、国证、恒生指数公司）、基金公司公告、上市公司公告、官方统计。媒体报道和搜索摘要只作线索；只拿到二手资料时写明"二手"。
  - 每条标 [出处, 日期]，区分已披露事实、第三方预测和自己的假设。
  - 查不到写"未知"，不编数字。
- **持仓**：用户给一行即可——各主题市值、主题待配现金、ETF 账户总值（不含黄金）。02800 按快照 §7 的港币中间价折算。个股、私募持仓可选。
- **工具**（方案 §十）：
  - 名单上每个主题写一只**定投工具**（代码、份额），本主题的新增资金只进这一只。已定的沿用上期台账，换工具时写理由。
  - 已持有跟踪该指数的基金、且核查合格的，继续用这只基金，不为统一名单而换；可以换到同一基金费率更低的份额。核查看快照 §5：年费、跟踪差异与误差、规模。
  - 新进主题，或已持有的基金核查不合格、偏离原因查不清时，比较跟踪同一指数的各只产品：年费、跟踪差异与误差、规模。
  - 每个定投工具记一只同指数备用工具；查不到写"未知"，列入下次要查。
  - 一个主题有多只基金时（例如创新药四只），写清哪只与论点最贴。需要减持时，研究上先减错位最大的。

## 5. 节奏

- 奇数月（1、3、5、7、9、11 月）各评审一次。首期在 2026-10，有了新快照就做。每年 11 月同时汇总年度记分。
- 提前评审只在三种情况下触发：失效条件触发、单主题超过 15%、指数或基金发生结构性变化。
- 框架只在规则或数据口径需要变化时修改；市场叙事变化写进报告，不改框架。

**执行侧接口**：ai_investment 的 `src/etf/plan.py` 读研究仓已合并 main 上最新一期报告，据此算每月的定投分配与卖出清单。下面几处是它依赖的格式，改动须两边同步：

- 两张表都按列名取值，主题一一对应，同一主题的「目标」相同。缺表、缺行、重复行、列数不够，执行侧一律报错，不猜。
- §1 主表：首列表头为「主题 / 现金」，取「目标」「存量」两列。
  - 「存量」以 不动 / 持有不投 / 部分切换 / 减至目标 / 退出 之一开头，冒号后可写具体说明（例如先减哪几只）。没给持仓时写「—」。
- 台账（标题含「台账」）：首列表头为「主题」，取「目标」「定投工具」两列。
  - 「目标」以百分数开头，可带括号说明，例如「0%（退出）」。目标取 0 / 5 / 10 / 15%。
    持有不投例外：写当前权重，可以是任意百分数（例如 7.3%），§1 主表同一主题写同一个数。
  - 目标 0% 的主题，处理只能是退出或减至目标。
  - 「定投工具」列：第一个 6 位代码是定投工具，不在名单上写「无」。括号里列出本主题其余**全部**持有代码，包括要减持、退出的，否则执行侧无法归属这些持仓。
  - 候补主题的名称带「候补」，执行侧会跳过它们。
- 「待配现金」两张表各一行，为 0% 也要写。目标须等于 30% 减去各主题目标之和；这一行是两张表的校验和，缺了执行侧会报错。
