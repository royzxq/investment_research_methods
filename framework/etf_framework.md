# ETF 调研框架 v1.1

> 第三条轨道（ETF / 指数基金），与期货、个股并列。canonical 文档：任何 AI 环节读本文件；改动只走分支 + PR。
> 配套：数据快照 `scripts/etf_data.py`、确定性计算 `scripts/etf_calc.py`、指数登记清单 `framework/etf_index_registry.json`。
>
> 对 **{{AS_OF_DATE}}** 的 ETF 组合（持仓 **{{HOLDINGS}}**，可缺）给出：每个配置方向的**调仓方向**（增配 / 维持 / 降配 / 退出 / 观察）、**建议目标权重**、
> **12 个月预期**（悲观 / 基准 / 乐观）、核心理由、关键变量与失效、复评条件。**本框架只产出研究结论：不给交易指令、金额、价格点位或时点，
> 不参与交易决策**——怎么买卖、何时买卖由用户决定（与个股框架只给 Price Map 同一定位）。
>
> 本框架不写任何市场环境假设。环境判断只存在于每期的调研报告里；市场叙事变了改报告，不改框架。
> 框架只在五种情况下改：结构性事实变了（编制规则、产品、税费、额度）、口径错了、年度评估给出证据（§7）、上期挂账的观察项到期、用户改组合基准（写明日期与理由）。

## 0. 决策链总览

数据快照（§2）→ 组合基准（§1）→ 排除优先（§3.1）→ 固定仓检查（§3.2）→ 主题六问与筛选（§3.3–§3.5）→ 方向判定（§4）→ 预期与压力（§5）→ 复评条件（§6）→ 结论输出（§8）

为什么是这个形状（本仓自己的证据）：
1. 个人在指数上没有信息优势，池内指数高度同向：31 个权益指数只相当于约 3.3 个独立押注，一半波动来自同一个因子（`research/etf-2026-09-19-pool-research.md`）。
   收益与风险主要由"持有多少中国权益、A 股与港股怎么分"决定，所以 70% 交给规则，主动研究只管 30% 的主题。
2. 预注册的择时规则验证里，估值分位阶梯、趋势闸门、定投趋势暂停全部被否；唯一通过的回撤阶梯靠长期持有现金取胜（`research/etf-2026-09-18-rule-validation.md`）。
   所以本框架不给点位、不设自动择时，方向只来自配置偏离与基本面研究。
3. 头号风险是被回测和叙事骗：主题判断先登记失效条件与目标，事后对照固定基准评估（§7）。

**AI 与代码的分工**：数字由代码产生（快照与 `etf_calc`），AI 负责读编制方案、写因果链、找反证、查观点与持仓的错位、比较主题、给方向与理由。
报告里的估值、情景回报、结构读数必须引自快照章节或 `etf_calc` 函数；查不到写"未知"，不用看似合理的数字填空。

## 1. 组合基准（用户方案 v1.0，2026-09-30）

方向的参照系。规模：ETF 总仓按 50 万规划（含盈立直持的 02800）；黄金约 1 万单列管理，不在本框架范围内；比例按实际市值、以"股票 ETF 市值 + 纳入本策略的现金"为分母。
只覆盖普通、非杠杆的被动股票 ETF；中国权益 ≤90% 的全资产约束不用于本 ETF 组合（用户 2026-09-30）。

| 模块 | 方向 | 目标 | 区间 |
|---|---|---:|---:|
| 长期指数底仓 | 中证A500 28% / 科创50 7% / 恒生指数 15% | 50% | 45–55% |
| 长期风格 | 红利低波（恒生港股通高股息低波动，现持仓口径） | 20% | 15–25% |
| 动态主题 | 主题股票 + 主题待配现金 | 30% | 25–35% |

- 固定 70% **不参与双月轮动**，不做 A/H 短期轮动、宽基估值择时、均线卖出；战略比例原则上每年复核一次，不因跑输一个季度删改。
  科创50 按宽基固定持有，但风险上是科创板倾斜（与半导体近 3 年周相关 0.97）。核心内部子项偏离超过 min(目标×25%, 5 个百分点)（A500 5 / 科创50 1.75 / 恒指 3.75）触发复核。
- 主题规则：单主题目标 5% 或 10%，15% 是例外须书面说明估值、把握和下行风险；常态持有 2–3 个，主题目标合计 ≤ 30%，余下是主题待配现金（不为凑满而买）；
  实际权重超过 15% 提前复核；资料不足的方向是 0%，不是象征性配置；常规评审最多新增或退出一个主题（逻辑证伪、超限纠偏、首期比较除外）。
- **主题研究池固定 8 个**，半年调整一次（6、12 月），加入须替换已有席位；同一主题共用一个预算（A 股、港股创新药是一个方向）：

| 方向 | 研究对象与边界 | 每次重点更新的变量 | 估值抓手 | 登记主指数 |
|---|---|---|---|---|
| 恒生科技 | 在恒指底仓之外加配港股科技（与恒指相关 0.93，波动约 1.4 倍） | 主要权重公司盈利、资本开支后的自由现金流、股东回报 | 正常盈利、现金流与增长假设 | `HKTECH` |
| 半导体 | 先研究较广泛的芯片路线；设备材料另做映射 | 需求与库存、收入及毛利率、设备订单与资本开支 | 周期位置与正常盈利 | 未登记（首期比较时实测登记） |
| 创新药 | A 股、港股路线比较，共用一个预算 | 产品商业化、授权款兑现、现金消耗与融资 | 分公司情景、现金与管线兑现 | `987018.CNI` / `931787.CSI` / `931152.CSI` / `399989.SZ` |
| 国防军工 | 核实现有国防基金对应指数 | 可验证订单与交付、利润、回款与应收账款 | 正常交付对应的盈利与现金流 | `399973.SZ` |
| 电网设备 | 设备企业，不与电力运营混用 | 中标与在手订单、收入兑现、利润率与回款 | 订单质量与可兑现盈利 | 未登记（首期比较时实测登记） |
| 主要消费 | 固定主要消费指数，不混用其他消费主题 | 量价、渠道库存、利润与现金流 | 正常盈利、增长与股息 | `000932.SH` |
| 工业有色 | 工业有色路线，不等同于铜价或金价 | 对应金属供需库存、企业产量成本、资本开支 | 中周期利润与商品价格情景 | `000819.SH`（含贵金属，核实工业有色口径） |
| 化工 | 核实现有产品对应指数，区分子行业 | 产品价差、产能利用率与扩产、现金流 | 正常价差下的盈利与现金流 | `000813.CSI` |

  观察项（不在研究池）：人工智能、通信、软件、机器人、光伏、电池、证券、新能源汽车。

## 2. 数据契约

快照与计算器的数字视为既定输入，AI 的工作是校验与判断，不采集、不计算。读快照先过三项：
① 时效——快照有「快照完成」行，AS_OF 与报告日相差不超过 10 天（过期请用户本地重跑 `scripts/etf_data.py`）；② 缺失——§0 缺口清单里与本期有关的项逐条写进报告，标 `[需人工补充]`；
③ 异常——与上一份快照相比跳变超出常理的读数标「存疑」。关键数据缺失时降低置信度，尚无仓位的主题证据不足可以直接给 0%。

- 区分**已披露事实、第三方预测、自己的假设**，记录数据所属期间与发布日期。数据优先用指数公司、基金公司、上市公司的正式资料；行情平台用于交叉检查，新闻只作线索。
- 估值口径：快照 §4 的自聚合 PE/PB 按**指数权重**调和加权，报告里的估值状态与情景倍数只用这一口径；§1 的乐咕与 tushare 读数是总市值加权（系统性偏低），只作跨源核对。
- 持仓：用户给出时用实际市值算各方向当前权重（港币按快照 §7 中间价折算）；没给时只出主题结论，组合层面的偏离写"持仓未提供"。

## 3. 研究规则

### 3.1 排除优先
任务不匹配、关键数据不可靠、工具门槛不过、主题预算已满或会超单主题上限——任一条成立，结论就是"不买 / 0%（原因）"，不许用低费率、大规模之类的优点抵消。不做总分排行。

### 3.2 固定仓（70%）
初次充分研究：指数样本范围、选样和加权、集中度、调整机制；基金跟踪质量、费用和交易条件（§3.6）。之后半年复核，规则或产品重大变化时提前。
**不设估值开关**：估值用于理解长期回报与风险，写进预期，不生成"贵了停投、便宜加倍"的方向。固定仓的方向只由配置偏离决定（§4）。

### 3.3 主题六问（每次评审逐席回答）

| 研究问题 | 必须形成的输出 |
|---|---|
| 买到什么？ | 指数规则、主要公司和行业权重；受益企业是否真的在指数里（观点与持仓的错位度） |
| 为什么能赚钱？ | 一条可验证的盈利或现金流逻辑，配套 2–3 个关键变量 |
| 为什么是现在？ | 相比上次新增了什么证据，预计何时兑现 |
| 当前价格划算吗？ | 12 个月悲观、基准、乐观情景，列明盈利与估值假设（§5） |
| 对组合有何影响？ | 与固定仓、其他主题、个股的重叠，压力损失贡献 |
| 判断错了怎么办？ | 降配、退出条件，下次需要验证的事实 |

行业数据必须映射到指数持仓并写明覆盖了多少权重；不能用三家表现好的公司替整个指数下结论。成分已在个股研究池内的（快照 §3 研究覆盖率）直接复用个股研究；
归档的 v0.1 卡（`research/etf-cards/v1-archive/`）里的论点与反证可作输入，数字须按当期快照重核。

### 3.4 筛选：条件，不打分
一个主题给"增配"，须同时满足：有可核实的基本面依据；当前价格仍提供可接受的收益风险条件；合并底仓后仍值得额外配置。
不设"80 分自动买入"，不为每次研究都有成果而强行换冠军。**维持、观察、0% 都是正常结论。**技术信息（近 3–6 个月含分红表现、相对强弱、波动与回撤）只作辅助，不单独构成方向。

### 3.5 底层资产、指数与估值
- **因果链**：下游需求 → 订单与产能利用率 → 价格与利润率 → 成分公司盈利与现金流 → 当前价格是否已反映。回答：能否传导到指数实际持有公司的股东回报？市场是否已提前付钱？
  产出 **1 句主判断 + 3 条支撑证据 + 2 条反证**。
- **指数四问**：① 选什么（样本空间、行业定义、目标子行业占多大权重）；② 怎么加权（单一成分与行业上限，额外承担了什么风险）；③ 何时换仓（频率、缓冲区、换手，快照 §3）；
  ④ 历史业绩能不能用（区分回溯期、正式发布后、基金成立后，回溯期不作证据）。
- **估值方法**：

| 类型 | 方法 | 要防的误判 |
|---|---|---|
| 宽基 | 回报分解 + 股债利差为主，PE/PB 分位为辅 | 只看点位不看盈利与结构 |
| 成长/主题 | 情景 + 反向估值（当前价格要求多高增长） | 把产业空间当股东收益 |
| 周期（有色、化工、半导体、电网设备等） | PB 与中周期利润，不同周期位置做压力测试 | 景气顶部利润使 PE 看起来很低 |
| 红利/价值 | 可持续股东回报、分红覆盖、行业集中度 | 高股息率 = 低风险 |
| 亏损公司多的主题（创新药等） | 分公司情景、现金与管线兑现 | 只看剔除亏损公司后的市盈率 |

  分位一律用扩张窗，历史不足 5 年不出结论，引用时写明口径、样本数、起点；亏损股权重（快照 §4）超过 15% 的指数，PE 分位降级为参考、改看 PB。

### 3.6 工具比选（研究结论的一部分，不是下单）
不同指数比"谁更准确表达观点"，同指数比"谁更可靠更便宜"，两者不混；给首选、备选与落选原因。看 A/C 份额（长期持有 A 类通常更便宜）、
费用与跟踪差异/跟踪误差（同窗口、同币种、注明是否含分红，剔除成立后半年建仓期，快照 §5）、赎回费阶梯、QDII 限购、规模与清盘风险。
税：基金分红对个人暂免个税；盈立直持港股 ETF 无红利税，港股通渠道 20%——红利低波股息率高，这项税差要写进工具结论。
境外直持的工具（02800）卖出所得不能直接转为人民币基金，降配建议注明"以新增资金稀释为主"。

## 4. 方向判定

| 方向 | 固定仓（只由配置偏离决定） | 主题（由 §3 研究决定） |
|---|---|---|
| **增配** | 模块低于区间下沿，或子项低于目标超过复核阈值 | 三条件同时满足，且明显优于现有选择；给新目标（5/10，例外 15） |
| **维持** | 在区间内（新增资金自然向缺口倾斜，不必调整存量） | 原逻辑成立；新方向只是略好、或只有涨幅热度差异 |
| **降配** | 模块高于区间上沿，或子项高于目标超过复核阈值 | 目标下调（新方向明显更适合、估值透支、超过单主题上限或主题合计超 30%） |
| **退出** | 不适用（战略比例是规则） | 逻辑失效或风险不可接受，目标 0%，不等回本或季度日历 |
| **观察** | — | 研究池内、不持有，证据未满足三条件 |

- 每个主题同时写**上次目标 → 建议目标**；只说"看好""继续关注"不算结论。轻微偏好变化只影响新增资金的倾斜，明显目标变化才建议调整存量，逻辑失效直接建议处理存量——报告说明属于哪一种。
- 组合层面：主题合计相对 30%、各模块相对区间、港股合计（红利低波按港股计，跨模块统计）、同簇合并敞口（恒生科技之于恒指、半导体之于科创50）都要给出方向。

## 5. 预期与压力

- **主题**：12 个月三情景（`etf_calc.scenario_annual_return`，`years = 1`）。基准情景必须假设估值零变化；期末倍数只取快照分位点；盈利增长、股息率是假设并如实标注。
- **固定仓**：回报分解给长期（与持有期相称的年数）三情景，作为长期预期的说明，不生成方向。
- **组合压力**（`etf_calc.joint_stress_loss`，按建议目标权重）：方案情景 A500 −35% / 科创50 −50% / 恒指 −35% / 红利低波 −25% / 主题 −50%，合计约 38.55%；
  历史情景 −72% / −70% / −66% / −50%（估计）/ −70%，合计约 66%。两者都不是预测或上限，用来说明方向调整前后风险怎么变；用户接受约 30% 回撤，30% 若是硬约束只能降低权益比例。

## 6. 复评与失效条件

- 每个持有或建议增配的主题至少登记一条可观测的失效条件（逻辑失效 → 退出；目标下调或超限 → 降配；工具变差 → 换同指数产品）和下一次复评时间。
- 提前复评的触发：主题实际权重超过 15%；模块超出区间；用户告知账户回撤（剔除入出金）达到 20% / 25% / 30%（专项复核损失来源与风险目标，不是止损线）；
  指数编制规则、基金费率或运作、税费与额度等结构性事实变化。

## 7. 节奏与评估

| 时间 | 内容 |
|---|---|
| 每月 | 本地出快照（只为保持数据新鲜，不必然出报告） |
| 双月（1、3、5、7、9、11 月） | 主题评审报告。**5、9、11 月**在 A 股报告披露截止（4/30、8/31、10/31）后做 8 主题全量比较；1、3、7 月只更新已持有与被触发的方向 |
| 每季度末 | 组合层面检查：模块与子项偏离、港股合计、同簇重叠、两套压力；相关矩阵按候选池调研方法重算 |
| 每半年（6、12 月） | 工具、指数规则、研究池（席位调整只在此时）、重叠；连续两次评审找不到足够合格主题时，讨论是否缩小主题模块 |
| 每年（12 月） | 主题研究是否创造价值：对照预先固定的基准（A500 49% / 科创50 7% / 恒指 24% / 红利低波 20%，即把 30% 主题换成 21% A500 + 9% 恒指）与"初始主题篮子不轮换"，用户提供收益数据；运行 12–24 个月仍看不到净价值，建议缩小主题模块 |

## 8. 输出格式（ETF 调研结果）

报告写入 `research/etf-<AS_OF_DATE>-review.md`，结构固定：

1. **摘要**：一句话结论；本期类型（全量 / 只更新持有与触发项 / 季度 / 半年 / 年度）；快照文件与缺口。
2. **组合现状 vs 基准**（持仓提供时）：各方向当前权重、目标、区间、偏离与方向；主题合计；港股合计；同簇合并敞口。
3. **固定仓结论**：A500 / 科创50 / 恒指 / 红利低波 各一行——方向、理由（偏离读数）、长期预期、工具结论。
4. **主题结论表**：

   | 方向 | 结论 | 上次目标 → 建议目标 | 12 个月预期（悲观 / 基准 / 乐观） | 核心理由 | 关键变量 | 失效条件 | 下次复评 |
   |---|---|---|---|---|---|---|---|

   主题目标合计与主题待配现金（30% − 合计）及其理由；为什么没选其他候选；本期是否超过"一次最多变动一个主题"的限制及理由。
5. **逐席六问摘要**（全量期 8 席都写，其余只写更新的席位）：主判断 + 3 证据 + 2 反证、指数匹配与错位、估值状态与情景、工具结论。
6. **组合影响与压力**：建议目标下两套压力损失、与调整前对比；风险重叠说明。
7. **复评条件与下次评审时间**；`[需人工补充]` 清单。

报告不写：买卖金额、交易清单、下单时点、指数点位锚点、分批计划——这些属于用户的交易决策。
