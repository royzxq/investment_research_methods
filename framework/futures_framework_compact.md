R-ID继续沿用canonical的稳定锚点：0D、0.3#1–#31、①–⑤、D8–D15、Step5及Step6；不重编。`[源: …]`标注规则出处。§1为固定规则，§2为品种差异，§3为带日期的配置/历史状态。**0D有限数据协议优先于旧状态中的全量必刷、待补优先级和不许改规则指令**。本次是方法更新，未重做市场调研，历史触发不能直接变成本周触发。[源: 0D、0)版本]

## 0. 决策链总览

1. 识别允许的品种与模型，区分可研究、临时缺项、研究观察和信号席；不以专业数据不可得冻结全池。[§1.1]
2. 核验行情/产业证据日期、单位与口径；先纠错，再判断市场变化。记录具体规则的适用与豁免。[§1.11]
3. 用既有策略条件筛选；A高分位只是研究对象，不自动给方向。[§1.4–§1.6]
4. 明确模型、独立产业支持/反证、事前确认条件、Entry/SL/TP及期限；按固定权重归一化评分，不能凭缺账户停止研究。[§1.7–§1.8]
5. 核适用事件、真实执行报价、账户持仓挂单、风险/保证金/限仓及双腿压力预案；金额折减后一次取整。[§1.2、§1.3、§1.8、§1.10]
6. 输出signal与status、已知否决和未知项；只有完整核验才可ready，有经核实持仓才执行管理。[§1.9、§1.12]

## 1. 固定规则层

### 1.1 有限数据、池归属与路由 [源: 0D、0)分层、0.0]

默认 `research_mode=public_data`：优先MA/RB；M/SR/CF按已有路由、季节/事件窗口和独立公开证据激活。AU/SC仅作信号。公开数据简化不扩C池、不开放continuation、不复活用户已排除品种。

| data_feasibility | 判定与处置 |
|---|---|
| available | 模型最低研究数据齐备；继续研究、评分、计划，不代表账户可执行 |
| temporary_gap | 本来可取得的必要数据本期缺失、过期或冲突；仅相关候选incomplete |
| research_only | 必要专业依赖无法持续取得或无已许可路由；退出本轮执行候选，保留已知阻断、原机会ID、原因与复活条件，不扩大为全池缺项 |

每候选最低包为现有行情/合约资料＋一项相关、独立于该期价的当前产业事实＋相关公开日历/规则；不要求库存、利润、开工、船流、战争险整链齐备。专业增强项不可得不加扣分/冻结/乘数，不进入完整性分母；强因果模型确需它时保留原门并转研究观察。实际价格、规格、真实SL/成本、账户/挂单、保证金/限仓、执行压力不能猜。

- 核心池维护品种卡、可交易性、阶梯与适用事件；准入=#1期限+#2流动性+#31真实计划/容量+驱动确实作用于该合约月份。
- 备选维护可交易性和品种卡，有独立驱动才升级，升级首期系数0.5；2ATR只作扫描参考。
- 信号席不建仓。池外仅记退出理由与复活条件，不跑全量取数；一般复活先独立驱动+#1/#2+2ATR预检容量，再入备选，#31仍待完整计划。
- H/④/D15/②''/#28、曲线、JM月差/JM-RB、PS/LH/LC、C单边、SI-E、SI/AL-F当前交易用途休眠；权益/跨资产信息仅作相关商品背景。休眠模型无数据不占活跃待裁决清单。

| 近月 | 已出清叙事的回归、事件落地确认后的冲击、近月现货验证；不承载远月政策叙事，近月政策多头受#27 |

### 1.2 事件与低敞口 [源: 0.0b、0.1、4.0]

开仓/加仓前必须核未来10个交易日节点、未落地节点、T-1对冲/减仓预案、节点±1新开限制；实际完成后才能填“事件日历核对=已完成”。官方发布时间须换算北京时间，再映射交易日；不以旧周报日期代核。已到期事件没有新证据不得自动续冻；仍有效的许可冻结不能因缺数据解除。

低敞口任一适用触发成立→§1.8的组合金额上限；多项触发不重复扣减，不再添加单笔低敞口乘数。触发为：宏观节点T-1未对冲金融/准金融单边；能源单日脉冲[#30]；存量carry双杀[D15]；高密度簇且当周有未落地离散催化；policy_calendar_density=高且当周≥2政策节点未落地；liquidity_regime=收缩；地缘/权益夜盘跳空风险；波动升档且临近事件T-3；收缩证伪[D14]；创新高且周涨前10%；保证金/限仓公告±1日；ATR分位极差>50且单边当日未重校准；地缘双轴质变日及次日；跨资产再校准下依赖跨资产对冲；#28重新冻结。休眠门只在复活后适用。[源: 0.1低敞口清单]

双轴质变：霍尔木兹持续<10艘/日、回升至10日均以上、停火/重开、扩大打击/再袭船；俄乌停火、出口禁令扩汽油/延期/解除、更大打击。任一方向均做跳空预案，不预设盈利方向；定量事实未核不假报其门已过。地缘事件日±1的能源新开限制对MA两条A证据路线均适用。敏感品种周五前核对冲/减仓；跨资产再校准时依赖对冲的组合按无相关性保护核验。交易所公告±1日受影响品种新开门槛+0.3，公告日检视占用。解除低敞口须复评全部仍有效触发。[源: 0D、0.3#26、0.1]

### 1.3 合约、期限与换月 [源: 0)阶梯及注a–e、0.2、Step5-A、6.8]

- #1按trade_cal真实交易日；#2按≤行情基准日近20交易日均量，单日放量不算。
- 方向性执行腿为主力月阶梯中剩余td≥20+策略持仓上限的最近月份；D上限30日时需≥50td。
- 结构退出/重建唯一边界为近腿触#1（<20交易日）或主力换月，先到为准，整对下滚。计划写具体最晚退出日及预定最短/最长持有期；不能静默缩短已定计划过门。A旧30–60日仅参考，public_data优先研究有依据的5–20交易日计划。
- 目标腿须过#2，不足退到最近能过月份并标降级。阶梯日期或主力换月先到即执行，不等周报；执行日重核流动性、期限与新计划。触发前3个交易日旧腿单边新开从严。
- “重建”是用新对重新核历史样本、日期、流动性、方向与SL/TP，可回溯新对已有历史；不把分位赋0，不新增未定义的等待天数，不继承旧对分位和许可。
- A同期样本固定过去3年、同月合约对、各年目标日±20交易日；每年期望41个，至少33个（80%向上取整）有效唯一同日两腿样本。40/41仅质量警示；任一年<33、缺年、重复/非法日期或同对口径不可核→incomplete，不补值、不缩年数/换窗口。分位按实际有效原值算；这是可得性治理下限，不保证独立性/统计显著，也不要求换月后新等41天。[源: 3.1样本验收]
- SC信号按主力–次月，不受#1/#2建仓门；INE近12个月逐月、更远按季挂牌，缺月份时取下一实际挂牌月。AU亦仅信号。**RB实际执行腿没有信号席期限豁免**。
- 周度记录期限、均量、适用最低证据、precheck、交易所约束；脚本2ATR金额/参考数量不代真实SL风险和最终手数。


#### 仓位：唯一计算出处 [源: Step5仓位、#31]

金额均人民币元，单腿单位为1手，A为近远各1手的一组。ACCOUNT_SIZE用于测算时须是已核实际净值；配置150000不是账户核验。计划止损损失不是保证的最大损失。

```text
trade_cap = ACCOUNT_SIZE × 3.5%
portfolio_cap_normal = ACCOUNT_SIZE × 3.5%
low_exposure_cap = LOW_EXPOSURE_RISK_CAP  # 用户配置5000元
portfolio_cap = min(portfolio_cap_normal, low_exposure_cap) if RISK_REGIME == low_exposure else portfolio_cap_normal
risk_unit = abs(Entry−SL) × multiplier + round_trip_cost  # A须先过上面的方向式
factor_product = strategy_factor × 各适用场景金额系数
trade_effective_budget = trade_cap × factor_product
used_open_risk = sum(各持仓剩余计划止损风险，逐项≥0)
reserved_order_risk = sum(未成交挂单及部分成交未计持仓部分的预留风险，逐项≥0)
portfolio_remaining = max(0, portfolio_cap−used_open_risk−reserved_order_risk)
existing_trade_risk = 本交易已有持仓及挂单风险  # 已包含在组合占用内；核实新交易才填0
trade_remaining = max(0, trade_effective_budget−existing_trade_risk)
candidate_budget = min(trade_remaining, portfolio_remaining)
risk_lots = floor(candidate_budget / risk_unit)  # 仅此一次风险取整
final_lots = min(risk_lots, margin_capacity_lots, position_limit_capacity_lots)
```

- 单腿滑点预算=2×slippage_tick×tick_value，另加实际开平手续费；A两腿成本按本节A式。止损先由失效逻辑确定，不能反推窄SL或放宽SL凑数量。
- 系数组只接受strategy、D11、D12、D13、D14、D15、event_window、exchange_buffer、promotion、driver_weakness、MA_oil_guard、seasonal_adx、policy_adverse、equity_confirmation、correlation_recalibration。D12高波/T-3/共振先取唯一最严值，event_window只计独立T-1纪律；driver_weakness含同源背离；未知组名/重复JSON键拒绝，不用别名重复乘风险。低敞口不进乘数乘积。
- 账户快照须已核、与测算同一北京时间日期、不晚于测算，有新成交/撤单后刷新。无持仓/挂单须明确核实才可填空列表；未知则相关风险、组合剩余和final_lots均null。配对组合计一次，裸腿按单边，跨交易风险相加，不因相反方向/浮盈/未验证相关性抵消；盈利仓按当前估值到SL的不利损失＋成本，不能填负值。

### 1.10 gap_ratio与压力核验 [源: 1.2]

`gap_ratio=stressed_loss/planned_loss`，同一手/组、同一人民币费用口径；planned_loss为有效计划真实止损损失，stressed_loss=max(planned_loss,压力退出损失＋压力成本)。场景注明报价/历史跳空/涨跌停依据及假设，不把估计当预测，不以无新闻假设损失0。结构核同一时点双腿与单腿事故，不拼不同时间的有利报价。可用现有日线/终端及公开交易规则，研究可列待核场景；执行前缺必要场景/报价仍incomplete。

两数依次为轻仓复评线/淘汰线：超第一线须具体减额方案并核绝对压力损失/可用资金，缺金额承受依据仍incomplete，不能只写轻仓；减手数不改变单位gap_ratio，不能据此绕过第二线，超第二线否决。单一收紧值为当条件的淘汰线。阈值是治理参数，新计算口径须影子记录复评，压力损失非保证最大损失。

### 1.12 状态、审计与最小报告 [源: 4.3–4.4、0D]
