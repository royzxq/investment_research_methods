# 期货研究执行导航 v3.0

方法日期：2026-10-11（Asia/Shanghai）。与[完整版](futures_framework.md)共用30个规则锚，执行条件等价；取证/API见[数据协议](FUTURES_DATA_PROTOCOL.md)。当前信号与账户未重算，见末节。新参数待验证，不代表已回测盈利。

## 0. 决策链总览

<a id="r-v3-scope"></a>
只用T顺势`trend`与V经济回归`economic_reversion`：**价格筛选→产业论证→最多2份计划→执行风险→账户容量**。研究期限最多20交易日；无日内、期权、跨品种套利、股指carry。允许no_signal，不凑交易；账户缺失不阻前序研究。新规则仅前瞻生效，旧行情可离线检验，不回填历史建议；工具不交易。

<a id="r-v3-pool"></a>
| 层级 | 品种 | 允许模型 |
|---|---|---|
| 优先 | M豆粕、RB螺纹 | 双向T；RB另有V，M无V |
| 常规 | MA甲醇 | 双向T/V |
| 常备次级 | SR白糖、CF棉花 | 双向T；SR另有V，CF无V |
| 信号参考 | AU黄金、SC原油 | 不交易，仅解释实际候选风险 |

V只限MA/RB/SR同品种近远月1:1。JM及其他品种/表达均在池外，不每周必刷；扩池须明确修订。AU不交易、JM移除、SR/CF常备的用户裁决保留。

<a id="r-v3-workflow"></a>
每期5品种T筛选、3类有可解释错价的月差V筛选，记录未覆盖原因。最多深入2个独立机会，跨周沿用opportunity_id；未触发可早停，未知不冒充未触发。周度维护产业假设、每交易日收盘/入场前刷新机械信号与事件；仅周更须披露监测空窗。允许最多2份未触发条件观察计划（突破价/产业/失效条件），仍no_signal；不顺延2日信号。本次不创建自动化。

| 必要条件 | 核什么 |
|---|---|
| G1 | 范围、真实合约、期限和流动性 |
| G2 | 固定价格信号＋独立当前产业事实＋最强反证 |
| G3 | Entry范围、SL、成本、退出规则、有效期和最晚退出日 |
| G4 | 当前报价、事件、跳空、双腿方案及公开合约规则 |
| G5 | 真实账户、持仓挂单、单笔/组合剩余预算 |
| G6 | 风险、保证金、限仓、执行/压力容量共同决定最终≥1手/组 |

六组条件逐项pass/fail/unknown，非评分；正常隔夜不再多设门。必要缺项不能用好分数补，账户后置仍须尽量完成G1–G4。账户专属经纪商实收保证金、资金、账户限额归G5/G6，勿挂回G4；账户绝对压力承受金额归G5/G6；研究方能取得的报价/场景/成本缺口自行补。

## 1. 数据与研究路线

<a id="r-v3-data"></a>
真实合约/交易所/交易日/抓取时间齐全，close、settle、pre_settle分开。T用原合约完整OHLC，V用同日同对settle；不拼主力、不换合约沿用指标、不把盘后结算当成交。日线唯一连续、对照交易日历；缺值不补0，非交易日用最新已完成日。

产业事实附原发布者/链接、观察期/发布时间、单位/地域/样本/比较期；未读摘要只作线索，可信转引注明口径限制；月值不外推周变、未到官方发布时间不算失败。全国旬价不能直接减期货充当地交割基差。取证/计算/论证/账户各自留痕。

<a id="r-v3-calendar"></a>
使用真实交易所日历，夜盘归所属交易日。事件记官方时区、北京时间、首次国内可交易时刻、国内T；先映射再算T±n。最后交易日、自然人/经纪商退出和休市按现行规则核；不以普通工作日替代。只有与候选相关的事件才套窗口。

<a id="r-v3-economics"></a>
T最低为1项独立于期货走势、方向相关的当前产业事实＋最强反证。“当前”=已发布最新适用周期且注明时滞；不无限续旧新闻，不要求全链数据或全链同向。计划依赖的变量才是必要输入：关键缺项unknown，主因被推翻fail，非致命分歧可折预算。专业数据不可持续取得则公开替代验证或research_only结案，不能用不等价代理假装完成。

| 品种 | 研究链与双向路线 | 防误读 |
|---|---|---|
| M重点 | 到港/大豆库存→压榨与粕供应→粕库存、提货/成交、当地基差。去库且提货改善/供应确减可支持多；到港压榨恢复、累库/基差走弱可支持空 | 大豆紧不等于粕紧；减产去库非需求强；油强促压榨可能增粕。CASDE/USDA背景须证明传导，优先国内公开事实 |
| RB重点 | 同口径螺纹产量→厂库+社库→表需/成交→同地区规格现货/基差。需求改善或可核减产支持多；增产到货但需求弱、累库/现货弱支持空 | 五大材非螺纹、铁水非螺纹产量；减产去库非需求复苏；表需残差非成交，政策/焦炭涨价不能独立证明短缺 |
| MA | 装置、到港、港库、交割供给解释T/V | 回归必须有独立收敛机制，地缘只是适用风险/证据 |
| SR / CF | SR产销、库存、榨季、交割供给；CF新棉上市、纺织需求、库存、基差 | 季节/成本/事件只解释T/V，不另建固定月份策略 |

RB V补近远月供需、可交割供应、持有成本/区域基差，M本版先做T。只需可检验因果链，库存/基差/产量/成交不全列必查。

<a id="r-v3-quality"></a>
无加权总分、D1–D15、4.0/4.2/4.5隔夜门。`evidence_quality`：strong=多项独立一致，adequate=最低因果链成立且无决定反证，weak=非致命分歧（market_risk=0.5）。关键缺项/已证伪不能借weak过门。转引同源不算独立。按完整性→证据→成本/执行排序，不增准入门。

## 2. 固定模型

<a id="r-v3-signal-t"></a>
**T双向信号**：同一真实合约t日close严格`>前20完整日最高high`为long，严格`<前20完整日最低low`为short；排除t，相等不触发。G2还须独立产业依据。创新高/低不否决，不加ADX、D8、250日高或均线门。

统一61根连续完整OHLC。`TR=max(high−low,|high−前close|,|low−前close|)`；固定61日的60个TR，首20均值初始化，再40次`ATR=(19×前ATR+TR)/20`。不得混旧EWM或含t的H20/L20。

<a id="r-v3-plan-t"></a>
T在信号后第1–2交易日可入场；`|Entry−signal_close|≤0.5×ATR20(t)`，且long Entry>U20、short Entry<L20，范围取二者交集向内对齐tick。超价/过期/逻辑失效取消，不顺延等回价。使用下一可交易时段的计划报价，不报t日已成交。

初始SL=long `Entry−2ATR`、short `Entry+2ATR`，按tick向不利方向取整（long下、short上）；实际Entry变化重算，不能缩SL凑手数。`targets=null`，无TP/净R门。

入场后每个完整日收盘取最近10完整日long最低low/short最高high，下一交易时段生效，只收紧；第一次不早于入场日收盘，记录10日范围及生效时间，禁未完成日/盘中回填。事前latest_exit晚于entry日（SL/证伪可当天退）；入场日算1，第20交易日收盘前退出，与更早合约/事件/逻辑边界取最早并写latest_exit_date。SL触发按可成交价退出，不保证SL成交；固定20/10/2/0.5参数不周周变。

<a id="r-v3-signal-v"></a>
**V双向信号**：MA/RB/SR同品种1:1，`S=近settle−远settle`元/吨，一组各1手。short卖近买远，long买近卖远，S可负。

事前冻结经济锚`[low,high]`、适用月份/截止、来源/观察日、计算、5–20交易日内收敛机制、最强反证和SL依据。锚来自现货/交割供给、仓储资金跨期成本或近远供需差，核储运交割可实现性及品级/地区差；contango成本约束不能对称当backwardation上界。锚区分可复算成本边界/供需修复情景区间，后者列价格转换假设与不确定性，数量库存非公允价差，单侧边界不复制成对称区间；仅有方向则T/观察不硬造V。5日是机制预期下界，不妨碍到价/止损提前退出。

`short：S(t)>high 且 S(t)<min(S(t−1),S(t−2))`；`long：S(t)<low 且 S(t)>max(S(t−1),S(t−2))`。需3个完整同对日，相等不触发。历史高低分位/季节只背景，不单独给方向，不强制3年×41样本。不能事后改锚或借V做价差趋势。

<a id="r-v3-plan-v"></a>
信号后2交易日有效。short `SL>Entry>target=high`；long `SL<Entry<target=low`，实际Entry仍在锚外，entry_range事前明确可单点。SL是有解释的经济失效价；Entry/SL/目标按tick有效，经济锚报价取整须事前说明，不用小数虚增R。目标取近侧锚，不移到远侧/分位/理想价凑R。

```text
side=+1(long)/−1(short)
cost=两腿开平全部费用+滑点；滑点≥4×tick_value（每腿开平各1tick），实估更大取更大
risk_unit=side×(Entry−SL)×multiplier+cost
net_reward=side×(target−Entry)×multiplier−cost
net_R=net_reward/risk_unit≥2.5
```

两腿同乘数，tick/费用核实际。最长20交易日，入场算1；合约窗口须覆盖所声明5–20日机制，不事后缩计划。Entry/SL/target、范围、有效期、具体最晚退出、双腿预案齐全才成案。实际价差变化重验R/风险/容量，不拼异步有利价。全entry_range须在SL/锚之间且最差点净R≥2.5（short下界/long上界），否则收窄可单点。V净R不变成T隐藏门。

## 3. 风险预算与执行

<a id="r-v3-expiry"></a>
各腿距最后交易日≥20交易日，计划在跌入`<20`前完成，并遵守更早自然人/经纪商/交割/限仓边界。记录最后交易日、强制退出日、可持有日数；剩20日不等于可持20日。

<a id="r-v3-liquidity"></a>
每腿近20完整交易日均量≥10,000手，再核真实盘口/报价/数量可成交。涨跌停无法退出、双腿不能处置则不新开；报价未知执行unknown。禁止同品种多个近远层重复做方向暴露；换月/对冲不免风险。

<a id="r-v3-budget"></a>
真实当日权益E，`B=E×3.5%`为单笔和组合上限；低暴露组合`min(B,5000元)`，正常B。相关重大事件风险未结束、或实际持仓/待开候选已核高波动时低暴露；只有证据分歧不自动触发。按当期证据解除，unknown不默认normal；低暴露不再全面禁止单边。

```text
trade_cap=B×strategy×market_risk×exchange_buffer
remaining_trade=max(0,trade_cap−本机会持仓/挂单风险)
remaining_portfolio=max(0,portfolio_cap−全部持仓−全部未撤挂单保留风险)
risk_lots=floor(min(remaining_trade,remaining_portfolio)/risk_unit)
final_lots=min(risk_lots,可新增保证金/限仓/执行/压力及适用周末整数容量)
```

金额汇合后只floor一次；risk_unit>0，T/V均含开平费用滑点；T至少2tick_value（开平各1tick），实估更高取更高。单笔与组合两道上限不在同一组合重复扣仓。浮盈/相关性/结构不自动抵其他风险；存量按当前价至有效SL的非负潜在损失+退出成本，不用浮盈增加额度。

<a id="r-v3-factors"></a>
仅3因素：`strategy=0.7`；`market_risk=1或0.5`（高波动/相关持续事件/非致命证据分歧任一成立0.5，多个仍一次；三项核齐，都解除为1）；`exchange_buffer=1或0.8`（实际提保/收紧限仓覆盖0.8，按公告条件与经纪商实收解除）。旧D因素不能混入。必要判定缺项仍补核。

高波动T=`同合约log日收益样本SD20/SD60>1.3`，V=`同对价差日变动样本SD20/SD60>1.3`；61连续有效值，分母0等unknown，相等不触发，不对负/零S取log；无需年化。SL距离与预算反映波动后不再扣分/抬门；费用、压力、保证金/限仓仍独立核真实约束。

<a id="r-v3-account"></a>
当日带来源/时区且不晚于、接近sizing_at的账户快照：权益/可用资金、全部仓/单、SL/风险归属、保证金、费用、限仓、系数。空仓空单也须核，禁推断0。成交/挂单/报价/风控变化即重算，当日快照非自动有效。未知final_lots=null，G1–G4继续具体化。

<a id="r-v3-margin"></a>
新增后总保证金≤权益60%，提保覆盖品种合计≤20%，任何适用交易所/经纪商限仓≤80%，取严。未确认双腿优惠按两腿分别占用；自然人不借产业/套保豁免。任一容量<1则blocked，未知非0/无限；交易所最低非经纪商实收。

<a id="r-v3-gap"></a>
`gap_ratio=stressed_loss/planned_loss`同一手/组人民币含成本；planned是真SL损失，stressed=`max(planned,不利压力退出损失+压力成本)`。场景/报价/跳空或涨跌停依据/假设齐全，非承诺最大亏损，无新闻不能填1。

MA轻仓/淘汰线1.3/1.8，RB/M/SR/CF为1.5/2.0。超过第一线须具体减额、账户绝对压力承受金额并核可用资金；缺依据unknown。超过第二线否决，减手数不能降单位ratio。相关重大事件T−1至T+1淘汰线MA1.2、其余1.3，同时冻结新开，仍复核存量。MA无有效对冲跨周末单仓planned_loss≤B×30%，周五收盘前减至以内/退出，与其他容量取严。

<a id="r-v3-pair"></a>
V事前写两腿限价、最大总滑点、裸腿时限、未成交撤单/平裸腿；只能完整1:1享价差风险，裸腿全额方向风险并即时处置。压力含反向跳变、单腿不可成交、扩板提保；优惠/止损单/对冲未生效不算保护。不能监控/执行预案不ready，不拼异步有利价。

<a id="r-v3-event"></a>
候选相关重大数据/政策/交易所风控/突发供给事件，国内T−1至T+1不新开；存量提前压力预案，不能承受就减/退。M供应事件如WASDE、RB实质供给政策、MA装置地缘分别论证，CPI/FOMC非全池自动冻结。记录相关性/T/终点/首次恢复日，无无限“事件密集”。窗后只能用原2日有效期剩余，过期等新信号；风险持续则更新反证/压力/market_risk，不恢复旧永久方向禁令。现行法定/交易所限制不因窗口结束解除。

## 4. 管理、输出与验证

<a id="r-v3-stop"></a>
建仓即确定SL及可执行监控/下单；触发按可成交价退出。禁加宽止损、亏损摊平、缩SL凑手数。T只收紧，V到SL或经济逻辑证伪即退。跳过SL/涨跌停未成交要记风险、走预案，不虚报SL成交。

<a id="r-v3-manage"></a>
每持仓日收盘及重大事件后核SL/风险/期限/保证金/反证。T按通道/20日/逻辑最早退，不强制1R/2R止盈；V按锚目标/SL/时间/机制最早退，禁默移目标。“MA库存升一律减半”退役，按方向判断。更新不放宽存量风险，超限减/退；账户未知只给条件指令不报已执行。

<a id="r-v3-roll"></a>
期限/流动性需换腿则结束旧计划，新腿重算历史/信号/锚/成本/风险，不承接旧指标、分位、日期或手数。新腿既有历史可用，无额外20/60日等待，不足列缺口。真实旧存量先核账户，保留有效止损并记迁移，不因升级加仓/放风险。

<a id="r-v3-status"></a>
| 状态 | 必要条件 |
|---|---|
| no_signal | 筛选已核未触发，无影响该判断的必要未知；列方向/筛选读数/下次触发，可不做后续门 |
| incomplete | 必要非账户未知或研究未成案；fail也同时留痕 |
| awaiting_account | triggered、G1–G4全pass、完整计划、仅G5/G6账户未知；final_lots=null |
| blocked | 必要核验齐全无unknown，有已知硬失败；列所有阻断/解除 |
| ready | G1–G6全pass、当日账户、final_lots整数≥1；交易前刷新 |

fail+necessary unknown仍incomplete，不丢fail。未触发不等于反证、也不外推全品种无机会。另列data_feasibility=available/temporary_gap/research_only，不替代状态。缺账户不自动awaiting_account。

<a id="r-v3-audit"></a>
