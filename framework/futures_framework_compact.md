## 1. 固定规则层

### 1.1 池归属与路由 [源: 0)分层规则、0.0]

- 核心：每周维护品种卡、0.2、阶梯、事件轴；准入=#1期限+#2流动性+#31真实计划风险/容量+驱动对应合约定价窗口。近月紧张不自动支持远月单边。
- 独立备选：维护0.2和品种卡；有独立供需证据才升核心，升级首期系数0.5。
- 信号席：只取指标服务状态/门，不建仓；周度扫描仅记录退出理由与复活条件，不取脚本全量数据、不进0.2。一般复活=独立驱动+#1/#2过+2ATR预检有容量→先备选，#31待完整计划；用户明确排除优先。
- 池外休眠：未在核心/备选/信号席的品种，其策略块、门、乘数、惩罚项及“必刷”指令停用；保留复活条件。H/④/D15/②''/#28、曲线、JM月差/JM-RB、PS/LH/LC、C单边、SI-E、SI/AL-F休眠。跨资产/权益资金面只作商品背景；不把池外未知项传染为全账户冻结。

| 路由 | 表达与边界 |
|---|---|
| 近月 | 已出清叙事的极端分位回归、事件落地确认后的冲击顺势、近月现货验证；不承载远月政策预期；政策多头受#27 |
| 远月 | A期限结构、F政策远月赔率；公告/deadline不加权；A先过数据及方向协议 |
| 结构 | 同品种月差及经核定的对冲/价差；完整配对才豁免近远横跨、单边D12、#16、#30及MA原油周涨单边护栏；不豁免组合风险/成本/两腿执行及专属门；裸腿按单边 |
| 横跨 | 同品种横跨近/远方向性单边禁止；结构/价差除外[#4] |

### 1.2 事件与低敞口 [源: 0.0b、0.1、4.0]

开仓/加仓前完成：未来10个交易日节点清单；横跨未落地节点的T-1对冲/减仓预案；节点±1新开限制；模板“事件日历核对=已完成”。实际未核验不得填完成，不得输出开仓/加仓决策。换月是机械执行节点，仍须核对。

低敞口任一适用触发命中→组合上限使用§1.8的min(常规组合预算, LOW_EXPOSURE_RISK_CAP)；多项不累计扣减，不加入单笔乘数。触发清单：宏观节点T-1未对冲金融/准金融单边；能源单日脉冲[#30]；存量carry双杀[D15]；高密度簇且当周有未落地离散催化；policy_calendar_density=高且当周≥2政策节点未落地；liquidity_regime=收缩；地缘/权益夜盘跳空风险；波动升档且临近事件T-3；收缩证伪[D14]；创新高且周涨前10%；交易所保证金/限仓公告±1日；ATR分位极差>50且单边当日未重校准；地缘双轴质变日及次日；跨资产再校准下依赖跨资产对冲；#28重新冻结。休眠项仅在复活后适用。

地缘质变：霍尔木兹持续<10艘/日、回升至10日均以上、停火/重开、扩大打击/再袭船；俄乌停火、禁令扩汽油/延期/解除、更大打击。任一方向都作双向跳空预案，不预设机会。敏感品种周五前对冲/减仓；相关性再校准时依赖对冲的组合按无相关性保护核验。交易所公告±1日受影响品种新开门槛+0.3，公告日检视占用。解除低敞口需复评全部仍有效触发，不能只移除其中一个。

### 1.3 合约、换月与数据时点 [源: 0)阶梯及注a–e、0.2、6.8]

- #1使用trade_cal真实交易日；#2使用≤行情基准日近20交易日均量，单日放量不算。
- 方向性执行腿=主力月阶梯中剩余td≥20+策略持仓上限的最近月份；D上限30日时需≥50td。
- **结构退出/重建唯一边界**=近腿触#1（<20交易日）或主力换月，先到为准；整对下滚。原“换月前15日”无统一基准已取消。计划必须写具体最晚退出日并覆盖预定最短持有期；不够则不满足该计划，不能静默缩短持有期。30–60日仅A参考，不覆盖更早退出日。
- 目标腿均须过#2，未过退到最近可过月份并标注降级。阶梯写死日期或fut_mapping主力换月先到即生效，不等周报；执行日核目标#2、回填0.2、重建新腿分位/计划。触发前3个交易日旧腿单边新开从严。
- 换月后价差同期分位/涨幅分位归零重建；新腿不能继承旧分位、方向、SL/TP或许可，观察期结构新开从严。SC信号腿按主力–次月读结构、不受#1/#2；INE近12个月逐月、更远按季挂牌，缺挂牌时取下一实际挂牌月。AU信号同样不作建仓判断。
- 每周0.2记录期限、20日均量、2ATR预检参考、微观完整度、precheck、保证金/限仓。2ATR只用于扫描，不是#31最终风险，不能输出最终手数；真实方向/SL、成本和账户缺失记incomplete。能源涨停/创新高周交易所措施从严预设受影响直到核实。

### 1.8 交易计划 [源: Step5]

STYLE不做日内；允许方向性单边+结构型对冲；不开放期权/跨式，扩展需另行许可。文中的“买保护/对冲”必须用已许可工具，无可用工具时执行减仓/观望，不自动添加期权。

#### A：方向、失效与退出协议 [源: Step5策略A]



本节适用于池内MA/RB/SR同品种跨月1:1组合。定义 `S=近月价格−远月价格`，单位为元/吨；做多价差=买近卖远，做空价差=卖近买远。一组=近远各1手。跨品种或非1:1结构须另有已核定模型，不能借用本式。

**研究筛选与交易信号分开**：同期分位≥70=研究候选，≥85=高分位研究候选；不使用“主仓触发”标签，不从极端分位推断交易方向或手数。低分位对称策略本次未新增。完整信号须同时具备已许可的模式/方向、独立微观证据、适用品种门与完整交易计划。单靠“历史100分位”不证明会回归，也不证明应追随延续。

| 模式 | 方向与依据 | 止损与目标关系 | 当期权限 |
|---|---|---|---|
| `reversion` 高价差回归 | 做空价差；现货/库存/供需及结构证据支持紧张缓解、价差收敛；MA地缘溢价fade仍须①缓和证真+结构确认 | `SL > Entry > TP1 ≥ TP2`；SL是进一步走阔后本逻辑失效的明确价差价位；TP1/TP2可参考30/10分位对应价差 | 仅在既有A路由与品种门允许时评估，不因本次定义修复解禁 |
| `continuation` 结构延续 | 方向须由已批准的具体结构模型给出，不能由分位自动选取；做多价差时需近月相对远月继续走强的独立证据 | 做多：`SL < Entry < TP1 ≤ TP2`；做空：`SL > Entry > TP1 ≥ TP2`；目标来自具体模型，不沿用回归型30/10分位 | 本次只定义协议，未新增许可；须显式记录批准来源与模型验证依据后再评估 |

**计划必填**：两腿合约及1:1配比、模式、方向、入场与失效依据、Entry/SL/TP1/TP2数值、价格单位、合约乘数、两腿费用/滑点、行情基准交易日与完整历史样本、许可来源、计划持有期、最晚退出日、双腿执行/跳空预案。缺项记`incomplete`；方向关系错误或净R不达标记计划校验未过。

**50分位只是回归进度参考，绝不自动充当SL或风险锚**。触发统计使用价差百分比时，输出其分位；实际损益一律用同一组冻结的元/吨价差数值计算，不把百分比分位直接代入人民币止损。30/10分位也是参考目标，入场时固定数值、记录样本与依据；滚动样本更新不静默挪动止损或止盈。止损不得为满足手数反推或放宽。

```text
side = +1(做多价差) / -1(做空价差)
cost_unit = 两腿开平合计滑点成本 + 两腿开平合计手续费
           # 默认滑点预算=4×tick_value(近远每腿开平合计2tick)，实际更大时取更大值
risk_unit = side × (Entry−SL) × multiplier + cost_unit
net_reward_tp1 = side × (TP1−Entry) × multiplier − cost_unit
R = net_reward_tp1 / risk_unit ≥ 2.5
```

Entry为信息齐备后下一可成交时点的计划价差，实际两腿成交后重新校验风险和R；不得将盘后结算价当作已能成交的价格。两腿限价、最大可接受滑点和一腿未成交的撤单/平裸腿预案必须事先写明；裸腿期间按单边风险计入账户，不能享结构豁免。压力情景须核对价差反向跳变、单腿成交及交易所扩板提保，既有gap/周末/保证金门继续独立执行，数据未知不能标记`ready`。

期限以0)合约滚动阶梯的**近腿触#1(<20交易日)或主力换月，先到为准**作为唯一结构退出/重建边界；交易计划须写出具体最晚退出日，至少覆盖预定最短持有期。原“换月前15日”没有统一日期基准，自本版取消该重复表述，统一使用上述更明确的结构滚动规则。30–60日是参数参考窗口，不能覆盖更早的退出日期；窗口不够则本合约对不满足该计划，不能靠默默缩短持有期过门。换月时原计划结束，新对重新核样本、方向、SL/TP和全部门，不继承旧分位或许可。

黑色月差仍受D14及铁水/复产逻辑检视，收缩叙事不额外加分。MA结构不受#30及原油周涨方向性单边护栏，但①的fade门、质变日结构检视、双腿执行与组合总风险上限仍适用。MA近强远弱目前只构成研究对象，未核定的方向和SL/TP不得回填为可交易信号。池外SC/PS/LH及其他结构模块保持休眠，复活时先按本节重建协议。

#### 仓位：唯一计算出处 [源: Step5仓位计算]



本节是所有池的手数、组合计划风险和低敞口预算的唯一计算出处。金额单位均为人民币元；单腿的单位=1手，A的单位=近远各1手的一组。计划止损风险不保证能以SL成交，不是最大可能亏损。

【用户裁决2026-09-06】低敞口组合计划风险采用5,000元固定上限，并受常规净值3.5%预算约束；不再机械减半。该金额是用户接受的风险配置，不是回测最优参数。实际净值降低时取更低常规预算；实际净值增加时低敞口仍封顶5,000元。#16、独立事件系数和专属否决继续各自适用。

```text
trade_cap = ACCOUNT_SIZE × 3.5%                          # 当期值见§3
portfolio_cap_normal = ACCOUNT_SIZE × 3.5%               # 当期值见§3
low_exposure_cap = LOW_EXPOSURE_RISK_CAP                  # 用户确定的固定金额5000
portfolio_cap = min(portfolio_cap_normal, low_exposure_cap) if RISK_REGIME == low_exposure else portfolio_cap_normal

# 先有交易逻辑及有效失效止损，再核成本；不得反推止损凑手数
risk_unit = abs(Entry−SL) × multiplier + round_trip_cost
# 单腿滑点预算=2×slippage_tick×tick_value，另加实际开平手续费
# A同品种1:1组合风险/成本见策略A；禁止把距中位数的距离当风险

factor_product = strategy_factor × 各适用场景的仓位系数
trade_effective_budget = trade_cap × factor_product
used_open_risk = sum(各持仓剩余计划止损风险金额，逐项≥0)
reserved_order_risk = sum(未成交挂单及部分成交尚未计入持仓的预留风险金额，逐项≥0)
portfolio_remaining = max(0, portfolio_cap−used_open_risk−reserved_order_risk)
existing_trade_risk = 本交易已持仓及挂单风险合计             # 新交易须显式填0，已含在上述组合占用中
trade_remaining = max(0, trade_effective_budget−existing_trade_risk)
candidate_budget = min(trade_remaining, portfolio_remaining)
risk_lots = floor(candidate_budget / risk_unit)            # 风险手数仅在此取整一次
final_lots = min(risk_lots, margin_capacity_lots, position_limit_capacity_lots)
```

**系数规则**：strategy_factor来自2.2；其余适用仓位乘数来自2.3，逐项记录规则ID/适用对象/数值/依据。全部为0–1，不适用项记录为1及理由；评分加分D10不是仓位放大系数，不能把“商品0分”当仓位×0。高位档位按最严一档，不能同时叠×0.6与×0.3；同一D12高波/事件风险项只记一次，高波+共振的×0.3替代该组×0.5，其他确属不同风险且原文要求叠加者照常保留。MA周涨护栏在表中重复出现时按同一规则ID只执行一次，>8%冻结优先于>5%折减。**低敞口只改变portfolio_cap，不进入factor_product**；独立的T-1事件系数或#16禁令仍适用。硬否决的理由单列，不用乘积为0隐藏原因。

**数值工具输入分组**：`factors`仅接受strategy、D11、D12、D13、D14、D15、event_window、exchange_buffer、promotion、driver_weakness、MA_oil_guard、seasonal_adx、policy_adverse、equity_confirmation、correlation_recalibration。D12高波/T−3事件/高波共振须调用前按最严值归为唯一D12；event_window只表示独立T−1纪律。driver_weakness包括同源驱动衰弱及基差/库存/利润背离，correlation_recalibration对应2.3未对冲跨资产再校准。未知组名或JSON重复键拒绝；不得通过别名重复乘同源风险。新规则若引入独立风险组，先同步正文与工具契约再使用。

**账户占用**：使用经核验、带时间戳且与测算时点同一北京时间日期的账户快照；快照不能晚于测算时点，有新成交/撤单后须刷新。明确核实无持仓/挂单才可填两个空列表；脚本POSITIONS为空、上周称空仓均不能替代。结构按配对后的组合风险计一次，未配对裸腿按单边计；不同交易风险保守相加，不因相反方向、浮盈或未验证相关性自动抵消。已有盈利持仓按当前估值到有效止损的不利损失与成本计，不填负值。持仓或预留风险未知 → portfolio_remaining和final_lots为null、状态incomplete。

**交易所与保证金容量**：margin_capacity_lots为同时满足全账户保证金≤净值60%、受提保品种≤净值20%及经纪商实际收费/可用资金约束的新增整数手/组数；两腿按实际保证金收取口径计算，无核实优惠则不假设抵扣。position_limit_capacity_lots为各腿在交易所限仓80%阈值内扣除现持仓/挂单后的新增整数容量，两腿取更小可配对值。受提保/限仓品种的0.8缓冲仍是单笔适用系数，只记一次。容量未知时可留risk_lots，但final_lots=null；容量为0则明确记录保证金或限仓阻断。多个候选不得各自复用同一笔portfolio_remaining，按评分排序及固定平分顺序逐笔预留后重算。

**新开与加仓**：risk_lots或final_lots经完整计算为0，才可报告“预算/交易条件不支持最小单位”。任一必要输入未知则报告“尚未完成核验”，不可写成“市场无机会”。加仓须把拟加数量与该交易现有风险合计核对单笔有效预算，并占用组合剩余预算。数值工具`scripts/futures_risk.py`只校验A计划与数值容量，返回portfolio_risk_cap_normal/portfolio_risk_cap_current分别表示常规/当前组合上限，low_exposure_cash_cap表示固定金额配置；不再输出portfolio_regime_factor，旧portfolio_risk_cap名称改为当前上限别名。返回值不代替Step4全规则许可；只有完整门核验通过且final_lots≥1才可标ready。

**存量重校准**：方向性单边保留ATR20_entry及原止损公式；ATR20_now/ATR20_entry>1.3或分位升入>80时，以既定策略的SL口径及当期ATR重算，不统一改成2ATR、更不放宽已有止损。超出单笔有效预算或组合上限部分按原纪律次日开盘先行降仓；触即时风险/保证金约束则按其要求更早处理。当日核验未完成不得隔夜(#25)。结构豁免单腿ATR重校准，但仍每日核对自身有效SL/实际风险、双腿保证金与组合总上限。

低敞口命中多个条件仍只应用一次固定金额上限；不反复将存量“再减半”。存量合计超过组合上限时按实际金额减至上限内，并保留各品种更严的强平/禁隔夜纪律。解除须由0.1状态复评确认，不能因某一个触发消失就忽略其他仍在命中的触发。
