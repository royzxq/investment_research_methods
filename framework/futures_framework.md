# 期货研究与执行框架 v3.0

方法日期：2026-10-11（Asia/Shanghai）。本文件是唯一方法权威；[精简版](futures_framework_compact.md)保留同一组有效规则，[数据协议](FUTURES_DATA_PROTOCOL.md)规定取证与工具接口。当前市场状态见文末，不能把方法更新当作新行情或交易许可。

## 0. 决策链总览

<a id="r-v3-scope"></a>
只研究两类机会：**T 顺势（trend）**和**V 有经济依据的回归（economic_reversion）**。先筛选价格信号，再论证与计划，最后核账户。目标是持续产出少量可检验的方案；允许无交易，不要求每期凑出买卖建议，也不能因账户暂缺而停止研究。默认持有期限不超过20个交易日，不做日内交易、期权、跨品种套利或股指carry。

新增参数是待验证的研究规则，不是已证明有效的收益规律。前瞻约束针对评估、计划登记和执行，不要求价格信号日必须晚于框架生效日。可按当前固定参数重评已完成行情：保留原`signal_date`、原有效期，记录真实`evaluated_at`与`registered_at`，仅用于登记后的未来可交易时段；不能重启两日计时、回填历史建议/成交或把登记前涨跌计为策略业绩。T的当前产业证据可用于当前决策，不假称信号日已知；V仍须有在信号前冻结且适用的经济锚，不能事后造锚选中旧价差。研究与工具均不执行交易。

<a id="r-v3-pool"></a>
| 层级 | 品种 | T 顺势 | V 经济回归 | 日常投入 |
|---|---|---|---|---|
| 重点 | 豆粕 M、螺纹 RB | 双向 | RB同品种月差；M暂不开放 | 每期优先覆盖 |
| 常规 | 甲醇 MA | 双向 | MA同品种月差 | 价格筛选后按需深入 |
| 常备次级 | 白糖 SR、棉花 CF | 双向 | SR同品种月差；CF暂不开放 | 有信号/产业变化再深入 |
| 信号席 | 黄金 AU、原油 SC | 不交易 | 不交易 | 仅在解释实际候选风险时引用 |

V仅限MA/RB/SR近远月1:1；其他月差、跨品种、金融期货及JM均不在执行范围。保留用户对AU不交易、JM移除、SR/CF常备的既有裁决。池外没有每周必刷任务；扩池须另作明确方法修订，不能借改名套用T/V。

<a id="r-v3-workflow"></a>
每期先对5个执行品种做T筛选，对有可解释错价的3类月差做V筛选；记录覆盖与未覆盖原因。未触发不强制补完整计划；未知与未触发分开。周度更新产业假设，交易日收盘后/下次入场前刷新机械信号及事件；只有周更而无逐日刷新时须披露监测空窗，不声称覆盖了周初短期信号。可提前写最多2份尚未触发的条件观察计划（突破价/产业条件/失效条件），仍为no_signal，不算可执行建议。按证据完整性、成本和可执行性选**最多2个独立机会**深入，同一机会跨周沿用opportunity_id。账户后置，无账户仍须尽量完成G1–G4。

## 1. 数据与产业研究

<a id="r-v3-data"></a>
行情须含真实合约、交易所、交易日及抓取时间；close、settle、pre_settle分别保留。T用实际收盘OHLC，V用同日两腿settle作信号；均不拼连续主力、不拿旧合约指标配新合约价格，不把结算价当成交价。原始日线必须完整、唯一且可对照真实交易日历；异常或缺值不补零。对非交易日运行使用最新已完成行情日，不能用未完成当日线。

产业事实记录原发布者、链接、观察期、发布时间、单位、样本/地域和比较期。原文未读的搜索摘要只作线索；可信公开转引可用，但标明不能确认的口径。月度数据按月度使用，不伪造成周度变化；尚未到官方发布时间的值不算取数失败。全国旬度现货价不直接当成某交割地基差。来源取证、信号计算、模型判断与账户事实分开。

<a id="r-v3-calendar"></a>
所有日期按交易所真实交易日历计算，夜盘按所属交易日。事件同时记官方带时区发布时间、北京时间、首次国内可交易时刻和国内事件日T；美国当地日期不能直接用作国内T。只有经核实会影响具体候选的事件才适用窗口。交易所休市、合约最后交易日、自然人/经纪商提前退出要求均从当前有效规则核验，不能以普通工作日替代。

<a id="r-v3-economics"></a>
### 豆粕、螺纹的最低研究路线

T需要**至少一项独立于期货走势、与方向有关的当前产业事实**，并核最强反证。所谓当前，指截至研究时已发布的最新适用周期，注明时滞；不能无限沿用一条旧新闻。T是带产业解释的价格顺势，不要求产业全链同向或先证明长期均衡价。关键产业输入确实缺失为unknown；已有明确事实推翻主因则G2 fail，不能仅靠缩仓继续使用失效逻辑。

| 重点 | 沿什么链研究 | 支持做多的例子 | 支持做空的例子 | 最容易误判的反证 |
|---|---|---|---|---|
| M 豆粕 | 大豆到港/可用库存→压榨与豆粕供应→豆粕库存、提货/成交与当地基差 | 豆粕库存下降且由提货改善或可核供应减少解释；或进口成本冲击已传至国内现货/基差 | 到港/压榨恢复造成豆粕累库、提货走弱或基差走弱 | 大豆短缺未必已变成豆粕短缺；减产去库不等于饲料需求改善；油强带动压榨可能增加粕供应 |
| RB 螺纹 | 同口径螺纹产量→厂库+社库→表观消费/实际成交→同地区同规格现货和基差 | 库存下降由需求改善或可核减产支撑，并说明是哪一条逻辑 | 产量/到货回升而成交弱、库存累积或现货走弱 | 全部钢材/五大材库存不等于螺纹库存；铁水不等于螺纹产量；单纯减产去库不能写成需求复苏 |

M优先读国内油厂、行业公开统计、仓单与当地现货；CASDE及USDA用于进口、压榨与全球供应背景，只有解释了传导环节才能支持M方向。RB优先使用同一统计者同口径的螺纹产销存、交割仓单和对应现货；政策表态、地产投资或焦炭涨价不能单独证明本周螺纹短缺。表观消费是平衡表残差时必须注明，不冒充终端成交。

最低交付是一条可检验因果链，不是整张产业数据库。库存、基差、产量、成交不要求全部获得；若计划依赖其中某变量，该变量就是必要输入。持续拿不到的专业模型列research_only，改用确有解释力的公开路线或结束该模型；不得机械把不等价代理降格替代为“已验证”。

RB的V另外解释为何近月相对远月将修复：可交割供应、库存持有成本、区域基差及近远月供需差。M本版先把双向T做完整，不直接搬用RB/MA月差。MA关注装置、到港、港口库存及可交割供应；SR关注产销库存、榨季与交割供应；CF关注新棉上市、纺织需求、库存与基差。季节、事件、成本只解释T/V，不另立策略或固定月份开仓门。

<a id="r-v3-quality"></a>
### 证据用于排序，不作总分门

取消加权总分、D1–D15评分及4.0/4.2/4.5等叠加门槛。使用`evidence_quality=strong / adequate / weak`：多项独立一致为strong；满足最低因果链且无决定性反证为adequate；存在非致命分歧为weak。weak若仍具备必要证据可用market_risk=0.5研究；关键输入缺失直接unknown，已证伪直接fail，不能包装成weak过门。同一数据的多次转引不算独立证据。排序先完整性，再证据质量、成本与执行条件，不增加第二套准入规则。

## 2. 两类策略的固定定义

<a id="r-v3-signal-t"></a>
### T：顺势

记信号日为t，使用同一真实合约连续完整交易日，严格排除信号日：

```text
U20(t) = max(high[t−20 : t−1])
L20(t) = min(low [t−20 : t−1])
close(t) > U20(t) → long；close(t) < L20(t) → short；相等不触发。
TR(t) = max(high−low, |high−前日close|, |low−前日close|)
ATR20 = 固定最近61根完整日线产生60个TR，首20个TR均值初始化，余40个按Wilder递推：
        (19×前ATR+当日TR)/20；每次计算固定相同长度，不与旧EWM初值混用。
```

趋势信号与产业证据同时通过才是完整G2。新高/新低本身不否决趋势；不再要求D8周涨分位、ADX、250日高点或额外均线。v3统一取得61根连续完整OHLC，同时支持固定ATR初值与60日波动预算。原快照含信号日的H20/L20不符合本定义。

<a id="r-v3-plan-t"></a>
T计划在信号后第1至第2个交易日有效，实际Entry与signal_close的绝对距离≤0.5×信号日ATR20，且long仍须>U20(t)、short仍须<L20(t)；超出、过期或经济逻辑失效就取消，不能顺延等回价。Entry为下一可交易时段的计划报价区间及选定价格，不是t日盘后已成交。

当前重评已有T信号时，仍从原信号日计算上述窗口；与登记后的未来可交易时段取交集。尚在有效期且其余条件成立，不因框架刚升级而要求再次突破；已过期才等待新信号。评估/登记前已发生的夜盘或日盘不得追记为入场。

- 初始SL：long为Entry−2×ATR20(t)，short为Entry+2×ATR20(t)。SL按实际tick向不利方向取整（long向下、short向上），入场范围向内对齐tick；成交后按真实Entry重算风险和容量，报价偏离不能通过缩止损凑手数。
- `targets=null`，无固定TP，也无最低净R门。趋势收益来自后续路径，不用“2R目标”反过来证明2R赔率。
- 入场后的每个完整日收盘，计算最近10个完整交易日的最低low/最高high，作为**下一交易时段**long/short的跟踪止损；只能向有利方向收紧，首次收紧不早于入场日收盘。记录所用10日及生效时刻，不能用尚未完成日的极值回填盘中退出。
- 事前计划最晚退出日晚于入场日（止损/证伪可当天退出）。入场日算第1日，第20个交易日收盘前退出；与已核更早合约/事件/逻辑退出边界取最早，事前写具体latest_exit_date。止损触发在可成交时退出，不承诺恰按SL成交。首次信号后冻结参数，不按每周结果反复换20/10/2/0.5。

<a id="r-v3-signal-v"></a>
### V：有经济依据的回归

只做MA/RB/SR同品种近远月1:1，`S=近月settle−远月settle`，元/吨；一组为各1手。short=卖近买远，long=买近卖远。价格可正可负。

研究方先给独立于期货历史分位的经济锚`[low,high]`：列现货/可交割供给、仓储资金及跨期成本或近远月供需差的数值与来源、计算过程、适用月份、有效截止；成本约束还须核储运/交割能否实现。非线性、地区/品级差和近月短缺可能使锚失效。锚要区分“可复算的持有/交割成本边界”和“供需修复情景区间”；后者列价格转换假设与不确定性，库存数量不能直接换算成某个公允价差。只有方向证据而无法给合理区间时，保留T/观察，不硬造V。单侧成本边界不能复制成对称区间。持有成本可约束部分contango，却不意味着backwardation有对称上界；不能把“偏离历史均值”直接写成可套利。

必须解释**未来5–20交易日内**哪项已发生或可检验的变化使价差向锚修复，以及最强反证；不是要求最少持仓5日，止损/到价可提前退出。锚、机制、反证与数值止损随计划冻结，不能看见回落后换锚。价格确认用连续同对的3个完整交易日：

```text
short：S(t)>high 且 S(t)<min(S(t−1),S(t−2))
long ：S(t)<low  且 S(t)>max(S(t−1),S(t−2))
```

相等不触发；不是看到高分位就空或低分位就多。历史同期分位/季节性仅为背景，不再要求3年×41日样本作为统一准入，也不能借V许可交易未定义的价差趋势。

<a id="r-v3-plan-v"></a>
V信号同样只在其后2个交易日内有效。short要求`SL>Entry>target=high`，long要求`SL<Entry<target=low`；实际Entry仍须在锚外。数值SL对应经济判断失效/可检验的不利结构变化，并解释为何该距离有效。用于下单的Entry、SL和目标须落在实际tick；经济锚若需报价取整须事前说明，不能用不可成交小数增加净R。目标取靠近Entry的锚边，不能为凑R改成远侧锚、任意分位或理想价格。

```text
side = +1(long) / −1(short)
cost_unit = 两腿开平全部手续费 + 滑点
滑点预算 ≥ 4×tick_value（一组近远每腿开平各1 tick）；实估更大则用更大值
risk_unit = side×(Entry−SL)×multiplier + cost_unit
net_reward = side×(target−Entry)×multiplier − cost_unit
net_R = net_reward / risk_unit ≥ 2.5
```

MA/RB/SR同品种两腿须乘数一致，实际tick/费用按当前规则和经纪商核实。整个冻结entry_range须位于SL与近侧锚之间，且其中最差入场价的净R仍≥2.5（short取区间下界，long取上界）；否则收窄范围，可使用单点[Entry,Entry]。净R只评价V，不跨模型排序成T的隐藏门。计划最长20交易日（入场日第1日），但可供收敛的合约有效窗口必须覆盖所声明5–20日机制；禁止事后缩期限凑过门。数值target、SL、entry_range、valid_until、latest_exit_date及双腿执行预案齐备后才是完整计划。实际成交价差变更时重新核净R、风险、账户容量；不能将两腿不同时间的有利报价拼成Entry。

## 3. 核心风控：一次计预算，保留真实执行约束

<a id="r-v3-expiry"></a>
### 合约与交易能力

任何实际腿距最后交易日须≥20个真实交易日；计划必须在落入`<20`之前完成，且不晚于更早的自然人、经纪商、交割及限仓强制边界。开仓前写出各腿最后交易日、强制退出日、计划可持有日数；“当前还剩20日”不等于还能持有20日。不能用虚构的工作日计数延长期限。

<a id="r-v3-liquidity"></a>
每腿最近20个完整交易日日均成交量须≥10,000手，并核当前买卖报价、价差与计划数量能否成交。阈值通过不证明盘口容量足够。无当前报价可先出研究计划，交易执行保持未知；涨跌停无法退出或双腿不可同步处置时不新开。仓位不跨同品种多个近远层重复做方向性暴露；有存量时先处理已有计划，不能把对冲或换月算成免费风险。

<a id="r-v3-budget"></a>
### 金额上限与一次取整

用当日真实权益E，不固定假设15万元。基础`B=E×3.5%`；单笔风险上限B，组合计划止损风险上限也为B。低暴露期组合再封顶5,000元：相关重大事件风险尚未结束，或实际持仓/待开候选出现已核高波动时采用；仅证据非致命分歧不会自动触发全组合低暴露。低暴露是金额约束，不再全面禁止方向性新开。触发与解除以当期证据记录，未知不能默认normal。

```text
portfolio_cap = B（normal）或 min(B,5000元)（low_exposure）
trade_cap = B × strategy × market_risk × exchange_buffer
remaining_trade = max(0, trade_cap − 本机会已有持仓/未撤挂单风险)
remaining_portfolio = max(0, portfolio_cap − 全部持仓风险 − 全部未撤挂单保留风险)
risk_lots = floor(min(remaining_trade,remaining_portfolio) / risk_unit)
final_lots = min(risk_lots, margin_capacity_lots, position_limit_capacity_lots,
                 execution_capacity_lots及适用压力/周末容量)
```

只在金额预算汇合后向下取整一次，不能分步取整各系数；硬容量均为可新增的整数手/组。单笔与组合计入同一风险是两道上限，不能在同一剩余组合预算里重复扣同一持仓。`risk_unit>0`，纳入手续费和滑点；T也计开平成本，滑点至少2×tick_value（开平各1tick），实际估计更高取更高值。止损获利、结构对冲、不同品种相关性都不自动抵扣其他持仓风险；已有持仓按当前价格到有效止损的非负潜在损失加退出成本计，不以浮盈生成风险额度。

<a id="r-v3-factors"></a>
| 因素组 | v3固定规则 | 解除/缺失 |
|---|---|---|
| strategy | T和V统一0.7 | 本轮保留风险余量；不是评分 |
| market_risk | 通常1；高波动、相关持续事件风险、非致命产业证据分歧中任一成立取0.5，多个成立仍只乘一次0.5 | 三项逐一核；已核触发则0.5，缺必要判定仍须补；都解除才为1 |
| exchange_buffer | 当前受提高保证金/收紧限仓覆盖时0.8，否则1 | 核交易所条件及经纪商实收；不能凭节后日期自行恢复 |

高波动：T以同合约close的对数日收益样本标准差`HV20/HV60>1.3`；V以同对价差日变动样本标准差`SD20/SD60>1.3`，不得对零/负价差取log。均需61个连续有效观察值，分母为0等不可计算情形记unknown。1.3相等不触发。比例不必年化；同一年化因子会相消。方向与结构使用各自风险序列。

波动已通过当期止损距离和market_risk预算反映，不再扣分或提高入场分数。同一风险不能以不同D编号继续相乘。费用、压力损失、保证金与限仓是实际执行约束，仍各自核算，不因预算折减而豁免。

<a id="r-v3-account"></a>
账户输入必须是当日可追溯快照，时间不晚于且接近sizing_at；包括权益、可用资金、全部持仓/未撤挂单、止损、风险归属、保证金、费用、经纪商限仓和适用系数。0持仓/0挂单也要有明确核验，不从脚本配置、旧周报或缺行推断。交易前若新增成交/挂单、价格、保证金或事件变化，立即重算；当日早些时候的快照不当然仍有效。缺账户时final_lots=null，不阻止G1–G4具体化；只出条件计划。

<a id="r-v3-margin"></a>
拟新增后总保证金占权益不得>60%；受提保覆盖品种的保证金合计不得>20%；任一适用交易所/经纪商限仓使用率不得>80%，取更严规则。只计算真实可用的双腿保证金优惠，未确认则按双腿分别占用。任一剩余容量不足1手/组即blocked；数据未知不填0或无限大。交易所最低标准不能代替经纪商实收；自然人不能依赖产业客户交割/套保豁免。

<a id="r-v3-gap"></a>
### 跳空、事件及双腿事故

`gap_ratio=stressed_loss/planned_loss`，同一手/组、人民币与费用口径。planned_loss是真实止损距离及成本；stressed_loss取它与不利压力退出价损失+压力成本的较大者。压力价来自明确场景、当前报价、可核历史跳空/涨跌停与假设，不是保证的最坏价。

| 品种 | 轻仓复核线 / 淘汰线 | 相关重大事件T−1至T+1 |
|---|---|---|
| MA | 1.3 / 1.8 | 淘汰线收紧到1.2 |
| RB、M、SR、CF | 1.5 / 2.0 | 淘汰线收紧到1.3 |

超过第一线须给具体减额与账户绝对压力承受金额，重新核可用资金；缺金额依据为unknown。超过淘汰线不新开，减手数不能改变单位gap_ratio。事件窗同时按下文冻结新开，收紧线仍用于存量复核。缺压力场景不凭“未见新闻”填1。MA无有效对冲跨周末时，单仓计划止损风险不得>B×30%；周五收盘前减至以内或退出。该金额与其他容量取严，不另加一层评分。

<a id="r-v3-pair"></a>
V事前给两腿限价、最大总滑点、允许裸腿时间及一腿未成交的撤单/平裸腿方案。完整1:1配对才按价差风险；裸腿按方向风险全额占用并即时处置。压力核价差反向跳变、单腿无法成交、扩板提保，不用异步有利价拼接；未确认的跨期保证金优惠、止损单或相关性保护不算已生效。无法监控两腿或执行事故方案时不进ready。

<a id="r-v3-event"></a>
经核实与具体候选直接相关的重大数据/政策/交易所风控/突发供给事件，国内T−1至T+1不新开；持仓提前重做压力与退出预案，不能可靠承受则减仓或退出。M的WASDE等供应事件、RB的实质供给政策、MA装置/地缘冲击须分别判断；CPI/FOMC并非全池自动冻结。每条记录相关性、T、窗口终点、窗口后首次可交易日，不用“事件密集”无限延长。

事件窗结束后使用原计划剩余有效期；原信号已过2交易日则过期，须等待后续新的价格信号，不能顺延旧入场。若实质风险持续，更新产业反证、压力场景及market_risk；不得把旧状态永久化为某方向禁令。交易所法律/规则仍有效的限制不因本框架窗口结束而解除。

## 4. 持有与复评

<a id="r-v3-stop"></a>
止损在建仓时确定，必须具备可执行监控/下单方案；触发后按可成交价格退出。禁止加宽止损、亏损摊平或为容纳1手缩小初始风险距离。T跟踪止损只收紧；V到失效价或经济假设被明确推翻时退出，不等目标。价格跳过止损、涨跌停锁住时记录未执行风险并用事故预案，不能回报为按SL平仓。

<a id="r-v3-manage"></a>
每个持仓交易日收盘后及相关重大事件后复核有效SL、真实风险、剩余期限、保证金和经济反证。T按10日通道/20日时间/逻辑失效取最早退出；不强制1R/2R固定止盈截断趋势。V按锚边目标/SL/时间/机制失效取最早，目标不得静默远移；库存上升是否利空取决于具体方向，不沿用“MA库存升一律减半”。参数更新不能放宽已持仓风险，风险超限优先减仓或退出；未核账户时给条件管理指令，不声称已实际减仓。

<a id="r-v3-roll"></a>
换月不是持仓自动续期。合约期限或实际流动性要求换腿时，关闭原计划；新合约/新月差重新算自身行情、信号、锚、费用和风险，不沿用旧合约指标、分位、日期或手数。已有足够连续历史可直接用于研究，不额外等待20/60日；不够则列真实数据缺口。旧版本实际存量若存在，先以真实账户登记并保留原有效止损，不因升级自动加仓或放宽风险，迁移处置另行留痕。

## 5. 输出与验证

<a id="r-v3-status"></a>
统一五种状态，data_feasibility另列available / temporary_gap / research_only：

| 状态 | 判定 | 输出 |
|---|---|---|
| no_signal | 已完成所需早期筛选且未触发；不存在影响该筛选结论的必要未知 | 方向、筛选读数、下次触发；允许不展开后续门 |
| incomplete | 存在必要非账户未知；或研究尚未成案 | 已知阻断与未知同时保留，写责任/补件 |
| awaiting_account | 信号已触发、G1–G4全过、完整计划且仅G5/G6账户类未知 | 具体条件方案，final_lots=null |
| blocked | 已知必要条件失败且其余必要未知不影响状态；不存在仍未完成的必要核验 | 所有已核阻断及解除条件，不写“已全面通过” |
| ready | G1–G6全过、当日账户核实、final_lots为≥1的整数 | 可供用户执行审阅的计划；成交前刷新 |

fail与necessary unknown并存，主状态incomplete但不得丢掉fail。signal未触发只是价格条件判断；已知方向反证可另外保留，不伪造信号。data_feasibility不能代替机会状态。没有账户不会自动使所有候选awaiting_account。

<a id="r-v3-audit"></a>
正文只需四块：覆盖表；最多2份完整计划或无法成案的具体原因；已持仓的条件管理；下一次触发/复核。附[schema 3审计](../projects/future_change_analysis/EXECUTION_AUDIT_TEMPLATE.md)，v3以strategy枚举和G1–G6记录，不再计算总分（旧score兼容字段写null并说明retired）。同一机会沿用ID，不把每周重复检查算成独立样本。

每条证据附日期与来源；每个necessary unknown写gap.kind、owner、next_action、due_at。定义/计划由research完成，计算由data_pipeline补，真实账户由user提供；官方未发布须给实际发布安排，不以项目截止冒充官方日期。only_blocker仅在适用核验完整后使用。报告不得把当期行情上涨、无交易或账户未知归因成某条护栏的有效性。

<a id="r-v3-shadow"></a>
成案后保存冻结时间、模型版本、参数、真实合约、计划价/实际可交易范围、SL、退出规则、成本和有效期，后续逐期追加可核行情与未成交/过期/退出原因。v3 T没有固定TP，现有`price_evidence.py`固定目标影子结算器不能结算该模型；旧`shadow_plans`仅保留v2历史。v3暂以candidate.plan与后续审计做人工前瞻轨迹，`performance_status=not_automated`，不得声称自动回测已支持或拿legacy结果算v3收益。

纸面登记不等于成交。没有事前冻结计划与后续可核路径时，收益、避免亏损与错过盈利均为null；日线无法判断盘中先后或真实双腿成交时亦不作有利假设。可登记被硬门挡下但研究已完整的计划用于以后评价，不能改标签绕执行门。

<a id="r-v3-validation"></a>
按独立机会复评，而非以每周候选条数为样本。每期统计：扫描覆盖、信号、G1–G4成案、仅账户待核、真正硬阻断、数据缺口；再看有可靠轨迹的计划结果及费用敏感性。连续两期卡在同一非账户专业字段，就指定公开替代验证或research_only结案，不再加必查清单。没有交易数配额，不以“更常给建议”替代质量评估。

20/10日通道、2ATR、0.5ATR、V的2.5净R与统一0.7预算均标`validation_stage=uncalibrated`。结构/离线单元测试只证明计算或契约，不证明盈利。后续策略检验需固定版本、真实合约/交易日、完整费用、无前视与保留失败样本；结果未完成前不宣称最优参数，也不另设“等全量回测完成才允许研究”的门。

<a id="r-v3-tools"></a>
工具分工：`future_data.py`采集候选行情；`futures_strategy.py`计算T/V信号并验证可计算计划；`futures_risk.py size-v3`算风险容量；`futures_refresh.py`复用现有行情/信号工具检查新鲜度、原计划有效期并留存轻量刷新；`futures_handoff.py`按类型选择明确采纳的报告及纠错、核规则/计算依赖兼容与来源哈希；`futures_continuity.py`冻结跨 worktree 本地采纳、纠错和 V 锚；`validate_futures_audit.py`验输出结构；`futures_framework_governance.py --check`验双版、锚点和迁移覆盖。均不能证明来源真实、产业因果、当时可成交或下达交易。旧A、季节B、D8和固定TP影子工具只支持历史复现，不能为v3授予许可。具体输入见[数据协议](FUTURES_DATA_PROTOCOL.md)。
