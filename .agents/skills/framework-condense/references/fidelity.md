# 保真规则与七项自审

本文件在执行 `framework-condense` 时完整读取。目标是保持核心方法、数字阈值、风控、例外和证伪条件，明确执行顺序，减少重复与冲突，并使当期状态可局部维护；保真优先于体积。

## 同步与组织

通读当前 canonical，提炼其自身的决策链，不套用另一轨道的阶段名。期货通常为路由→状态→策略→评分→门槛→计划→管理；股票通常为数据契约→Precheck→机制→Gate→估值→Terminal→Price Map→结论。开篇“0. 决策链总览”须在正文有完整承载。

对照上一版 compact 同步受影响条目，未改规则沿用稳定编号，新规则续号；日期变化不要求重写无关规则。必要时可重排结构，但逐项保留有效内容。当前状态原位替换，历史在日期报告与 git；规则与动态状态在现有文件内分区，不新增碎片方法模块。

按四轴组织内容：

- **固定规则/动态配置**：判定条件、阈值、公式与映射归固定层；当期状态、事件日历与防过度反应项归动态层，分段维护。
- **通用规则/标的特例**：通用定义保留唯一出处，特例写与通用规则的差异，不复制通用内容。
- **执行条件/背景解释**：compact 保留完整判据；论证过程通常留 canonical。执行所需经济逻辑、换算基准、口径或边界仍要保留，可压成短句。
- **当前结论/历史过程**：保留有效结论、观测日期、证据限制及解除条件；被明确取代的旧值、历代标记与勘误过程留历史。仍用于比较基准、连续条件或触发窗口的旧日期不可删除。

消重时采用唯一权威定义与短引用、条件→动作表达、字段或表格。规则来源指向现行 canonical 章节；保留既有规则ID与章节映射，不从 git 补齐被删去的有效规则。来源可在同组表头记录，不必反复附同一引用。

## 语义原子

逐条保留五元组：**触发条件、数值阈值、动作、例外/豁免、证伪/解除条件**。措辞与结构可改，语义不可走样。

- 数字、单位及比较符（≥、>、≤等）不得近似、改变或遗漏；公式完整保留。
- 且/或/非、执行顺序、覆盖关系与优先级必须精确等价。
- 单独清点例外和证伪条件；带复活/解锁条件的冻结、归档、休眠或挂起条款属于活逻辑，不因当前不执行而删除。
- 未确认失效的内容先保留。发现冲突时按明确权威定义或覆盖关系收敛；没有依据时记录待澄清项，不静默择一、不填新参数。

## 七项自审

全部完成后才能交付为已核验的同步结果；若当前任务允许提交，未通过项修复或明确阻碍后再按根执行约定处理。

1. **有效内容覆盖**：逐条核对五元组，完整方法、策略、评分、风控及输出契约均有承载。遗漏补回；数量或编号相同不等于内容一致，未完整计数不可声称全部语义等价。
2. **数值与公式**：用 `rg` 或只读脚本对照数字、单位、比较方向、公式与日期；逐项解释删值属于重复或已失效历史的依据。相同数字出现不证明逻辑角色相同；有效比较日期不删。
3. **规则引用**：稳定ID无改名、重编、重复定义或悬空引用，来源及章节映射有效。
4. **自包含执行抽检**：选三条 canonical 定义明确完整的规则构造假想情形，仅凭 compact 走判断。精简遗漏导致回查时补全；canonical 原有缺定义不为自包含而编造。
5. **副本矛盾**：不静默择一；有明确权威定义/覆盖关系时据此收敛并记录依据，否则保留边界并列待澄清项，不借精简改方法。
6. **决策链**：“0. 决策链总览”每一步在正文有对应固定规则及适用动态配置，无断链或空节。
7. **体积与范围**：记录行数、字符或 UTF-8 字节 before→after，并说明计量口径；确认未增加方法模块、研究范围限制或必办门。期货运行 `python3 scripts/futures_framework_governance.py --check`；股票核 R/D 编号、来源及章节引用。结构检查不能证明语义等价或规则有效性，诚实记录未运行/失败与验证限制。

## 结果承接

compact 文件头只保留当前关系、方法日期和状态日期，不积累精简履历。适配报告记录覆盖核对、尺寸、抽检、歧义与限制；不粘全文。返回尺寸统计、核对结果、原有歧义及验证限制，供同一框架更新流程的编排器使用。

仅授权本地维护时交付本地结果，不启动市场调研或发布；已授权的完整更新流程按根 `AGENTS.md` 在同一分支承接，不由本 skill 另开一套发布流程。
