# 框架保真维护

输入 `CANONICAL_PATH`、`COMPACT_PATH`、本次变更报告（如有）。先读根 `AGENTS.md`，再读 [保真规则与七项自审](references/fidelity.md)，按当前 canonical 全文和上一版 compact 同步受影响内容，并核对全文一致性。

canonical 保存完整有效规则，compact 是同一框架的详略表达；只删除重复表达、修订簿记及已被明确替代的历史，不删有效策略、评分、执行要求或当前状态。每条规则保留“触发条件、数值阈值、动作、例外/豁免、证伪/解除条件”；数值、单位、比较方向及逻辑关系精确等价，稳定规则标识不重编。无法确认失效或缺少权威定义时保留边界并记录歧义，不通过精简补造规则。

不设压缩比例、目标字数或硬体积上限。只要求 compact 维护时不改 canonical 规则；用户同时授权 canonical 治理时才在该范围处理。实际标的研究可用 compact 导航，方法修订、参数核对及歧义裁决仍回 canonical。

完成七项自审后，更新 compact 当前方法/状态日期；将覆盖核对、数值/引用检查、尺寸统计、抽检、歧义和验证限制写入适配报告的“精简版同步”（期货 §9、股票 §8），独立维护则按用户授权交付核对记录。报告链接完整框架，不粘贴全文；未完整核验不能声称“100%语义等价”。

提交、分支与 PR 统一遵循根 `AGENTS.md`；已授权的完整框架更新流程内，在同一分支提交 compact 与报告并向编排器返回核对结果。本地整理不自动运行调研、提交、推送或开 PR。
